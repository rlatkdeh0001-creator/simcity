# 확정 요청과 프로토타입 선택

사용자 직접 요청: CITIES_DO, 심시티 계열 격자 건설, 자유롭게 그리는 도로,
2×2 신축, 2×2·4×4·8×8 무작위 재개발(8×8 약간 선호), 수치가 부족한
인접 건물도 함께 업그레이드될 가능성.

첨부 문서는 Godot·아이소메트릭·데이터/렌더 분리와 일반도로 구획 조건의
참고 자료로 반영했다. 문서 전체 기능을 이번 요청으로 간주하지 않았다.

## 변경 가능한 기본값

- 부지 크기 추첨: 8=45%, 4=30%, 2=25%. 공간 제한이 반영된 최종 비율이 아님.
- 추첨 크기가 불가능하면 더 작은 크기로 내려가며, 유효 공간이 없으면 변경하지 않음.
- 기존 부지의 중심을 포함하는 로컬 정수 좌표 후보를 가까운 순서로 검사. 자동 합필·철거 없음.
- 레벨은 성장할 때 +1. 레벨과 부지 크기는 별개라 높은 레벨도 2×2가 될 수 있음.
- 신축 수치=0, 최초 성장 기준=100, 인접 전달 확률=55%, 한 트랜잭션 최대 8개.
- 공유 변 길이가 양수일 때 인접(모서리만 닿으면 제외). 성장 전 인접 그래프를 사용.
- 같은 연쇄에서 한 건물은 한 번만 방문. 확률 실패한 이웃을 반복 재추첨하지 않음.
- 연쇄는 수치 조건만 면제하고, 공간·도로 접근·경계를 계속 검사.
- 신축은 일반도로 가장자리에서 2.5셀 이내. 일반 2·3·4·5·8차로 도로 폭=각각 2·3·4·5·8셀(보도 포함). 고속도로는 접근권 없음.
- 도로는 연속 좌표 폴리라인(손으로 그린 곡선을 샘플링한 형태). 매끄러운 스플라인,
  차로 연결 그래프, 교차로 신호·자유 높이 편집·10m 이격 검증은 이번 구현에 포함하지 않음.
- 자동 시간 성장·경제 수치 산출은 미구현. 데모에서 수치 +100 및 성장 버튼으로 검증.
- 대규모 최적화 전의 MVP: 충돌은 건물/도로 순회, 연쇄 인접 그래프는 O(B²).
  10만 시민·대규모 지도 성능을 검증했다고 주장하지 말 것.

## 승인된 중형 주거 외관

- 사용자 승인: 벽돌형·모던형 맨션 두 안 모두 중형 주거로 채택.
- 실제 정의: cities_do/assets/buildings/catalog.json의 `medium_residential` 2종.
- 두 안 모두 4×4 부지, 지상 4층, 성장 레벨 2 이상에 사용.
- 같은 크기 성장 시 외관 유지, 크기 변경 시 카탈로그 재매칭.
- 4×4 후보 2종은 동등 확률이며 외관 난수와 성장 난수를 분리.
- 성장 크기 확률·수치·연쇄 규칙은 기존 설정을 유지.


## 타일·도로 시안과 예시 지도

- 1칸=4m 제안 유지. 2차로=2칸(8m), 4차로=4칸(16m), 방향별 1+1 / 2+2.
- 기본 예시 지도는 maps/example_100.json의 100×100. 시작 시 빈 지형, 격자 숨김.
- 일반도로 확정 시 주변 8칸 깊이 범위의 도로 로컬 격자만 표시. 도로 면은 구획에서 제외.
- 블록 진행 방향과 구획 깊이는 지도 위에서 직각. 아이소메트릭 화면상 각도와 구분할 것.
- road_geometry.gd는 연속 경로를 폭 있는 면으로 변환. 렌더링의 픽셀 선폭을
  도로의 실제 폭으로 간주하지 않음. 보도까지 포함한 폭으로 건설 충돌 판정.
- 32×32 희소 구획 청크와 화면 범위 조회 사용. 1024×1024 전체 도시 성능이
  검증되었다고 주장하지 말 것. 빈 맵·짧은 도로 국소 검사만 완료.


## 직각 구획·곡선 규칙

- 도로별 로컬 (u,v)는 정수, 블록 원점·기저와 월드 부지 꼭짓점은 실수 좌표.
- 곡선은 짧은 반듯한 블록으로 근사. 최대 8칸, 방향 편차 ±10도, 직선 근사 오차
  최대 0.25칸은 임시 기준. 꺾임에서는 새 블록을 생성한다.
- 모든 칸은 정사각형. 곡선 안쪽의 겹침·도로 침범·지도 경계 칸은 제거한다.
  블록 충돌은 먼저 만든 쪽 우선이며, 빈틈을 늘이거나 찌그러뜨려 채우지 않는다.
- 건물 신축·성장·인접·충돌 판정은 같은 회전 부지를 사용. 8×8도 한 블록 안에
  들어가야 하며 불가능하면 작은 크기로 검사한다. 도로 변경으로 건물을 자동 이동하지 않는다.
- PNG 건물은 임의 방향으로 단순 회전/변형하면 안 된다. 현재 회전 부지는 임시
  입체 건물로 표시하며 방향별 원본 또는 3D 연결은 후속이다.
- 구획 후보는 모든 도로 주변 블록에서 재생성. 희소 저장이 전체 도로망 성능을
  보장하는 것은 아니며 대형 도시 증분 갱신은 후속 최적화 항목이다.

## 승인된 소형 상업 외관

- 사용자 승인: 동네 MART, 2×2 부지, 지상 1층.
- `small-2x2-mart-01`을 상업 신축에 배정. 주거·공업이나 4×4 이상에는 사용하지 않음.
- 원본: `assets/commercial-study/small-2x2-mart-01/mart.blend`.

## 승인된 4×4 소형 상업 외관

- 동네 슈퍼마켓(1층), 식당·카페 복합상가(2층) 모두 승인 및 등록.
- 상업 4×4 부지에서 두 외관을 사용하며, 2×2·8×8에 늘려 쓰지 않음.
- 보석·명품 매장은 고밀도 상업에만 사용. 2×2 AUTO는 별도 승인 대기.


## 교차로·홀수 차로 (2026-10-31)

- 같은 높이의 도로 중심선이 교차하면 연결 노드를 만들고 양쪽 경로를 분할한다.
  세 갈래는 T자, 네 갈래는 십자, 두 끝의 연결은 일반 연결이다.
- 새 도로의 끝이 기존 도로 폭에 닿으면 기존 중심선의 최근접 위치에 붙인다.
  판정 거리=(양쪽 전체 폭의 합)/2+0.05칸. 내부 경로 전체를 격자에 맞추지 않는다.
- 보도를 먼저 그리고 아스팔트를 나중에 그려 교차로를 가로지르는 보도를 없앤다.
  교차점 주변 반경(접속 도로 최대 폭×0.68)에서 중앙선·차로 구분선을 끊는다.
- 3차로=2+1, 5차로=3+2, 방향 반전 가능. 폭은 각각 3칸(12m), 5칸(20m).
  모든 폭은 보도 포함. 노란색은 양방향 중앙선, 흰 점선은 같은 방향 차로 경계다.
- 미리보기는 확정과 같은 끝점 연결을 보여주며 도로망·구획을 변경하지 않는다.
- 현재 연결 그래프는 도로 구간 수준이다. 좌회전 전용차로, 신호 제어, 차량 이동,
  차량 차로별 경로와 자유 높이 편집은 후속 작업이다. 일반도로와 고속도로는 아래 추가 규칙에 따라 분리한다.
- 도로망은 확정마다 전체 재계산하므로 대규모 도시의 성능을 검증했다고 주장하지 않는다.


## 일반 8차로·고속도로·나들목

- 사용자 확정: 모든 일반도로 제한속도 80km/h, 모든 고속도로 160km/h.
- 차로 수는 기존과 같이 왕복 합계. 일반 8차로=4+4, 폭 8칸(32m).
- 고속도로는 2·3·4·5차로(1+1·2+1·2+2·3+2), 폭 2·3·4·5칸.
  홀수 차로 방향 반전 유지. 고속도로 폭은 길어깨·방호벽 포함이며 보도 없음.
- 고속도로는 높이 계층 1, 일반도로는 0. 두 종류가 교차해도 연결하지 않음.
  고속도로와 나들목 램프는 건물 접근권·건설 구획을 제공하지 않음.
- 나들목 도구로 일반도로-고속도로 교차점을 누르면 다이아몬드형 램프 4개 생성.
  진입 2개·진출 2개, 각 1차로 일방통행, 폭 1.5칸. 램프 속도는 임시 80km/h.
- 자동 나들목은 교차각 60~120도와 양쪽으로 최소 14칸 이상의 완만한 구간 필요.
  도로 폭 합×1.5가 14보다 크면 그만큼 공간을 늘린다. 조밀한 드래그 샘플도 지원.
- 램프 부지의 건물·지도 경계·다른 도로 중심선 충돌·중복 설치는 전체 취소.
  기존 도로와 건물을 자동 철거하지 않음. 모델 미리보기와 확정은 같은 검증 사용.
- 구간별 속도와 자유 흐름 예상 시간(거리×4m/속도)을 저장하지만 차량 주행,
  신호·양보·합류 시뮬레이션·차로별 좌우회전은 아직 구현하지 않음.
- 높이는 연결 계층이다. 실제 3D 교량·기둥·지형 경사와 자유 고가 편집은 후속.


## 나들목 측면 연결 보정

- 램프의 보이는 끝은 일반도로와 고속도로의 바깥쪽 차도 가장자리에 둔다.
  양방향 중앙선·중앙분리대를 향해 램프를 끌고 들어가지 않는다.
- 시작·끝의 접선은 연결 대상 도로와 나란히 둔다. 방향 반전·홀수 차로에도 유지.
- `start_attachment`/`end_attachment`가 대상 도로, 중심선상의 논리 anchor,
  외측 position, side, carriageway, 높이를 구분해 저장한다.
- 도로 구간 그래프에 방향 있는 `ramp_port` 논리 연결을 별도로 둔다.
  이 논리 연결을 도로 면으로 그리지 않으며 중앙선에 평면 교차로를 만들지 않는다.
- 외측 합류부의 방호벽·길어깨만 열고 본선 중앙분리대와 차로 선은 유지한다.
- 외부 후보 조사 근거: docs/design/ROAD_SKILL_RESEARCH_KO.md.


## Road Generator 실제 도입 비교

- MIT Road Generator 0.9.5를 addons에 설치하고 편집기 플러그인을 활성화했다.
- 비교 장면의 오른쪽은 상류 플러그인이 실제 생성한 3D 메시다.
  기존 평면 도로와 같은 모델·축척으로 비교하며 입체 보기 전환을 지원한다.
- CITIES_DO 어댑터가 약 20m 측면 연결 구간과 높이(0~8m)를 설정한다.
- 기본 건설 화면의 2D 렌더러와 CityModel은 유지한다. 차량 경로 엔진 통합은 후속.
- 원본 커밋·라이선스·로컬 패치·검증은 docs/design/ROAD_GENERATOR_ADOPTION_KO.md 참조.


## 승인된 도로 색감과 합류부 후처리

- 플러그인 도로도 기존 짙은 회색 아스팔트와 차분한 녹색 지형을 유지한다.
- 램프가 생기는 바깥 가장자리에서 흰 실선을 끊고, 정상 점선·중앙선은 유지한다.
- 같은 높이에 포개지는 램프 시각 표면은 부모 도로 면과 중복되지 않게 절단한다.
  높이가 다른 입체교차를 평면 겹침만으로 삭제하지 않는다.
- 후처리 진입점: core/road_surface_finisher.gd, 색상: shaders/road_palette.gdshader.
- 기본 도로망·속도 제한과 비교 장면 적용 범위는 유지한다.


## 유선형 램프 연결 규칙

- 모든 새 나들목은 RampGeometry의 공통 5차 베지어 곡선을 사용한다.
- 양 끝의 방향은 부모 도로와 일치하고, 끝점 곡률은 0으로 직선에 이어진다.
- 폭은 양 끝에서 0부터 5차 smoothstep으로 늘고 줄며, 높이도 같은 완만한 함수로 변한다.
- 본선 경계에 닿는 바깥 윤곽은 C2 필렛으로 접합한다. 도로 옆에 고정 폭 끝단을 붙이지 않는다.
- 게임 모델·미리보기·실제 2D 렌더러·3D 어댑터가 같은 경로와 폭 정보를 사용한다.
- 3D 어댑터에서 별도의 20m 경로를 앞뒤에 추가하지 않는다. 연결 공간은 모델에서
  기존 반경에 5칸(20m)을 더해 검증하며, 공간이 부족하면 설치하지 않는다.
- 제한속도·기존 색상·합류부 흰 실선 개구·중복 면 절단은 유지한다.
- 실제 메시와 화면은 곡선의 샘플 근사다. 자유 높이 편집·차량 합류 시뮬레이션은 후속.


## 사용자 확정: 우측통행·램프 실선 금지

- 게임 전체는 우측통행이다. 월드 지도 (x, y)에서 진행 방향 d의 오른쪽은 (-d.y, d.x).
- 정방향 차로는 도로의 양(+) 오프셋 쪽, 역방향은 음(-) 오프셋 쪽이다.
  홀수 차로의 많은 방향 반전은 배분만 바꾸며 통행 방향을 좌측통행으로 뒤집지 않는다.
- 나들목 진입·진출 램프에는 **전체 구간에 흰색 실선을 표시하지 않는다**.
  합류 지점뿐 아니라 램프 양쪽 가장자리에도 적용한다. 방향 화살표는 유지할 수 있다.
- 모델, 실제 게임 2D 렌더러, 3D 재질과 플러그인이 생성한 차로 경로에 모두 적용한다.
- Road Generator 0.9.5의 LaneDir 명칭과 생성된 곡선 진행 방향이 반대인 부분이 있어,
  어댑터에서는 실제 생성 경로의 방향을 기준으로 변환한다. 이름만 보고 방향을 판단하지 않는다.
