# CITIES_DO 교도소

사용자 확정 규격: 8×8칸, 1칸=4m, 32×32m. 교도소 외관 시안을 제작한다.

회색 ㄷ자 수용동과 높은 담장, 감시탑 4개, 출입 통제동, 내부 운동장으로 경찰서와 시각적으로 구분한다. 도시 게임을 위한 축약 표현이며 실제 수용시설 설계가 아니다.

향후 도로변 육상 배치, 부지 충돌·지도 경계·유효 도로 접면과 도로망 연결을 검사한다. 수용 정원·인력·운영비·경찰시설과의 관계·교정 효과 등 게임 규칙은 아직 정하지 않았다. 현 단계에서 범죄율이나 수용 인원이 실제로 계산된다고 주장하지 않는다.

원본: assets/prison-study/. 디자인 승인 대기, 게임 미등록. 소형 경찰서 시안은 사용자가 승인했다.
