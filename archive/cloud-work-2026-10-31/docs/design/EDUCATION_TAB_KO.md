# CITIES_DO 교육시설

사용자 확정: 초등학교 4×4, 고등학교 4×4, 전문대 8×8, 대학교 8×8. 1칸=4m. 층수와 수용 인원은 아직 확정하지 않았다.

초등학교는 낮고 친근한 교사동과 놀이공간, 고등학교는 길쭉한 다층 교실동, 전문대는 실습동·강의동, 대학교는 본관·캠퍼스 광장 중심으로 외관을 구분한다. 작은 부지 안에 실제 캠퍼스 전체가 들어간다는 뜻이 아니라 게임용 축약 조형이다.

추후 공공시설 설치 구현에서 유효한 육상 부지와 도로 접면, 기존 건물·도로·지도 경계 충돌, 통학 경로를 검사해야 한다. 교육 단계·학생 수·수용 정원·운영비·교육 만족도·전문 기술 인력 효과 등 시뮬레이션은 별도 설계·밸런스 작업이다. 원형 영향 반경만으로 실제 통학이 가능하다고 처리하지 않는다.

## 최신 배치 수정

사용자가 단일 건물과 넓은 빈 땅으로 학교가 작게 보이고, 대학 건물 하나가 과대해 보인다고 지적했다. 초·고등학교는 4×4 부지 가장자리를 따라 교사동을 배치하고 내부에 작은 순환 트랙을 둔다. 전문대는 저층 4개 동, 대학교는 저층 5개 동과 보행로·광장으로 재구성한다. 트랙과 건물은 게임용 축약 표현이며 실제 시설 치수를 재현하지 않는다.
