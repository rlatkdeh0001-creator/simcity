# 교차로와 왕복 3·5차로

건설 화면에서 왕복 2·3·4·5차로를 선택한다. 도로를 그린 방향을 기준으로
3차로는 2+1, 5차로는 3+2이며 체크박스로 많은 차로 방향을 반전한다.
1칸=4m, 보도 포함 폭은 각각 8m·12m·16m·20m다.

같은 높이의 도로 중심선이 만나면 연결점을 만든다. 세 갈래는 T자,
네 갈래는 십자이며 두 도로 끝끼리 만나면 일반 연결이다.
자유 곡선·대각선도 폴리라인의 실제 교차 위치에서 연결되며
건물 격자에 맞추려고 교차점을 이동하지 않는다.
새 도로 끝이 기존 도로에 닿으면 중심선의 최근접 위치로 붙여 T자를 완성한다.
끝점 붙임 거리는 양쪽 폭 합의 절반+0.05칸이다.

모든 보도를 먼저, 모든 차도를 나중에 그려 교차로 내부를 아스팔트로 이어 준다.
교차점 주변 최대 도로 폭×0.68 반경에서 노란 중앙선과 흰 차로 구분선을 끊는다.
홀수 차로에는 방향 화살표를 표시한다. 끝 연결은 신호 교차로로 분류하지 않는다.

도로 확정 시 연결 그래프와 구획을 갱신한다. 미리보기에서는 같은 연결 위치를
보여주되 기존 도로망을 변경하지 않는다. 건물과 충돌하거나 끝점 붙임으로
경로가 사라지는 경우에는 확정하지 않는다.

현재 범위는 도로 구간 연결과 렌더링이다. 신호등·횡단보도·차량 이동·
회전별 차로 연결·자유 높이 편집은 아직 구현하지 않았다. 일반도로-고속도로 높이 분리와 나들목은
`HIGHWAYS_INTERCHANGE_KO.md`에 추가했다.
전체 도로망 재계산 방식이므로 1024×1024 대형 도시 성능은 미검증이다.
