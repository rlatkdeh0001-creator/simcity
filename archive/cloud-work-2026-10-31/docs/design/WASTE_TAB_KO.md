# CITIES_DO 쓰레기 처리 — 소각장과 재활용센터

사용자 최신 요청: 매립지는 제외하고 소각장에 이어 재활용센터를 제작한다. 현재 단계는 기존 시설들과 같은 외관 시안 제작이며 게임의 수거·소각 시뮬레이션은 아직 구현하지 않았다.

## 이번 시안

- 도로변 육상 시설. 부지는 시안용 8×8칸(32×32m) 제안이며 사용자 확정 크기가 아니다.
- 최신 사용자 수정 요청: 소각장처럼 보이는 네모난 형태와 하얀 분위기. 흰색 패널의 직사각 소각로동·반입동, 하역구 2개, 외부 정화설비, 단일 사각 배기탑·제어실·계근대로 다시 설계. 곡면 지붕 시안을 대체.
- 처리 후 재 반출은 밀폐 컨테이너로 표현. 매립지·야적 쓰레기 더미는 포함하지 않음.
- 소각장은 발전소와 다른 공공시설 분류. 이번 요청에 열병합 발전 기능을 추가하지 않음.

## 추후 구현할 동작

도로망과 연결된 건물에서 쓰레기를 수거해 소각장으로 운반한다. 소각장 수거 능력과 소각 처리 능력·반입 대기량을 분리한다. 처리 능력보다 유입량이 많거나 도로·시설이 정지하면 건물에 미수거 쓰레기 또는 소각장 반입 대기량이 증가한다. 초과량을 매립지로 자동 전환하거나 조용히 삭제하지 않는다.

유효한 육상 부지와 도로 접면, 전력·용수 공급, 운영비를 검사한다. 기존 건물·도로·지도 경계 충돌과 도로망 단절은 별도 검사한다. 주거 가까이에서는 소음·대기오염 영향이 나타나는 방향으로 설계하며 처리량·비용·영향 범위 숫자는 이후 밸런스 작업이다. 실제 교통·폐기물 모델이 없는 상태에서 수거차가 작동한다고 주장하지 않는다.

## 제작 상태

`assets/waste-study/incinerator/`에 편집 가능한 원본과 정면·뒷면 렌더, 규격을 저장. 사용자 디자인 승인 대기, 게임 미등록. 기존 수도 취수장 수정안은 사용자가 승인했다.

## 재활용센터 추가

8×8 도로변 육상 시설을 시안 규격으로 제안한다. 녹색 선별동과 종이·플라스틱·유리·금속 분류함, 컨베이어, 압축품 출하장을 표현하며 굴뚝과 소각로는 포함하지 않는다.

추후 재활용 가능한 쓰레기를 선별·회수하고 잔여 폐기물은 소각 처리 대상으로 보내는 방식으로 설계한다. 선별률·처리 용량·운영비·수거차 역할은 이후 밸런스 작업이며, 재활용센터가 모든 폐기물을 소멸시키는 기능으로 취급하지 않는다.

흰색 사각 소각장 외관은 사용자가 승인했고, 새 재활용센터는 승인 대기다. 두 시설 모두 게임 등록과 수거·처리 기능 구현은 대기 중이다.
