# 일반 8차로 · 고속도로 · 나들목

| 도로 | 왕복 배분 | 전체 폭 | 제한속도 |
|---|---|---|---|
| 일반 8차로 | 4+4 | 8칸 / 32m | 80km/h |
| 고속도로 2차로 | 1+1 | 2칸 / 8m | 160km/h |
| 고속도로 3차로 | 2+1 | 3칸 / 12m | 160km/h |
| 고속도로 4차로 | 2+2 | 4칸 / 16m | 160km/h |
| 고속도로 5차로 | 3+2 | 5칸 / 20m | 160km/h |
| 진출입 램프 | 일방 1차로 | 1.5칸 / 6m | 임시 80km/h |

기존 일반 2·3·4·5차로도 모두 80km/h다. 차로 수는 양방향 합계이며
홀수 차로는 많은 쪽을 반전할 수 있다. 일반도로 폭은 보도 포함,
고속도로 폭은 길어깨와 방호벽 포함이다. 고속도로·램프는 구획을 만들지 않는다.

## 게임에서 사용

1. 일반도로 또는 고속도로를 선택하고 차로 수를 고른 뒤 드래그한다.
2. 일반도로와 고속도로는 서로 다른 높이로 교차한다. 이때 두 도로망은 연결되지 않는다.
3. **나들목 · 교차 지점 클릭** 도구를 선택한다. 교차점에 마우스를 올리면
   램프 부지 미리보기가 보이며, 클릭하면 네 램프를 함께 설치한다.
4. 나들목은 진입 2개와 진출 2개의 일방 램프로 높이 계층 0과 1을 연결한다.

교차각 60~120도, 양쪽으로 최소 14칸(도로 폭 합×1.5가 더 크면 그 값)의
완만한 공간이 필요하다. 조밀한 드래그 경로도 길이를 합산해서 검사한다.
건물 충돌·경계 초과·다른 도로 중심선 충돌·중복 설치는 전체 취소한다.
메인 메뉴의 **8차로 · 고속도로 · 나들목 예시**에서 실제 공용 렌더러로 비교할 수 있다.

## 현재 구현 범위

- 도로와 구간 그래프에 `speed_limit_kmh`, 구간에 `free_flow_seconds` 저장.
- 같은 거리에서 160km/h의 자유 흐름 시간은 80km/h의 절반이다.
- 높이가 다른 중앙 교차점은 연결되지 않고 램프 끝에서 도로망이 이어진다.
- 교량은 평면에서 상부 도로와 그림자로 표시한다. 실제 3D 교각과 지형 경사는 후속이다.
- 차량 주행·합류·신호·차로별 회전 경로는 미구현이다. 예상 시간에 정체는 포함하지 않는다.
- 현재 전체 도로망 재계산 방식이므로 대형 도시 성능은 미검증이다.

## 측면 진출입 보정

램프가 양쪽 도로의 중앙까지 들어가던 형태를 외측 합류로 수정했다.
실제 램프 끝은 차도 가장자리, 도로망의 논리 anchor는 중심선상에 별도로 저장한다.
단방향 `ramp_port`는 도로망 연결에만 사용하며 도로 면으로 그리지 않는다.
본선 중앙분리대와 차선은 이어 두고 연결되는 쪽 방호벽만 짧게 연다.
