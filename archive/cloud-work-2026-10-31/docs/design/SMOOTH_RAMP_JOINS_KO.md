# 상·하단 램프의 공통 유선형 연결

상·하단 램프의 고정 폭 끝단과 미리보기 전용 연결 경로를 제거했다.
`core/ramp_geometry.gd`를 CityModel이 호출해 도로 방향·곡선·폭·높이 정보를 함께 생성한다.
게임의 실제 나들목 건설 도구와 미리보기, 2D 렌더러, Road Generator 어댑터가 이를 공유한다.

## 생성 규칙

- 5차 베지어의 양 끝 접선을 부모 도로 방향에 맞추고 끝점의 이차 미분을 0으로 둔다.
- 폭은 양 끝에서 0으로 수렴하며, 5차 smoothstep으로 확대·축소한다.
- 높이도 0~8m 사이를 같은 함수로 보간해 본선과 경사가 부드럽게 이어지게 한다.
- 부모 도로 바깥 경계와 만나는 윤곽에 C2 필렛을 적용해 급격한 접합각을 없앤다.
- 본선 보도와 길어깨가 입구를 막지 않도록 부드러운 개구부를 만든다.
- 기존 흰 실선 개구와 같은 높이 중복 면 절단, 색감, 일반 80·고속 160km/h는 유지한다.
- 본선 접합점은 이전보다 5칸(20m) 더 멀리 잡는다. 필요한 공간과 충돌을 확정 전에 검사한다.

변경 가능한 값은 growth_config.gd의 ramp_join_length, ramp_samples,
ramp_taper_fraction, ramp_fillet_width에 있다. 기본 샘플은 곡선당 48구간이다.
화면과 메시는 수학적 곡선의 유한 샘플 근사이며 차량 합류 시뮬레이션은 후속이다.

## 검증

`tests/test_smooth_ramps.gd`: 회전·방향 반전, 끝점 접선·곡률,
폭·경사 끝점 조건, 닫힌 윤곽의 삼각화, 미리보기/확정 일치,
실제 메인 화면 나들목 도구까지 31개 검사.
기존 10개 테스트도 유지한다.

- 게임 렌더러와 3D: docs/screenshots/road-smooth-joins.png
- 입체 보기: docs/screenshots/road-smooth-joins-isometric.png
- 실제 메인 화면 도구로 설치: docs/screenshots/road-smooth-in-game.png

기본 게임은 2D 렌더러를 사용하지만, **유선형 생성 규칙 자체는 실제 게임에도 적용**되어 있다.
