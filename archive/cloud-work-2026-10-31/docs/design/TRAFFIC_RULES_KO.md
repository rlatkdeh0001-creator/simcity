# 사용자 확정 도로 규칙

1. CITIES_DO는 **우측통행**이다.
2. 나들목 진입·진출 램프는 **전체 길이에 흰색 실선을 표시하지 않는다**.
   양쪽 가장자리와 연결부 모두 포함한다. 방향 화살표는 유지할 수 있다.
3. 본선의 정상 차선과 중앙선은 유지하고 램프 입구에서 경계선을 연다.
4. 기존 도로 색감과 유선형 연결을 유지한다. 일반도로 80km/h·고속도로 160km/h.

이 규칙은 AGENTS.md와 cities-do-construction 스킬에도 기록했다.

## 구현

- 지도 좌표의 오른쪽 벡터는 진행 방향 (dx,dy)에 대한 (-dy,dx)이다.
- 정방향 차로는 양의 오프셋, 역방향은 음의 오프셋에 배치한다.
- 홀수 차로의 방향 반전은 차로 개수만 교환하고 우측통행은 유지한다.
- 램프 진입/진출 구분과 포트의 forward/backward를 같은 방향 규칙으로 계산한다.
- 2D 렌더러는 램프의 실선 그리기를 금지하고 3D 램프 재질은 흰 페인트를 비활성화한다.
- Road Generator 0.9.5는 FORWARD 이름과 실제 곡선 진행이 반대인 부분이 있어,
  어댑터의 차로 열거형 변환을 실제 생성 경로에 맞춘다.

## 검증

- test_junctions.gd: 모든 차로 수와 방향 반전에서 화살표가 우측 차로에 있는지 확인.
- test_smooth_ramps.gd: 회전·방향 반전에도 양쪽 램프 포트가 우측 차로에 붙는지 확인.
- test_road_generator.gd: 실제 생성된 RoadLane의 위치와 진행 방향, 홀수 차로 배분,
  램프 전체 재질의 흰 페인트 비활성화 확인.
- 차량 운행·합류 시뮬레이션은 후속 범위다.
