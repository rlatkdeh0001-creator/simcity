# 의료시설 3종 — 사용자 검토용 시안

사용자 요청: 진료소·병원·대형병원, 대형병원에는 헬기.

- clinic: 4×4, 단층 박공지붕 진료소.
- hospital: 6×6, 높이가 다른 4층·3층 병동과 유리 연결 통로.
- large-hospital: 8×8, 넓은 2층 진료부와 뒤로 물러난 6층 병동, 옥상 헬기장·계단실과 구조 헬기 조형.

부지와 층수는 시안용 제안이다. 흰색·빨간색으로 의료시설 공통 색상을 유지하며 도로변 육상 공공시설을 의도한다. 구급차·헬기도 직접 만든 정지 조형이며 실제 진료·구급 출동·항공 이동 기능은 미구현이다. 모두 승인 대기, 게임 미등록이다.

각 폴더: building.blend 편집 원본(폰트 포함), building.png 정면, reverse-review.png 뒷면, metadata.json 규격. 대형병원 헬기는 동체·착륙 스키드·주로터·꼬리로터가 별도 오브젝트이지만 애니메이션은 포함하지 않았다.

Blender 4.3.2 CPU, 30도 정투영, 900×1100 투명 RGBA. 시설마다 프레이밍이 달라 화면 크기가 실제 부지 비율은 아니다. 외부 모델·텍스처 없이 직접 제작했으며 글꼴 조건은 FONT_LICENSE.txt 참조.

재생성: 저장소 루트에서 `blender --background --factory-startup --python-exit-code 1 --python assets/medical-study/build_clinic.py` 등 실행.

## 외형 재설계

사용자가 서로 비슷하고 밋밋하다고 지적해 흰 바탕·빨간 포인트로 변경하고 각 건물의 배치를 새로 구분했다. 의료 표식은 빨간 판 위의 흰 십자이며 색 변경 전 시안을 대체한다. 세 수정안 모두 승인 대기다.
