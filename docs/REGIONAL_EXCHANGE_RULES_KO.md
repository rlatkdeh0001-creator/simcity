# 게임 규칙: 네 이웃 마을과 외부 연결

2026-11-02 KST. 사용자 요청을 규칙으로 기록하고 연결 상태 판정 기반을 추가했다.

## 확정된 방향

- 화면에서 타일과 전체 도시 맵은 마름모 형태로 표현한다. 기존 내부 좌표계와
  실측 정사각 격자는 유지하며, 화면의 등각투영과 논리 좌표를 구분한다.
- 맵의 네 변 바깥에는 각각 **엄청 발전한 마을 1개, 발전한 마을 1개,
  우리와 비슷한 마을 2개**가 있다. 비슷한 두 마을도 서로 다른 교류 대상이다.
- 도로·철도·전선·지하철·상수도·하수도를 연결하면 그 마을과 자동으로 교류할 수 있다.
  이웃을 별도의 플레이어 도시로 직접 건설하는 기능을 요구한 것은 아니다.

## 이번에 적용한 해석과 임시 배치

각 기반 시설의 교류는 독립적으로 열린다고 해석했다. 도로를 연결하면 도로 교류가
가능하고, 전선 연결은 전력 교류를 연다. 여섯 시설 전체가 연결돼야 시작하는 조건은
추가하지 않았다. **이 독립 채널 해석과 아래 변 배치는 후속 사용자 수정이 가능하다.**

| 화면의 변 | 실제 맵 경계 | 임시 이웃 배치 |
|---|---|---|
| 오른쪽 위 | y=0 | 엄청 발전한 마을 |
| 오른쪽 아래 | x=맵 너비 | 발전한 마을 |
| 왼쪽 아래 | y=맵 높이 | 우리와 비슷한 마을 A |
| 왼쪽 위 | x=0 | 우리와 비슷한 마을 B |

사용자는 마을별 위치를 지정하지 않았으므로 오른쪽 위부터 시계 방향으로 나열했다.
설정은 `cities_do/maps/region_neighbors.json`에 분리했다. 마을 이름·발전 수준의
수치 기준·플레이어 성장에 따른 상대 수준 갱신은 아직 정하지 않았다.

## 연결 상태의 동작

각 이웃은 여섯 채널의 연결 여부와 연결 경로 수를 따로 가진다.
한 채널만 연결돼도 해당 마을의 `exchange_available`이 참이다.
이는 교류 가능 상태이며, 돈이나 물자가 이미 이동했다는 표시가 아니다.

- 기존 일반 도로와 고속도로를 도로 채널로 인식한다.
- 경로 끝점이 해당 변에 닿고 맵 내부에서 접근하면 외부 연결로 판정한다.
- 도로 폭이 경계에 가까워 보이기만 하거나, 경로 중간이 경계를 스치거나,
  경계선을 따라 지나가는 경우는 외부 단자로 세지 않는다.
- 모서리는 두 변 중 어느 마을인지 모호하므로 자동 연결하지 않는다. 전용 접속점
  선택 방식은 후속 규칙이다. 위 항목들은 이번 구현의 임시 판정 규칙이다.
- 같은 변에 여러 경로가 있으면 하나를 없애도 나머지 연결이 유지된다.
  마지막 연결이 없어지면 그 채널을 닫는다. 다른 시설 채널에는 영향을 주지 않는다.
- 반대편 두 변을 잇는 경로는 두 마을과 각각 연결된다. 이것만으로 두 이웃 사이의
  중계 무역이나 도시간 차량 통행까지 구현됐다는 뜻은 아니다.
- 상수도와 하수도는 별도 채널이다. 상수도만 연결해도 하수도가 자동 연결되지 않는다.

## 실제 구현 범위

`core/regional_exchange.gd`가 네 이웃·채널·경로 끝점을 판정하고,
`city_model.gd`의 `regional_exchange()`가 현재 도로/기반 시설을 읽어 결과를 반환한다.
연결 결과를 매번 현재 데이터에서 계산해 삭제 후 오래된 연결 표시가 남지 않게 했다.

도로는 기존 건설 데이터에서 자동 판정한다. 나머지 다섯 시설은
`add_external_link(kind, points, commit)` / `remove_external_link(id)`로 등록·검사할 수 있다.
미리보기는 상태를 바꾸지 않고, 유효하지 않은 경로와 모르는 시설은 거부한다.
이 API는 후속 시스템용 연결 기반이며 철도/전선/지하철/관로 건설 UI나 공급망을
완성한 것이 아니다. 새 UI·주변 마을 그래픽도 이번에는 추가하지 않았다.

## 아직 정하지 않은 교류 규칙

채널별 교류 대상·방향·요금·거래량·수용량·손실·수요, 수출입 조건, 발전 수준별
장단점은 후속 합의가 필요하다. 연결만으로 무료 전기/수도나 무제한 처리량을
부여하지 않았다. 실제 전력·상하수도 공급 여부와 건물 만족도도 바꾸지 않았다.
운행 가능한 연속 네트워크, 역·변전소·펌프 등의 필요 조건도 후속 규칙이다.
현재 판정은 경계 접속 가능 상태이며, 내부 소비자까지 서비스된다는 보장은 아니다.

## 검증

`tests/test_regional_exchange.gd`: 네 마을 구성, 빈 맵, 독립 채널, 미리보기 비변경,
복수 연결/삭제, 경계·코너·중간 접촉, 잘못된 경로, 비정사각 맵의 네 변,
고속도로·상수도/하수도 분리를 검사한다. 새 검사 **38/38**, 기존 검사를 포함한 **10종 모두 통과**했다. 로그와 기존 회귀 결과는
`docs/region-validation/`에 저장한다. 경제·유틸리티 실동작 검사로 확대하지 않는다.

```sh
godot --headless --path cities_do --script tests/test_regional_exchange.gd
```

기존 아카이브는 이전 커밋 스냅샷이다. 새 규칙과 코드의 최신본은 Git main을 사용한다.
