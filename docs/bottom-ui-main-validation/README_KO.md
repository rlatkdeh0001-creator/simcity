## 구현 범위

- 기본 실행 대상은 그대로 `res://main.tscn`. 이 장면이 공유 `bottom_ui.gd`를 사용한다.
  별도 검토 장면은 같은 HUD를 상속하며 `bottom_ui_preview.gd`에만 기존 34건물 예제를 둔다.
  **본게임은 기존 빈 100×100 맵·50,000 doth로 시작**한다. 캡처의 빈 땅은 정상 초기 상태이며
  검토용 도시를 플레이어 도시로 몰래 넣지 않았다.
- `main.gd`의 렌더·입력·기존 시뮬레이션 호출은 유지하고 도구 생성만 가상 메서드로 분리했다.
  본게임은 예전 상단/측면 도구 버튼을 생성하지 않는다. 기존 전시/실습 장면은 해당 도구를 유지한다.
- 가운데 12분류, 그 위 선택 도구, 최하단 실제 자금·건물 수·인구·날짜/시간,
  오른쪽 공통 불도저. 기존 자체 SVG를 보존하고 소방/경찰/교정 분류 SVG만 직접 작성했다.
  다른 게임의 아이콘·모델을 복사하지 않았다.
- 구획 3용도/해제·도로 2/4차로·전력·상하수관·시설 선택·통합 철거·정지/1×/3×를 연결했다.
  기존 건물 성장/수치 조절/초기화·전시·실습 진입도 하단으로 옮겼다.
  출력/용량/흐름 표시 등 기존 전력·수도 설정은 하단에서 여는 팝업에 **실제 기존 위젯**을 재사용한다.
  상세 설정을 열었다 닫아도 상시 측면 패널은 나타나지 않는다.
- 첫 시작에는 구획 격자를 숨긴다. 구획/도로에서만 표시하며 불도저에서는 숨긴다.
  탭 변경은 미완료 드래그를 취소하며 플레이어 카메라를 재설정하지 않는다.
  전시/실습 왕복에서 원래 도시·카메라를 보존한다.
- 좁은 창에는 도구 가로 스크롤과 포커스 추적을 쓴다. 시간/지도/접기 조작은 상태 텍스트
  스크롤 밖에 고정했다. 인구/날짜는 상태줄, 상세 취업·수요는 툴팁이다.
  설명 문구·반경/간격 튜토리얼·가짜 가격은 HUD에 추가하지 않았다.

## 소방·경찰·교정 슬롯

근거: [확정 슬롯 문서](../design/FIRE_POLICE_ASSET_SLOT_KO.md).
실제 데이터: `cities_do/assets/services/pending_slots.json`.

마무리 fetch에서 원격 `origin/main`의 **a4913a2**(원본 7종 회수)를 확인했다.
기획자가 갱신한 슬롯 근거 문서의 원본 매핑/확정 부지 크기는 보존한다.
이 1A 브랜치는 시작 기준 e8fff35를 유지하며 해당 원본 커밋을 병합·변환·등록하지 않는다.
따라서 pending_asset은 원본 파일 부재 주장이 아니라 **게임 연결/등록 대기** 상태다.

| 분류 키 | 슬롯 ID | 이름 |
|---|---|---|
| fire | fire.small | 소형소방서 |
| fire | fire.standard | 소방서 |
| fire | fire.regional | 광역소방서 |
| police | police.small | 파출소 |
| police | police.standard | 경찰서 |
| police | police.headquarters | 경찰본부 |
| corrections | police.prison | 교도소 |

전부 `status: pending_asset`, `asset: ""`. 비활성 버튼의 **이름만** 표시하며
모델/썸네일/가격/부지 치수는 없다. `services/catalog.json`은 바꾸지 않았다.
강제로 pressed 신호를 보내거나 활성화 함수를 직접 호출해도 건물·도로·자금·시계가 변하지 않는다.

파일 인수·검증·사용자 승인 뒤에는 슬롯의 `asset`에 실제 서비스 spec JSON의 `res://` 경로를
넣고 `status`를 `ready`로 바꾼다. spec은 기존 서비스와 같은 `name`, `model`, `width`, `depth`,
`height_m`를 가져야 하며 모델 리소스가 존재해야 한다. 이 조건을 만족하면 같은 하단 버튼이
실제 애셋 검사창을 연다. 잘못되거나 빈 경로는 활성화하지 않는다.
**이는 도시 건설 활성화가 아니다. 도시 배치·접도·정면·철거 연결은 1B에서 별도 구현한다.**

경제 CSV는 7슬롯의 건설비/유지비 행 14개의 상태 설명만 보강했다.
가격·유지비 수치/단위/승인 상태는 유지하며 런타임 과금·가격 표시에는 연결하지 않았다.
`docs/design/ECONOMY_LOOP_SPEC_KO.md`는 수정·커밋하지 않는다.
