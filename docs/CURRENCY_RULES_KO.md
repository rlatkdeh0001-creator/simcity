# 재화와 시작 자금

2026-11-02 KST 사용자 확정 규칙.

- 게임 재화 이름: **doth**.
- 한국어 발음: **도쓰**.
- 기본 난이도: 새 도시 시작 자금 **50,000 doth**.
- 표기 예: `50,000 doth`. 영문 이름은 소문자로 쓴다.

`cities_do/core/economy_config.gd`에 명칭·기본 난이도·시작 금액을 모았다.
도시 모델이 자금을 보관하고 건설 화면에서 현재 금액을 표시한다.
새 도시와 도시 초기화는 50,000 doth로 시작한다. 전시 화면에서 돌아오는 동작은
기존 도시 객체를 복원하므로 새 자금을 추가 지급하지 않는다.

건설비·유지비·세금·무역 가격·다른 난이도의 금액·부채·소수 단위·저장/불러오기는
이번 규칙으로 확정하지 않는다. 아직 가격/수입 계산이 없어 자동 지출·수입을
새로 넣지 않았다. 연결 가능 상태와 실제 경제 흐름은 계속 구분한다.

`tests/test_ui.gd`에서 시작 금액·화면 표기·현재 잔액 표시·초기화 금액을 검사한다.
새 자금 검사 4개와 기존 검사를 포함한 테스트 **10종 모두 통과**했다. 이번 실행 로그와 회귀 결과는 `docs/currency-validation/`에 보존한다.
기존 ZIP은 과거 스냅샷이며 최신 규칙·코드는 Git main을 따른다.
