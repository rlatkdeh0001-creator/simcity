# 주민·교육별 일자리·수요와 12일 달력

2026-11-03 KST 사용자 확정 내용을 적용했다. 시작 커밋 main 9ecfa41, 깨끗한 작업 트리였다.
이번 범위는 최소 주민/가구/취업/수요와 시간이다. 실제 통근 경로·학교 운영·물품 경제는 후속이다.

## 확정 시간 규칙

| 게임 시간 | 현실 시간(1배속) |
|---|---|
| 1분 | 2.5초 |
| 1시간 | 2분 30초 |
| 05~09시 출근 시간대 4시간 | 10분 |
| 1일=24시간 | 1시간 |
| 1년=12일 | 12시간 |

`core/city_clock.gd`는 현실초×24를 게임초로 환산한다. 1년 1일 00:00에 시작하고,
게임 12일이 완전히 지나면 2년 1일이 된다. 출근 구간은 05:00 이상 09:00 미만이다.
이전 코드에 확정된 출근시간 엔진은 없었으므로 이번 대화를 기준으로 기록했다.
실제 출근 차량이나 출발 시각 분산을 생성한 것은 아니다.
정지하면 시계·입주·신축·공급 계량이 멈추고 3배속에서는 현실 20분이 게임 하루다.
차량 물리 주행과 흐름 표시 애니메이션은 기존 표시 속도를 유지한다. 통근 도입 시
물리 이동시간과 도착 판정의 시간 계약을 별도로 검증해야 한다.

main의 기존 `advance_power(hours)`와 `advance_water(days)` 단위는 그대로 두고,
현실 delta→게임 시간 환산 경계에만 ×24를 적용했다. 이에 따라 같은 현실 한 시간에
전력은 24게임시간, 수도는 1게임일분을 계량한다. 기존 kWh/m³ 단가·잔액 이월·
동시 공급 규칙과 흐름 효과 분리는 바꾸지 않았다. 과거 문서의 ‘현실 1초=게임 1초’는
이번 규칙으로 대체한다. 제안서의 30일 비교월은 과거 비교 단위이며 실제 월/월 유지비
청구 기능은 없다. 12일년을 근거로 승인되지 않은 월 요금을 자동 환산·과금하지 않는다.

## 입주 → 상업·공업 수요 → 일자리

처음에는 주거 수요만 있다. 용도를 칠해도 인구가 0이면 상업·공업은 신축하지 않는다.
주거가 신축되면 빈 가구 정원에 외부 가구가 입주한다. 실제 people 수에서 상업·공업의
목표 사업장 수를 계산하고 기존 사업장을 빼서 신축 허가에 사용한다.
사업장에는 5학력별 slots/filled와 주민별 workplace_id/job_stage가 있다.
같은 학력의 빈 일자리를 먼저 찾고, 남는 시민은 ±1단계까지 지원한다.
유효한 기존 고용은 유지하며 한 시민은 동시에 한 일자리만 차지한다.

| 시민 단계 | 취업 가능한 요구 단계 |
|---|---|
| 미취학(0) | 0,1 |
| 초등교육(1) | 0,1,2 |
| 고등교육(2) | 1,2,3 |
| 전문대학(3) | 2,3,4 |
| 대학(4) | 3,4 |

미취학은 성인의 ‘교육 이수 없음’도 포함하는 학력이다. 나이가 어린 시민이 일할 수
있다는 뜻이 아니다. 취업 가능 연령과 학력은 별개이고 현재 임시 취업 하한은 18세다.
외부 입주 성인의 교육은 별도 seed RNG로 무작위 배정한다. 초기 가중치는 5단계 동일하며
사용자가 승인한 확정 분포가 아닌 조정 가능한 임시값이다. 외형/성장 난수와 분리했다.

지역 출생은 가구의 신생아를 age=0/education=0/local로 기록하고 부모의 학력을 상속하지 않는다.
게임년 단위로 나이가 증가한다. 나이만 찼다고 학력이 오르지 않으며,
`complete_education(person_id, stage)`에 실제 교육 이수가 기록되어야 한 단계 올라간다.
이 API는 미래 학교 엔진의 기록 진입점이며 현재 비활성 학교 메뉴가 실제 수업을 진행하는
것은 아니다. 전 단계 이수·최소 연령을 검사하고 단계 건너뛰기를 막았다.

건물을 선택하면 다섯 개 학력 링에 **충원/정원**이 표시된다. 0/0은 해당 학력 자리가 없는
구성이다. 현재 상업은 식품 소매를 가정한 기본 구성이고 공업은 작업장 기본 구성이다.
식품 상점의 미취학 정원도 실제 성인 고용에 사용할 수 있다. 브랜드/새 건물 모델은 추가하지 않았다.
사업장을 철거하면 고용을 해제한다. 집을 철거한 가구/주민은 삭제하지 않고 home_id=-1로
남겨 다른 빈집으로 재배정한다. 재배정 대기 가구가 있으면 신규 외부 가구 유입을 우선 중지한다.
성장 후 정원 축소 시 기존 가구를 강제 삭제하지 않으며 과밀 해소·이주 정책은 후속이다.

## 조정 가능한 임시 기본값과 단위

원본은 `cities_do/core/population_config.json`이며 경제 CSV에도 같은 값과 상태를 기록했다.
이는 최소 행동을 검증하는 **임시 적용값**이다. 새 시설 구매비·유지비를 승인 없이 과금하지 않는다.

| 설정 | 값·단위·근거 |
|---|---|
| households_per_2x2 | 2가구/기준 2×2 레벨1. 부지 면적배수×밀도레벨 배수; 실제 층수/실내 실측 정원 아님 |
| immigrant_adults_per_household | 2명/신규 외부 가구; 한 인구 틱에 최대 한 가구 입주 |
| household_max_members | 4명/가구; 기본 성인 2명에 자녀 여유 2명 |
| immigrant_education_weights | [1,1,1,1,1], 5단계 동일 가중치; 통계 인구분포로 해석하지 않음 |
| working_age_years | 18게임년; 취업 하한. 은퇴/사망은 미구현 |
| initial_housing_target | 초기 목표 8가구; 일자리 없이 출발하기 위한 부트스트랩 |
| residents_per_commercial | 8명당 상업 1개 목표; 소비·매출 계산을 대체하는 초기 인구 수요 지표 |
| residents_per_industrial | 12명당 공업 1개 목표; 생산·물품 흐름은 미구현 |
| commercial_jobs | 기준 상업 [3,2,1,1,0]명; 소매 인력은 저학력 중심, 사무/관리 포함 |
| industrial_jobs | 기준 공업 [2,2,2,1,1]명; 생산/기술/관리 5단계를 포함 |
| birth_probability_per_household_day | 0.01/가구/게임일. 가구 여유·성인 존재를 요구하는 임시 출생률 |
| education_min_ages | [0,12,18,20,22]게임년; 최소 연령일 뿐 자동 졸업 시점 아님 |

주거 목표=최대(초기 8가구, 올림(전체 일자리/4)), 주거 수요=목표-현재 가구-빈 정원이다.
사업장 목표=올림(실제 인구/용도별 인구 기준), 용도 수요=목표-기존 건물 수다. 음수는 0.
일자리당 1/4가구의 보수적인 추가 주거 목표는 빈 일자리가 무제한 이주를 유발하지 않도록
둔 임시 규칙이다. 임금·임대료·쇼핑 지출·물품 재고·이윤·세금 기반 균형은 아니다.
인구가 늘어도 수요가 0이면 그 용도는 신축하지 않는다. 기존 건물은 수요 감소로 철거하지 않는다.
주택 용도와 빈집만으로는 상업·공업 수요가 생기지 않고 **실제 입주민**을 기다린다.

인구/신축 틱은 기존 2초(배속 적용된 현실초)를 유지했다. 시간 환산으로 48게임초에 해당한다.
시민·가구·고용 갱신과 신축 검사를 순서대로 처리하고 한 프레임 최대 8틱, 남은 시간 보존이다.
시계/공급 계량은 입력 delta 전체를 반영하므로 큰 일회성 시간 점프에서는 인구 틱이
후속 프레임에서 따라잡는다. 일반 프레임 범위에서 고정틱의 프레임 독립성을 검사했다.
학교 정원/출석·통근/교통 수요·물류·공공 서비스·저장 파일·대규모 도시 성능은 이번에 구현하지 않았다.
전력/수도 소비량은 기존 건물별 시험 부하를 유지했으며 주민 수와 직접 연결하지 않았다.
