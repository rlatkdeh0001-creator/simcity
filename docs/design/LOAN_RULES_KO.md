# 대출·파산 규칙 (사용자 확정 2026-11-11, 구현 전)

상태: **확정(수치 임시값).** 구현은 4번 세금·예산 단계. 대출 게이지 UI는 구현 전에 시안 3개(M-008).

## 대출 게이지

- 세금처럼 **게이지(슬라이더)** 로 조절한다. 게이지 값 = 현재 빌린 총액.
- 게이지를 올리면 즉시 그만큼 빌려 자금 증가, 내리면 그만큼 상환(자금이 있을 때만).
- 고정 상환 기간 없음. 매달(게임 하루) **이자만** 자동 차감. 원금은 플레이어가 게이지로 상환.
- 이자·대출 잔액은 하단바 수지(±/월)에 반영.

## 한도

**한도 = 50,000 + 인구 × 20 doth** (인구 0 → 50,000, 1,000 → 70,000, 10,000 → 250,000, 100만 → 20,050,000)

- 인구가 줄어 한도 < 잔액이 되면, 넘친 금액의 **10%를 매달 강제 상환**.

## 이자

- **기본 연 10%.** 매달 = 잔액 × 연이율 / 12.
- 인구가 늘면 **한도의 앞 30%까지 우대 이자**:

| 인구 | 우대 구간(한도의 30%까지) | 그 이상 |
|---|---|---|
| 1,000 미만 | 10% | 10% |
| 1,000+ | 8% | 10% |
| 10,000+ | 6% | 10% |
| 100,000+ | 4% | 10% |

## 마이너스 자금·파산 (사용자 확정: 쉬운 게임이 아니다)

- 자금이 0 미만이면 **새 건설·도로·구획 외 유료 행동 불가**(민간 자동 신축·구획 지정은 원래 무료).
- **3달(게임 3일) 연속 마이너스 → 경고.**
- **6달(게임 6일) 연속 마이너스 → 파산(게임오버).**
- 자금이 0 이상으로 회복되면 연속 카운트 초기화.
- 경고·파산 표시 UI는 시안 먼저.

## 시작

- 시작 자금 50,000 유지. 시작 대출 0.
