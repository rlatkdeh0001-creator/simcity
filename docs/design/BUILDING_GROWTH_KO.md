# 건물 성장 규칙 — 단계·밀도·부지 (사용자 확정 2026-11-10)

상태: **결정 확정, 구현 전.** 근거: 회수 인계문 `docs/recovery/ORIGINAL_HANDOFF_KO.txt` 56~67행 + 이번 사용자 확정.
기존 `.agents/skills/cities-do-construction/references/RULES_KO.md`의 성장 크기 무작위 추첨(8=45%, 4=30%, 2=25%)은
아래 1번으로 **대체**된다(구현 시 RULES_KO도 갱신). 현재 코드는 수동 성장 버튼(+100)만 있다.

## 확정

1. **성장 단계**: 주거·상업·공업 각각 1~5단계. 1→3보다 3→5가 어렵다.
2. **밀도 등급 = 건물의 높이·용량(가구·일자리·생산량)** — 부지 크기가 아니다.
   - 1·2단계 = 소형, 3·4단계 = 중형, 5단계 = 대형(**최종 테크트리**).
   - 부지 크기(2×2/4×4)와 밀도 등급은 별개 축이다. 단 8×8은 대형 전용.
3. **최초 신축**: 2×2 또는 4×4, **1단계(소형)** (INITIAL_LOT_SIZE_KO.md).
4. **부지 확장**: 주거·상업·공업 일반 건물의 부지는 **2×2·4×4·8×8 세 가지뿐**이다(6×6은 소방서·경찰서·병원 등 직접 배치하는 서비스 건물에만 있음).
   **8×8은 대형(5단계, 최종 테크트리) 전용 특수 건물**이다(사용자 확정). 5단계에 도달하고 8×8 조건(공간·같은 용도·접도·충돌)이 되면 8×8로 짓는다(무작위 아님).
   1~4단계는 2×2·4×4만 사용(2×2 건물은 성장 시 4×4 조건이 되면 4×4로). 즉 '단계가 허용하는 가장 큰 부지 우선': 1~4단계 최대 4×4, 5단계 최대 8×8.
   안 되면 현재 크기 유지. 부지는 줄어들지 않는다. 8×8 건물은 항상 5단계(대형) 외관만 쓴다.
   기존 원칙 유지: 자동 합필로 남의 건물 철거 금지, 도로 접면 1.5m·정면 규칙, 도로 변경으로 건물 자동 이동 금지.
5. **경험치**: 입주자(주거)/종사자(상업·공업) **평균 행복도가 기준 이상일 때만** 쌓인다. 높은 행복도가 오래 유지되면 단계 상승.
   - 행복도 요소: 돈(가장 중요), 수요(행복도의 일부), 치안·교육·교통·소방·여가(서비스 엔진 이후). ECONOMY_LOOP_SPEC_KO.md의 행복도와 같은 값이다.
   - **수도 또는 전기 미공급 → 행복도 0, 경험치 정지.** 공급 회복 시 기존 단계·누적 경험치 보존.
6. **철거**: 플레이어가 강제 철거하면 성장 단계 1 하락(재건 시 반영 방식은 구현 시 제안).

## 미확인 (원본 수치 없음 — 구현 시 제안값으로, 사용자 승인 필요)

- 경험치 기준 행복도, 단계별 필요 경험치(3→5가 더 어렵게), 행복도 요소 가중치.
- 인계문의 "평균 만족도 5씩 깎자" 합의 — 적용 시점·대상 불명. 확정 전 구현하지 않는다.

## 애셋 매칭 — 부지 × 밀도 표의 빈칸

외관은 (용도, 부지 크기, 밀도 등급)으로 카탈로그에서 고른다. 현재 보유 애셋 기준 빈칸이 있다:

| 용도 | 2×2 | 4×4 | 8×8 |
|---|---|---|---|
| 주거 | 소형 2종 | 소형 2 · 중형(맨션 4층) 2 · 대형 2 | 대형 2 |
| 상업 | 소형 2(MART·자동차) | 소형 2 · 중형 2 · 대형 2 | 대형 2 |
| 공업 | 소형 2(식품·금속) | 중형 2 · 대형 2 | 대형 2 |

빈칸(예: 2×2 중형·대형, 8×8 소형·중형, 공업 4×4 소형)은 **추가 애셋 제작 또는 대체 규칙**(가까운 밀도 외관 사용 + 용량은 단계 기준) 결정 필요.
원본 metadata의 small/medium/large 표기가 사용자 정의(높이·용량)와 맞는지 30종 등록 결과로 확인한다.
