# 인터체인지 프리셋 (사용자 요청 2026-11-11, 기획 제안)

상태: **방향 확정(프리셋 애셋 + 도로 탭 안 인터체인지 탭), 종류 4개 제안 — 사용자 승인 대기.** UI 탭은 구현 전 시안 3개(M-008).

## 방향 (사용자)

- 인터체인지를 미리 만든 **샘플(프리셋) 애셋**으로 둔다.
- 하단 **도로** 카테고리를 누르면 **인터체인지 탭**이 있고, 유저가 프리셋을 골라 배치.
- 맵 시작 시 고속도로의 인터체인지 3개도 이 프리셋으로 생성(MAP_SIZE_KO.md).

## 종류 제안 (4개)

| 종류 | 연결 | 모양 | 크기 제안 | 쓰임 |
|---|---|---|---|---|
| 다이아몬드형 | 고속도로 × 일반도로 (4방향) | 마름모 램프 4개, 일반도로에 신호 교차로 2개 | 약 120×200m | 가장 작고 싸다. 초반·도심 진출입 |
| 트럼펫형 (T자) | 고속도로 → 일반도로 1개 (3방향) | 고리 램프 1개 + 직결 램프 | 약 200×200m | 고속도로 옆에서 도시로 빠지는 진입로. 시작 인터체인지 |
| 클로버형 | 고속도로 × 고속도로/대로 (4방향) | 고리 램프 4개 + 직결 램프 4개, 신호 없음 | 약 300×300m | 대형 교차, 넓은 땅 필요 |
| 로터리형 | 고속도로 × 일반도로 (4방향) | 고가 아래(또는 위) 원형 교차로 + 램프 4개 | 약 180×220m | 다이아몬드보다 처리량↑, 클로버보다 작음 |

(대체 후보: 터빈형/스택형 — 가장 크고 화려한 고속도로×고속도로 직결형. 지금은 클로버형으로 충분하다고 보고 제외.)

## 공통 규칙 (기존 나들목 규칙 준수)

- 고속도로 중앙이 아닌 **측면 진입·측면 진출**, 램프와 본선은 각지지 않은 **유선형**, 진출입 램프 전 구간 양쪽 가장자리 **흰 실선 없음**, 도로 면·애셋 겹침 없음.
- 차로 수 대응 — **확정(2026-11-11)**: 고정 메시가 아닌 **매개변수형 설계도**(본선 가장자리 기준 램프 곡선)로 저장하고, 차로 수(차로당 약 3.5m)에 맞춰 램프를 바깥으로 밀어 기존 도로 생성기로 생성. 프리셋 4종만 제작.
  - 기존 고속도로 위 배치: 스냅하면서 그 도로의 차로 수를 자동으로 읽음.
  - 맨땅 배치: **도로 탭에서 현재 선택된 고속도로 종류(차로 수)를 그대로 사용**. 인터체인지 탭에 차로 수 선택 버튼을 따로 두지 않음. 교차 일반도로도 같은 방식.
- 배치: 고속도로 위에 스냅, 회전 가능, 비용은 도로 단가 합산(임시).
