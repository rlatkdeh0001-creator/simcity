# 신축 부지 크기 변경 — 2×2 또는 4×4 (사용자 확정 2026-11-10)

상태: **결정 확정, 구현 전.** 현재 구현(ZONING_DEVELOPMENT_KO.md 19행, RULES_KO.md 21행)은 신축을 2×2만 짓는다.

## 확정

- 드래그 구획에 들어서는 **최초 신축은 2×2 또는 4×4 중 하나**로 짓는다(주거·상업·공업 공통). 이 신축은 **성장 1단계(소형)**다.
- 이후 성장 규칙은 docs/design/BUILDING_GROWTH_KO.md(단계 1~5, 조건 되면 8×8, 무작위 크기 추첨 대체)를 따른다.

## 구현 시 지킬 기존 규칙

- 4×4 신축은 4×4 전체가 **같은 용도로 지정**되어 있고, 한 도로 블록 안에 들어가며, 접도 1.5m·정면·충돌 공통 판정을 통과해야 한다.
  불가능하면 2×2로 내려간다(기존 '불가능하면 작은 크기' 원칙과 동일). 둘 다 불가능하면 짓지 않는다.
- 4×4 신축 외관은 해당 크기·용도 카탈로그에서 고른다. 주거 레벨1 4×4 = 소형 4×4 a/b(맨션은 레벨 2 이상 규칙 유지).
  상업·공업 4×4 모델(마트·카페·업무상가·벽돌상가 / 정밀기계·전자부품·화학·제약)은 30종 등록 후 연결.
- 4×4 1동은 2×2 4동 분량의 가구·일자리 정원을 갖는다(현재 인구 설정의 면적 비례) — 수요 계산이 한 번에 크게 뛰지 않는지 검사.
- 구획 무료·민간 신축 무료 유지.

## 미정 (사용자 결정 필요)

- 2×2와 4×4의 선택 확률. 제안: **2×2 60% / 4×4 40%** (초반 도시가 너무 빨리 커지지 않게, 성장 규칙의 8×8 선호와 균형).
