# CITIES_DO 시민(사람) 부위 애셋 — 시험 1명 제작 요청

도시 시뮬레이션 게임 CITIES_DO에 쓸 **시민(사람) 캐릭터**를 Blender 스크립트로 만들어 주세요.
이번에는 **시험용 성인 1명**만 만듭니다. 결과를 게임 화면 크기로 확인한 뒤 나머지 부위(머리 모양·옷 종류, 아이 체형)를 이어서 요청할 예정입니다.

## 1. 왜 부위로 나누는지

- 게임에서 사람은 수천 명이 동시에 보입니다. 사람마다 다른 모습이 필요하지만 그림 파일 수는 적어야 합니다.
- 그래서 사람을 **4개 층(부위)**으로 나누고, 게임에서 층을 겹쳐 그립니다. 색은 게임이 칠합니다(회색 그림에 색을 곱함).
  - 층 1 **몸**: 얼굴·목·손 (피부)
  - 층 2 **머리카락**
  - 층 3 **상의** (팔 포함, 손은 몸 층)
  - 층 4 **하의 + 신발**
- 나중에 머리카락 10종(남 5·여 5), 상의 5종+교복, 하의 4종으로 늘어나고, 어떤 상의든 어떤 하의·머리카락과 조합돼야 합니다. **이번 1명이 그 공통 틀(뼈대·크기·기준점)이 됩니다.**

## 2. 규격

- **키 1.75m**, 성인. 성별은 이번에는 중성적인 기본 체형 1개.
- **로우폴리**: 4개 층 합계 **1,500 삼각형 이하**. 화면에서 1~2cm 크기로 보이므로 얼굴 세부(눈·코·입·치아·손가락)는 만들지 않습니다. 손은 단순한 덩어리.
- **좌표계**: 기존 애셋과 동일 — 위쪽 +Z, 정면 -Y, **발바닥 중심이 원점(0,0,0)**. 단위 미터.
- **뼈대 1개**를 4개 층이 모두 공유(각 층 메시는 같은 뼈대에 스키닝). 뼈는 최소한으로: 골반·척추·머리·양팔(위·아래)·양다리(위·아래)·발 정도.
- **재질**: 층마다 재질 1개, **밝은 회색~흰색 단색**(색은 게임에서 칠함). 명암은 모델 형태로만. 텍스처 이미지 사용 안 함.
- 상의 아랫단은 하의 허리를 약간 덮게(층을 겹쳤을 때 틈이 안 보이게). 머리카락은 머리를 약간 감싸게.
- **외부 모델·외부 텍스처·생성형 이미지 금지.** Blender 파이썬 스크립트로 만든 지오메트리만.

## 3. 동작

- **걷기 1개**, **4프레임 루프**(1→2→3→4→1이 자연스럽게 이어지게). 제자리 걷기(원점에서 이동하지 않음).
- 서 있는 자세 1프레임(정지용).
- 4개 층이 같은 뼈대 동작을 따르므로 층별로 따로 움직이지 않습니다.

## 4. 렌더 (그림으로 내보내기)

- **층마다 따로** 렌더, 배경 투명 PNG.
- 방향 **5개**: 남(S)·남동(SE)·동(E)·북동(NE)·북(N). 나머지 3방향(SW·W·NW)은 게임에서 좌우를 뒤집어 씁니다.
- 프레임: 걷기 4 + 서기 1 = 5. → 층 4 × 방향 5 × 프레임 5 = **100장**.
- **카메라**: 기존 차량 8방향 렌더와 같은 설정 — **정사영(Orthographic), 위에서 30° 내려다봄**, 방향은 수평으로 45°씩 회전(S=0°, SE=45°, E=90°, NE=135°, N=180°).
- 축척: 사람 키 1.75m가 캔버스 안에 여유 있게 들어가도록 **1m = 약 40px**(캔버스 약 64×96px 권장). 최종 축척은 게임 화면 확인 후 맞출 수 있도록 렌더 스크립트에 값으로 빼 둘 것.
- **모든 층·방향·프레임이 같은 캔버스 크기, 같은 발 기준점 위치**여야 합니다(겹쳐 그릴 때 어긋나지 않게).
- 파일 이름: `<층>_<방향>_<프레임>.png` 예: `top_SE_2.png`, `body_N_idle.png`.

## 5. 납품물

- `.blend` 원본 1개(4개 층, 뼈대, 동작 포함) + 만든 파이썬 스크립트.
- 층별 PNG 100장.
- **확인용 시트 1장**: 4개 층을 겹치고 임의 색(피부·머리·상의·하의 각각)을 칠한 5방향 × 5프레임 그림.
- `spec.json`: 키, 삼각형 수(층별·합계), 캔버스 크기, 발 기준점 좌표, 방향·프레임 목록.

## 6. 확인 기준

- 4개 층을 겹쳤을 때 모든 방향·프레임에서 틈·어긋남이 없다.
- 색을 바꿔 칠해도 층 경계(허리·목·소매)가 자연스럽다.
- 걷기 4프레임이 반복될 때 튀지 않는다.
- 삼각형 1,500개 이하.
