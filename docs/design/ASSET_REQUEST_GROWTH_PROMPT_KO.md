# CITIES_DO 성장 건물 애셋 14종 제작 요청

도시 시뮬레이션 게임 CITIES_DO에 쓸 주거·상업·공업 건물 애셋 **14종**을 Blender 스크립트로 만들어 주세요.
이미 있는 건물들 사이에 비어 있는 부지 크기·밀도 조합을 채우는 작업입니다. 기존 애셋과 같은 시리즈처럼 보여야 합니다.

## 1. 게임 규칙 (왜 이 14종이 필요한지)

- 1칸 = 4m. 일반 건물 부지는 **2×2칸(8×8m), 4×4칸(16×16m), 8×8칸(32×32m)** 세 가지뿐입니다.
- **8×8은 대형(최종 단계) 전용 특수 건물**이고 이미 준비되어 있어 이번 요청에 없습니다.
- **2×2 대형은 좁은 땅(8×8m)에서 최종 단계까지 오른 건물**입니다. 바닥 면적을 늘리지 말고 **가늘고 높은 슬림 타워**로 표현해 주세요(세로 비율 강조, 상층부 세트백·옥탑 등으로 실루엣 차별화).
- 성장 단계 1·2=소형, 3·4=중형, 5=대형(최종 테크트리). 건물은 성장 단계에 따라 **밀도(높이·용량)**가 정해지고, 부지 크기와는 별개입니다.
  같은 2×2 부지라도 소형(낮은 집)부터 대형(좁고 높은 타워)까지 있을 수 있습니다.
- 밀도 기준:

| 밀도 | 주거 | 상업 | 공업 |
|---|---|---|---|
| 소형 | 1~3층 | 1~2층 동네 점포 | 단층 작업장, 낮은 지붕 |
| 중형 | 4~7층 | 3~6층 상가·업무 혼합 | 2~3층 공장, 굴뚝·탱크 소수 |
| 대형 | 8층 이상 | 7층 이상 백화점·오피스 | 대형 설비·굴뚝·탱크 다수 |

## 2. 공통 규격 (14종 모두)

- 부지 크기가 **정확히** 8×8m / 16×16m. 건물·주차·조경·담장 모두 부지 안에. 바닥판·지면 높이는 기존 애셋과 동일(일부 바닥판 z=-0.12m까지 허용).
- **정면은 Blender 기준 -Y 한 면, 위쪽은 +Z**(Godot으로 내보내면 +Z 정면 = 도로 쪽). 기존 애셋 좌표계 그대로. 출입구·간판·하역문·차량 진입구는 정면 중앙 쪽.
- 층고는 기존 시리즈와 동일(주거 약 3.05m). 층수는 아래 목록대로. 같은 부지의 다른 밀도는 높이·볼륨 차이가 확실히 보여야 함.
- 기존 시리즈 톤: 단순한 매스와 또렷한 실루엣, 저채도 팔레트, 사람(1.75m)·승용차(약 4.5m)와 비교해 축척이 자연스럽게.
- **외부 모델·외부 텍스처·생성형 이미지 금지.** Blender 스크립트 지오메트리와 시스템 폰트만 사용.
- 상업은 간판·쇼윈도로 주거와 확실히 구분. 보석·명품 표식은 대형 상업에만.
- 공업은 업종이 한눈에 보이게(사일로, 탱크, 굴뚝, 하역장, 컨베이어 등).

## 3. 산출물 (애셋마다)

폴더 `assets/{residential|commercial|industrial}-growth/{id}/`
- `{id}.blend` — 원본
- `building.png` — 900×1100px, 정사영 카메라, 앙각 30°, 투명 배경, 기존 애셋과 같은 구도
- `metadata.json`:
```json
{
  "id": "{id}", "name": "{한글 이름}", "zone": "residential|commercial|industrial",
  "category": "{예: medium_residential}", "density": "small|medium|large",

  "floors": 0, "footprint_status": "user-specified", "front": "-Y (Blender) / +Z (Godot)",
  "vertex_bounds_m": [[minX, minY, minZ], [maxX, maxY, maxZ]],
  "source": "original scripted Blender geometry; system font; no external models, textures or generation APIs"
}
```
