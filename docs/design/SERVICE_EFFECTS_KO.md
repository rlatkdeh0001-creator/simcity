# 서비스 효과 규칙 (사용자 확정 2026-11-11, 구현 전)

상태: **흐름 확정, 확률·수치 미정(구현 시 임시값 제안).** 행복도 점수는 HAPPINESS_KO.md(서비스 거리 단계).

## 교육

- 학력 5단계: 미취학(무학력) / 초등교육 / 고등교육 / 전문대학 / 대학. 취업은 자기 학력 ±1단계(기존 구현, POPULATION_TIME_KO.md).
- 시설마다 정원. 정원까지 가르친다.
- 기간(제안): 초등 6년, 고등 3년, 전문대 2년, 대학 4년 (게임 1년 = 현실 12시간).
- **고등학교 졸업 후 진학 선택**: 전문대 또는 대학. **대학은 전문대를 거치지 않는다** — 고등(2)에서 대학 졸업 시 바로 대학(4).
  - 현재 코드 `complete_education`은 한 단계씩만 올리므로 2→4 경로 추가 필요.
- **정원이 꽉 차 2년 이상 진학 못 하면 그 단계에서 학력 종료**(이후 진학 시도 없음).

## 소방

- 화재 확률(제안): 공업 > 상업 > 주거, 단계 높을수록↑, 소방 점수 낮을수록↑.
- 소방차 출동·진화. 제때 못 끄면 인접 건물로 번짐.
- **다 타면 파괴 버튼 없이 건물이 사라진다. 화재가 끝나면 그 자리에 다시 지어지며 성장 단계는 1부터.**
  (부지·용도 유지, 최초 신축 규칙 = 4×4 우선/2×2. 입주자·직원은 철거와 같이 집/직장 해제.)

## 경찰

- 범죄 원인(제안): 낮은 행복도, 실업, 낮은 경찰 점수.
- 범죄 피해: 해당 건물 행복도 하락, 상업은 매출 감소 → **세금도 덜 냄**(수익 감소).
- 경찰차 출동·체포 → 교도소에 자리가 있으면 수감, **없거나 꽉 차면 훈방**. 훈방자는 재범 확률↑.

## 의료·사망

- 질병 원인(제안): 나이, 오염, 보건 점수.
- 구급차가 환자를 병원으로 이송·치료. 치료 못 받으면 일정 기간 후 사망.
- **평균 수명 60세, 은퇴 55세**(취업 가능 18~55세). 기존 임시 취업 하한 18세 유지.
- 사망자는 운구차로 화장터에서 화장. 화장터가 없거나 꽉 차면 시신이 집에 남아 그 건물 행복도 크게 하락.

## 차량

소방차(있음), 경찰차(있음), 운구차(있음), 구급차·쓰레기차(사용자 제작 중, VEHICLE_REQUEST_GARBAGE_AMBULANCE_KO.md).
