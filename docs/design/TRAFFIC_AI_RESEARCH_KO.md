이 문서는 도입 전 조사 기록이다. 이후 선택한 스킬·Road Generator를 도입하고
기본 주행을 구현했다. [실제 적용·검증 결과](../TRAFFIC_AI_KO.md)를 확인한다.

확인일: 2026-11-01 (Asia/Seoul). GitHub 검색 후 고정 커밋의 실제 파일과
라이선스를 읽었다. 후보를 게임에 설치하거나 실행하지 않은 소스 검토 결과다.
출처 파일별 SHA-256은 `TRAFFIC_AI_SOURCES.json`에 보존한다.

## 게임에서 의미하는 기능

차량 모델은 외형과 바퀴 등의 피벗이다. 도로 주행 AI는 도로에서 방향이 있는
차선 경로를 만들고, 출발지→목적지 경로를 고르고, 차선을 따라 이동하며,
앞차·신호·합류 상황에 맞춰 감속/정지/진행하는 규칙이다.
생성형 AI API를 차량마다 호출하는 방식이 아니라 게임 내부의 경로 탐색·교통 로직이다.

현재 CITIES_DO는 2D 지도 모델/등각투영 렌더러와 2·4차로 도로 폴리라인을 사용한다.
차량은 GLB 전시와 8방향 PNG까지이며 차선 연결 그래프·주행 상태는 없다.
도로·건물 필지 격자를 차량 경로로 그대로 쓰면 안 된다. 특히 교차로가 보인다는
사실만으로 연결·통행 방향·회전 허용 정보가 생기지는 않는다.

### Road Generator의 정확한 범위

`plugin.cfg`에서 0.9.5를 확인했고 인계문의 `7cbefde…` 전체 SHA도 복원했다.
README는 Godot 4.4+를 대상으로 하므로 현재 4.6.3은 선언된 지원 범위 안이다.
실제 현재 게임에서의 호환성을 실행 검증한 것은 아니다.

`road_lane_agent.gd`는 스스로 차체를 이동시키는 완성 컨트롤러가 아니라 다음
위치를 계산하는 도우미다. `move_along_lane()`으로 경로를 따라 이동할 위치를
반환하고, 차선 간 연결을 따라 전환한다. 차체/바퀴 구동, 속도·앞차·신호 제어는
게임 측에서 연결해야 한다. `change_lane()`도 호출만으로 안전한 차선 변경이 완성되는 것은 아니다.

README에는 절차 생성 교차로의 RoadLane/edge curve 지원이 아직 예정이라고
명시돼 있다. 기존 조립식 교차로/램프와 모든 동적 교차로의 자동 주행을 구분해야 한다.
최근접 차선 탐색의 공간 인덱스도 TODO다. 대형 맵 성능 검증으로 해석하지 않는다.

### 2D 교통 예제의 정확한 범위

README와 `traffic_system.gd`, `vehicle_mover.gd`를 확인했다. README는 앞차 추종과
교차 교통 양보를 구현했다고 설명하며 실제 관련 코드가 있다. 신호등은 상태 목록에서
미완료다. 모든 충돌 방지·교착 방지·고속도로 합류가 검증됐다고 간주하지 않는다.
앞차 찾기가 차량마다 다른 차량을 순회하는 구조여서 대량 차량에 그대로 적용하면
비용이 커질 수 있다. 픽셀 단위 값도 현재 게임의 미터 단위로 변환해야 한다.

## 스킬 검색 결론

실제 SKILL.md가 있는 `game-ai`와 보조 `godot-gdscript`,
`godot-gdscript-headless-testing`을 찾았다. 단일 설치로 CITIES_DO의 교통 규칙을
모두 구현해 주는 교통 전용 스킬은 이번 조사에서 확인하지 못했다.
스킬은 작업 지침이고 애드온/시뮬레이터는 실행 코드이므로 구분한다.
모든 후보의 사용에 Claude 로그인이 요구되는 것은 아니다.

`RichtersFinger/DuckTraffic`도 MIT/Godot 4 프로젝트로 확인했으나 오리 무리의
속도·거리 상호작용 실험이 중심이라 도시의 차선망·교차로 구현 우선 후보에서 제외했다.
검색 결과의 이름만 보고 도로 교통 전용 구현으로 분류하지 않았다.

## 권장 연결 방식과 순서

현재의 2D 도시 모델을 유지하고 방향이 있는 차선 그래프와 교통 로직을 별도 계층으로
만드는 방향을 권한다. Road Generator의 경로 구조와 2D 교통 예제의 움직임/간격 유지
방식을 참고하고, 필요할 때 3D 도로 경로와 어댑터로 연결한다.
8방향 PNG 또는 3D 외형은 같은 차량 위치/진행 방향 상태를 표시하도록 한다.
주행을 위해 기존 도로 색상이나 건물 구획 규칙을 바꿀 필요는 없다.

1. 2차로 직선·곡선·폐회로에서 우측통행과 속도/방향 검증.
2. 앞차 차체 길이를 반영한 간격 유지, 가감속·정지·재출발 검증.
3. 목적지 경로 탐색과 교차로 회전 연결, 신호·우선권·교착 방지 검증.
4. 다차로 안전한 차선 변경, 고속도로 진출입·합류와 트레일러 회전 검증.
5. 도로 추가/삭제 시 경로 갱신, 차량 수 증가에 따른 공간 인덱스·프레임 성능 검증.

차량 종류별 목적(통근·물류·버스 노선·택시 호출)은 이 이동 계층 위에 얹는 후속 규칙이다.
이번 요청에서는 검색과 적합성 조사까지만 했으며 게임 주행 코드를 적용하지 않았다.
