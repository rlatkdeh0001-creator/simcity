# CITIES_DO 대중교통 애셋 제작 요청 (2026-11-16)

담당: cities-asset · 지시/1차 검수: cities-claude · 최종 검수: 사용자
브랜치: `assets/transit-20261116` — **별도 worktree `D:/project/simcity-transit`에서 작업** (`git worktree add D:/project/simcity-transit -b assets/transit-20261116 perf/render-sim-cadence`). cities-gpt가 `D:/project/simcity`에서 작업 중이므로 그 폴더에서 브랜치를 바꾸지 않는다.

대중교통 시스템(노선·승하차·철도 배치)은 아직 게임 코드에 없다. 이번 작업은 **애셋 원본 + 렌더 + 카탈로그 등록(검사 창 표시용)**까지이며, 지도 배치·운행 로직은 이후 cities-gpt가 한다.
크기·칸 수는 기획 제안값이다(사용자 최종 검수 때 조정 가능). 제안값으로 진행하되, 만들어 보니 명백히 어색하면 근거와 함께 보고하고 조정한다.

## 0. 공통 규격

- **1칸 = 4m**, 1 Blender 단위 = 1m, 실측 축척. AGENTS.md "Shared asset scale", `docs/ASSET_SCALE_REVIEW_KO.md` 먼저 읽기.
- 건물·시설: 기존 시설(`assets/facilities/*/`, `assets/service-facilities/`)과 같은 방식 — `facility.blend` + `spec.json`(id, name, kind, width, depth, metres, storeys, capacity, model, preview, source, render) + GLB + 미리보기 PNG(기존과 같은 카메라 고도 30°, 투명 배경). 정면(도로 쪽)은 기존 시설과 같은 방향 규칙.
- 차량: 기존 `assets/vehicle-fleet/*/` 와 같은 방식 — `vehicle.blend` + `spec.json` + GLB + 8방향 스프라이트(000~315) 기존 파이프라인(`tools/build_vehicle_fleet.py` 등). 좌표계 전방 −Y / 왼쪽 +X / 위 +Z, 바닥면 z=0. 열차는 **레일 윗면 = z=0**.
- 톤: 기존 시리즈와 같은 저채도 팔레트, 단순한 매스·또렷한 실루엣. 표식(버스·택시·지하철 기호)만 선명하게. 실제 회사 로고·실존 디자인 복제 금지.
- **외부 모델·외부 텍스처·생성형 이미지·가짜 PNG 금지.** 스크립트 지오메트리 + 시스템 폰트만. 기존 애셋 원본은 수정하지 않는다.
- 삼각형 목표: 차량 2,000~5,000, 정류장류 1,500~4,000, 역 건물 6,000~15,000.

### 열차 길이 (게임용 축소, 사용자 확정 2026-11-16)
- 실제 열차는 역 8칸(32m)에 안 들어가므로 길이만 축소. 폭·높이는 실측 유지. 기관차 10m + 객차 11m × 2 = 32m = 8칸.

### 열차 연결 규칙 (6~9 공통)
- 표의 길이 = 차체 길이. 연결기 앵커 = 차체 끝·z = 1.0m, 접촉 헤드는 각 끝 0.5m 돌출(전체 길이 +1m). spec.json에 body_length_m / overall_length_m 구분 기록.
- 궤간 1.435m, 바퀴는 레일 위(z=0).
- 컨테이너는 평판차와 **별도 모델**. 평판차 `spec.json`에 컨테이너 얹는 기준점(적재면 중심 좌표 x, y, z=1.2) 기록. 확인 캡처는 평판차 + 컨테이너를 얹은 상태 1장.

### 도로 부착형(3·4·5) 공통
- 부지가 아니라 **도로 가장자리에 붙는** 시설. spec.json에 `"placement": "road_edge"`, 도로와 맞닿는 변(`road_side`), 보도 안 차지 폭(m) 기록.
- 원점은 도로와 맞닿는 변의 중앙, 도로 방향 = 길이 방향.
