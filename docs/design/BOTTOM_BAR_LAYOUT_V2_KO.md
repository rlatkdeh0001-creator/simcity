## 카테고리 변경

- **교정 → 경찰로 합침.** 카테고리 12개 → 11개. 교도소(police.prison)는 경찰 탭 안의 슬롯으로 이동.
- **상하수도 → 수도** (2글자 통일). 카테고리 라벨만 변경, 시스템/키 이름 변경 여부는 구현 시 판단(내부 키는 유지 권장).

## 하단 상태줄 배치 (왼쪽 → 중앙)

```
[ 날짜 ] [ 행복도 ] [ R C I 수요 막대 ] ......  [ 도시이름 CITIESDO ]  ......
[⏸][ ×배속 ]                          [ 인구 ] [ 자금(크게) +수지/월 ]
```

| 위치 | 요소 | 세부 |
|---|---|---|
| 맨 왼쪽 | **날짜** | 기존 게임 날짜/시간 |
| 날짜 좌측 아래 | **일시정지** 버튼 | |
| 날짜 우측 아래 | **배속** 버튼 | 기존 1×/3× |
| 날짜 오른쪽 | **도시 평균 행복도** | 3번 단계 A 전까지는 데이터 없음 → 가짜 수치 금지, 빈 표시(—) |
| 행복도 오른쪽 | **RCI 수요 막대** | 주거·상업·공업 3막대. 기존 population 수요 값 사용(지금 구현 가능) |
| **정중앙** | **도시 이름 + 자금** | 자금은 다른 상태값보다 **크게** |
| 자금 옆 | **수지** | `+N` 초록 / `-N` 빨강, 자금보다 조금 작은 글씨. 기간 단위(일/게임월)는 구현 시 제안. 3번 이전엔 실제 수입·지출이 없으므로 0 또는 숨김(가짜 값 금지) |

## 확정 사항 (작업 시 그대로 적용)

- 도시 이름: **확정 — 기본값 `CITIESDO`, 이름을 누르면 바로 편집 가능**(클릭 → 입력 → Enter 확정/Esc 취소).
  빈 이름은 거부하고 이전 이름 유지. 저장/불러오기가 생기면 도시 이름도 저장 대상.
- 수지 기간 단위: **확정 — 한 달 단위.** 시간 규칙상 게임 1일 = 1개월(현실 1시간, 1년=12일)이므로
  "게임 1일(=1개월) 수입−지출"을 `+N/월` 형태로 표시. 주의: PRICE/CAPACITY 문서의 '게임월=30게임일'은
  옛 기준이라 현 시간 규칙과 불일치 — 4번(세금·예산)에서 월 유지비를 실제 청구하기 전에 '1게임일=1회'로 재정렬 필요.
- 건물 수: **확정 — 상태줄에서 제거.**
- 인구: **확정 — 중앙 자금의 바로 왼쪽**에 표시(실제 인구 값; 기존 취업·수요 상세 툴팁은 유지 가능).
- 카테고리 줄과 불도저 위치는 1A 그대로 유지(사용자가 별도 변경 지시 없음)

## 유지 규칙

HUD에 설명 문구 금지(AGENTS UI 규칙). 실제 값과 짧은 피드백만. 다른 게임 아이콘 복사 금지.

참고 문서에서 가져온 추가 조건:
- 자금 표기는 `50,000 doth` 형식, 영문 소문자 doth (CURRENCY_RULES_KO.md).
- 하단 anchor+container 배치, 고정 픽셀 좌표 금지, 1080p 기준 PC 글자 최소 18px, 1280×820·960×640에서 깨짐 없음,
  키보드 포커스·이웃 지정, HUD는 매 프레임 조회가 아니라 값 변경 이벤트로 갱신 (game-ui-ux 스킬).
- 선택 상태는 색만으로 구분하지 않음(파란 배경/밑줄+글자). 기존 팔레트 #142b37 / #38515e / #edf4f5 / #36b7ff 유지 (bottom-ui DESIGN_KO.md).
- 수지 초록/빨강도 색만으로 구분하지 않도록 `+`/`−` 부호를 반드시 함께 표시.
- '구획'처럼 라벨만 바꾸고 내부 키는 호환 유지 전례 있음 → '수도' 라벨, 내부 키 water 유지.
- 1A의 격자 표시·통합 불도저 규칙(DEMOLITION_ZONING_KO.md)은 변경하지 않는다.
