# 쓰레기 규칙 (사용자 확정 2026-11-11, 구현 전)

상태: **방향 확정, 수치·수거 방식 미정.** 1B에서는 소각장·재활용센터를 배치·비용·철거만 하고 효과 없음.

## 확정

- **모든 건물(주거·상업·공업)은 부지 크기에 비례해 쓰레기를 계속 생산**한다. 단계(밀도)가 아니라 부지 크기 기준.
- 각 건물에는 쓰레기 보관 한도가 있고, **꽉 차면 그 건물 행복도가 떨어진다** (BUILDING_GROWTH의 단계 상승 기준 행복도에 직접 영향).
- 쓰레기는 소각장·재활용센터가 수거·처리해 비운다.

## 제안 (승인 전 임시값, 테스트 후 조정)

| 항목 | 제안 |
|---|---|
| 생산량 | 2×2칸당 게임 하루 1단위 → 2×2=1, 4×4=4, 8×8=16 단위/일 (부지 면적 비례) |
| 보관 한도 | 생산량의 2일분 (2×2=2, 4×4=8, 8×8=32) |
| 꽉 참 패널티 | 꽉 찬 동안 행복도 −10 (비우면 즉시 해제) |
| 서비스 건물 | 소방·경찰·병원·학교 등도 같은 규칙(부지 크기 비례) |

## 미정 (사용자 결정 필요)

1. ~~수거 방식~~ → **확정: 쓰레기차가 도로로 다니며 수거**(교통 반영). 쓰레기차 전용 애셋 없음 — 신규 제작 필요(ambulance와 함께 차량 애셋 요청 대상).
2. ~~처리량·발전~~ → **확정(임시값)**: 소각장 8×8 하루 400단위, 처리량 비례 발전 최대 1,500kW. 재활용센터 8×8 하루 250단위.
   - 쓰레기차: 소각장 8대, 재활용센터 6대(데이터 값, 차고 그림과 달라도 됨).
   - **재활용센터 산출(단계적)**: 쓰레기 2단위 → **재활용 자재** 1단위(하루 최대 125).
     - 1차(지금): 자재는 이웃 마을 판매만 — 1단위 3 doth(하루 최대 375 doth). 판매 수입만 있는 C안.
     - 2차(공업 원자재 도입 시): docs/design/RAW_MATERIALS_KO.md — 원료 7종, 재활용 자재는 공업 재료(목재·철·석유)만 대체, 식료품·연료(석탄·석유발전·우라늄)는 대체 불가.
3. ~~초반 처리~~ → **확정**: 이웃 마을 반출 허용, 1단위 5 doth, 쓰레기차가 맵 가장자리 도로로 운반.
