# 학력·임금·생산 균형 (사용자 확정 2026-11-11, 수치 임시)

상태: **원칙 확정, 수치 제안.** ECONOMY_LOOP_SPEC_KO.md(임금 30~100 doth 임시)와 RAW_MATERIALS_KO.md를 잇는 규칙.

## 원칙 (사용자)

- 고학력일수록 임금이 높고 세금을 많이 낸다.
- 하지만 **모든 시민이 고학력이면 도시가 망한다.** 무학력·저학력 일자리가 필수 식료품 생산을 담당하기 때문.

## 구현 규칙 (제안)

1. **임금(일급 = 게임 하루)**: 미취학 30 / 초등 45 / 고등 60 / 전문대 80 / 대학 100 doth. 세금은 임금에 비례(세율은 4번 단계).
2. **업종별 일자리 학력 구성**: 식품가공·제빵·곡물 사일로·물류는 미취학·초등 위주, 금속·자동차는 초등·고등, 전자·정밀은 고등·전문대, 화학·제약·오피스는 전문대·대학 위주.
3. **취업은 학력 ±1만**(기존 구현) → 대학 졸업자는 미취학·초등 일자리에 가지 않는다.
4. **생산량 = 채워진 일자리 비율에 비례.** 저학력 일자리가 비면 식품 공장 생산이 줄어 식량 부족 → 수입(비용) 증가 → 수입도 모자라면 생필품 부족으로 행복도 하락(최대 −15).
5. 결과: 플레이어는 학교 정원(교육 투자)과 저학력 이주민 유입 사이 균형을 잡아야 한다. 고학력 도시는 세수는 많지만 식량을 비싸게 수입하게 된다.

## 미정

- 업종별 학력 구성 정확한 비율, 수입 식량 단가(현재 경제 명세 도매가 4 doth 기준 수입 할증).

## 수요식 — 일자리 기준 (사용자 확정 2026-11-16)

- 필요 일자리 = 일하는 나이(18세 이상) 주민 × 1.05(빈자리 여유 5%). 상업 60 : 공업 40으로 나눈다.
- 상업 수요 = (상업 몫 − 현재 상업 일자리) ÷ 신축 1채 일자리 수. 공업도 같은 방식.
- 주거 수요 = 빈 일자리가 실업자보다 많을 때 증가(일자리가 있으니 이주).
- 기존 residents_per_commercial 8 / residents_per_industrial 12(임시 밸런스)는 대체.

## 이웃 도시 통근 (사용자 확정 2026-11-16)

- 이웃 도시는 실시간 계산하지 않는다. **게임 하루 1회** 이웃별 숨은 스탯을 갱신: 인구, 노동 인구·실업자, 일자리, 전력·수도·쓰레기 처리량(생산/소비). 화면에 직접 보이지 않는 스탯(NEIGHBOR_TOWNS_KO 성장·건전도와 같은 갱신 시점).
- 통근은 양방향: 이웃 실업자가 우리 빈 일자리로 출근(유입), 우리 실업자가 이웃 일자리로 출근(유출).
- 통로는 **연결된 도로·기차·지하철만**(REGIONAL_EXCHANGE_RULES 연결 규칙). 연결이 없으면 통근 0.
- 수요식 반영: 이웃 통근 유입분은 우리 일자리를 채우므로 그만큼 주거 수요를 낮추고, 유출분은 우리 실업자에서 빼 준다.
- 통근자는 우리 도시 경계에서 등장해 직장까지 이동하고 퇴근 때 경계로 나간다(도로=차량, 기차·지하철=역에서 하차 후 보행). 표시 단계 비율(VEHICLE_SPAWN_DESPAWN)을 그대로 따른다.
- **수단 선택 (사용자 확정 2026-11-16):** 통근자는 **기차·지하철을 우선** 이용하고, 이웃과 기차·지하철 연결이 없거나 직장 근처까지 역으로 갈 수 없으면 **자동차(도로)**로 이동한다. 통로별 인원 상한은 두지 않는다(혼잡은 실제 교통·열차 수송으로 생김).

## 일자리 배정과 출근 (사용자 확정 2026-11-16)

- 배정 순서: **① 자기 학력 ±1단계인 일자리 → ② 그중 집에서 가장 가까운 곳**(도로 거리). 저학력 일자리(농장·광산·공장)는 외곽에 놓이므로 외곽에 사는 저학력 주민은 통근이 짧아 타격이 작다.
- 출근 시간대는 기존 규칙 그대로 **05:00~09:00**(1배속 현실 10분, POPULATION_TIME_KO.md).
- 체증으로 제시각에 출근하지 못하면 그날 수익이 줄어든다(HAPPINESS_KO.md '이사와 빈 건물').
- **지각 기준 (사용자 확정 2026-11-16)**: 출발 시각(05:00~09:00 사이)부터 **게임 4시간(1배속 현실 10분) 안에 직장에 도착하지 못하면 지각**. 예: 05시 출발 → 09시까지, 09시 출발 → 13시까지. 일급 = 기본 일급 × (실제 근무 시간 ÷ 정규 근무 시간)(제안).

## 2026-11-17 아침 확정 (사용자)

- **임금**: 학력 단계별 일급은 TAX_BUDGET_KO.md 값(30 / 40 / 55 / 75 / 100 D)을 쓴다. 이 문서의 이전 제안(30/45/60/80/100)은 폐기.
- **직장 재배정**: 이미 취업한 시민은 직장을 유지한다. **이사했을 때(또는 실직했을 때)만** 학력 ±1 → 도로 거리 최단 규칙으로 다시 구한다. 거리가 같으면 고정된 안정 순서.
- **기차·지하철 통근**: 역 배치·열차 운행 기능을 추가한다(대중교통 단계). 그전까지는 자동차로 대체.
- **프레임**: 시뮬레이션 callback 최대 0.18ms(30만)로 현재는 충분. 전체 프레임(최대 35.8ms) 최적화는 보류.
