# 1차 원료 규칙 (사용자 확정 2026-11-11, 2026-11-12 세분화, 구현 전)

> **2026-11-12 변경(사용자 확정, C안)**: 식료품 원자재를 **곡물 / 축산물 / 채소·과일 / 수산물** 4종으로 나눈다 → 원료 총 **10종**. 물자 6종은 그대로(A). 물자 세분화(20~30종)는 1.0 이후 검토.
> - 곡물: 제빵·곡물 사일로 → 식량. 축산물·채소·과일·수산물: 식품가공 → 식량. 수산물은 이후 어업(바다)과 연결.
> - 재활용 자재 대체 불가 규칙은 식료품 원자재 4종 모두에 적용.
> - 이웃 마을별 특산 원자재를 다르게 배정(NEIGHBOR_TOWNS_KO.md, 값은 미정).
> - **물자 현황 바(보기 전용)**: 품목별 가로 막대에 시내 생산 / 수입 / 소비, 부족분 빨강, 주요 공급 이웃과 의존도 %(60% 초과 경고색). 플레이어 조작 불가. UI는 구현 전 시안 3개(M-008).


상태: **종류·용도 확정, 수치 미정.** 경제 순환 단계 B(연료) 이후 공업 원료 단계에서 구현. 그 전까지 재활용 자재는 판매만(WASTE_RULES_KO.md 1차).

## 원료 7종

| 원료 | 쓰는 곳 | 공급 |
|---|---|---|
| 식료품 원자재 | 식품가공·제빵·곡물 사일로 → 식량 | 수입(나중에 농업) |
| 목재 | 정밀기계 → 사치품 일부 | 수입 |
| 철 | 금속가공, 정밀기계, 자동차 조립, 전자부품 | 수입 |
| 석유 | 화학·제약 → 의료품, 전자부품 → 가전 / **석유발전소 연료** | 수입 |
| 석탄 | **석탄발전소 연료 전용** (공업에 쓰지 않음) | 수입 |
| 우라늄 | 원자력발전소 연료 전용 | 수입 |
| 재활용 자재 | 아래 대체 규칙 | 재활용센터(쓰레기 2→1) |

물류창고는 원료 없음(보관·운송).

## 재활용 자재 대체 규칙

- **공업 재료로 쓰이는 목재·철·석유만** 1:1 대체한다.
- **식료품 원자재는 대체 불가.**
- **연료는 대체 불가**: 석탄(석탄발전소), 석유(석유발전소), 우라늄(원자력). 같은 석유라도 발전 연료 용도는 대체 안 됨.
- 공장은 재활용 자재를 먼저 쓰고, 부족분은 원래 원료를 수입. 남은 재활용 자재는 이웃 판매(1단위 3 doth).

## 미정

- 원료별 수입 단가, 공장별 원료 소비량·생산량, 재활용 자재 우선 사용 여부(가격 비교로 할지).

## 물자·생산 사슬 (사용자 확정 2026-11-12, 수치 임시)

물자(공업 생산품)는 지금 공업 14종에 맞춰 정한다. 석탄·석유는 원자재로만 다룬다.

| 물자 | 만드는 곳 | 쓰는 곳 |
|---|---|---|
| 식량 | 식품가공, 제빵, 곡물 사일로 | 시민 |
| 의료품 | 제약 | 병원, 시민 |
| 가전 | 전자부품 2종 | 시민 |
| 사치품 | 정밀기계 | 고소득 시민 |
| 자동차 | 자동차 조립 | 상업 자동차 판매점(small-2x2-auto-02 등)이 판매 → 시민, 남으면 수출 |
| 금속 부품 (중간재) | 금속가공 2종 | 전자부품·정밀기계·자동차 공장 재료 |
| **비료** (버프재) | 화학 3종 | 농장(곡물·채소·축산) |
| **폭발물** (버프재) | 화학 3종 | 석탄 광산, 석유 시추 |

- **버프재 규칙(사용자)**: 없어도 1차 산업은 돌아가지만, 공급되면 효율이 크게 오른다(제안: 생산 +50%). 남는 비료·폭발물은 이웃에 판매.
- 1차 산업(농장, 광산, 유전) 건물은 **곧 추가 예정**(자원 지형 표시와 연결, MAP_SIZE_KO.md). 그 전까지 버프재는 판매만.
- 화학은 생활용품을 만들지 않는다(사용자 지정으로 비료·폭발물에 집중).
