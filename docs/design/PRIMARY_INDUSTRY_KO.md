# 1차 산업 (농장·벌목·광산·유정·어항) — 사용자 확정 2026-11-12 · 수치 임시

자원 지형은 MAP_SIZE_KO.md(지형 표시), 원자재·버프재는 RAW_MATERIALS_KO.md.

## 짓는 방식 (확정: B — 직접 배치 + 자동 작업지)

- 플레이어는 **메인 건물**(농장 본채, 벌목장, 광산 입구, 유정 본부, 어항)을 공공 건물처럼 썸네일 카드로 직접 배치한다. 도로 접면 필요.
- 메인 건물은 주변 **범위 안 자원 지형**에 **작업지**(경작지·벌목지·채굴지·시추지)를 **자동으로** 넓혀 간다.
- **작업지 위에 건물이 들어서거나 도로가 생기면, 메인 건물이 파괴되는 게 아니라 그 칸의 작업지만 사라진다.**
- 작업지는 **메인 건물과 연속으로 연결**돼 있어야 한다. 도로 등으로 **메인 건물과 끊긴 작업지 부분은 사라진다**(연결 판정: 작업지 칸이 메인 건물 부지까지 이어지는지).
- 생산량 = 연결된 작업지 넓이 × 자원 등급 × (버프재 공급 시 +50%).
