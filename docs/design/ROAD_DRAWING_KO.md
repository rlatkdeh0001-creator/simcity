# 도로 그리기 방식 (사용자 요청 2026-11-12)

상태: **확정.** 수치(스냅 거리 등)는 구현 시 임시값.
기존 문서: PROJECT_SPEC_KO.txt 19행("직선·사선·곡선 지원"), ORIGINAL_HANDOFF_KO.txt 27행("자유롭게 그릴 수 있다"). 현재 구현은 자유 드래그 1가지뿐.

## 확정

- **기본은 직선.** 손으로 자유롭게 그리는 드래그 방식은 기본값이 아니다.
- **미리보기**: 그리는 동안 마우스 커서를 따라 **반투명 초록 도로**가 실시간으로 생겨 어떻게 만들어질지 보여준다. 건설할 수 없는 위치(겹침·각도·자금 부족 등)는 **반투명 빨강**(공공 건물 고스트와 같은 규칙).
- **이어 그리기**: 기존 도로의 끝점 근처에서 시작하면 그 끝점에 붙어 이어진다. 중간에 붙이면 교차로 생성. 직전에 그린 도로의 끝점에서 다음 도로가 이어진다.

## 그리기 방식 3가지 (사용자 확정 2026-11-12)

도로 그리기 도구 안에서 유저가 선택. 기본값은 직선.

| 방식 | 조작 |
|---|---|
| ① 직선 (기본) | 시작점 클릭 → 미리보기가 커서를 따라감 → 끝점 클릭 |
| ② 곡선 | 시작점 → 휘는 지점 → 끝점 클릭 |
| ③ 자유 곡선 | 앞 도로 끝 방향을 이어받아 부드럽게 휨 |

직각 격자 방식은 넣지 않는다. 원래 인계서(ORIGINAL_HANDOFF_KO.txt 37행)의 "S자" 모드도 추가하지 않는다(사용자 결정 2026-11-12: 3개만). 방식 선택 버튼은 UI라 구현 전 시안 3개(M-008).
- 길이 단위(ORIGINAL_HANDOFF 36행): 건설 8m 단위, 철거 4m 단위 — 적용 여부 확인 지시(2026-11-12).

## 관련 요청 (같은 날)

### 각도 보조 구현(후속)

- 기존 도로 중간/끝 접속점에서 근접한 방향은 로컬 선분 접선 기준 ±10° 이내이면 정확한90°로 보조한다. 기존 끝점의 바깥쪽 평행 연장도0°로 보조하며, 이미 도로가 점유한 중간 선분을 덧그리는 평행 구간은 만들지 않는다.
- 직선·곡선·자유곡선의 실제 첫/마지막 접속 구간과 초록 미리보기/확정에 동일 좌표를 쓴다. 범위 밖 사선과 비접속 자유 도로는 유지한다.
- 양쪽 기존 도로에 연결하면 중간 접점을 해당 중심선 위에서 이동해 해결하며, 기존 authored 끝점은 고정한다. 두 고정 끝점이 정확한 각도와 양립할 수 없으면 접속 보존을 우선한다. 저장된 기존 도로 자체는 수정하지 않는다.

- 공공 건물 배치 시 미리보기가 가까운 도로 가장자리에 붙고 정면이 도로를 향함(사용자 확정).
- 자금 부족 카드 클릭 시 "잔고가 부족합니다." / 마우스 올림 미리보기에 가격·유지비·발전량/용량 — UI라 시안 3개 먼저.
