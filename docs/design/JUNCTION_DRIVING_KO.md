# 차량 교차로 주행 (사용자 확정 2026-11-14)

신호(TRAFFIC_SIGNALS_KO)와 회전교차로(ROUNDABOUT_KO)가 올라갈 바탕 규칙이다.

## 지금 코드 상태 (확인: core/traffic_network.gd, core/traffic_simulation.gd, docs/ROAD_JUNCTIONS_KO.md 70~83행)
- 교차로 하나에 **차 한 대씩만** 통과(먼저 기다린 차 순). 8차선 교차로도 한 번에 한 대.
- 모든 차로에서 좌회전·직진·우회전 전부 가능(나가는 차로 = 들어온 차로와 같은 번호). 유턴 없음.
- 나갈 도로에 자리가 없으면 진입 안 함(꼬리물기 방지는 이미 있음).
- 앞차 간격 유지·가감속은 있음. 구간 안 차로 변경, 우선도로, 신호 단계는 없음.

## 1. 차로별 진행 방향 (기본값, 교차로 설정 창에서 변경 가능)
한 방향 차로 수 기준. 1차로 = 중앙선 쪽.

| 한 방향 차로 수 | 1차로 → 바깥 차로 |
|---|---|
| 1 | ←↑→ |
| 2 | ← / ↑→ |
| 3 | ← / ↑ / ↑→ |
| 4 | ← / ↑ / ↑ / ↑→ |

- T자처럼 없는 방향은 뺀다(예: 왼쪽 길이 없으면 1차로도 ↑).
- 좌회전 전용 차로를 두는 이유: 좌회전 신호를 기다리는 차가 직진 차를 막지 않게.
- 들어가는 차로: 좌회전 → 받는 도로의 안쪽 차로, 우회전 → 가장 바깥 차로, 직진 → 같은 번호 차로.
- 유턴: **막다른 길 끝에서만**(사용자 확정). 교차로 유턴은 기본 금지(설정에서 허용 시 1차로에서만).

## 2. 차로 고르기·차로 변경
- 차는 경로상 **다음 교차로에서 갈 방향**을 알고 있고, 그 방향이 허용된 차로 중 **줄이 가장 짧은 차로**를 고른다(CS2 방식: 빈 차로를 고르게 채움).
- 구간에 들어서면 목표 차로로 옮긴다. 옆 차로에 차체 길이 + 안전 간격만큼 빈자리가 있을 때만 약 2초에 걸쳐 이동.
- **정지선 앞 실선 구간**(제안: 12m 또는 구간 길이 절반 중 짧은 쪽)에서는 차로 변경 금지.
- 실선 구간까지 못 옮긴 차는 **지금 차로가 허용하는 방향으로 그냥 가고 경로를 다시 찾는다**(멈춰서 끼어들기를 기다리지 않음 → 그 차 때문에 뒤가 막히지 않음). 사용자 확정.

## 3. 교차로 통과 판정 (한 대씩 → 겹치지 않는 차는 동시에)
- 교차로를 만들 때 차로 연결선(이동 경로)마다 **서로 부딪히는 연결선 목록**을 미리 계산해 둔다(경로가 교차하거나 같은 차로로 합쳐지는 경우).
- 차가 정지선에 다가오면 순서대로 확인: ① 신호·우선순위상 갈 차례인가 ② 부딪히는 경로를 다른 차가 쓰고 있지 않은가 ③ 나갈 도로에 자리가 있는가. 모두 통과하면 그 경로를 잡고 진입, 뒤꽁무니가 빠져나가면 풀어 준다.
- 같은 경로의 뒤차는 앞차를 따라 줄지어 통과(앞차 간격 규칙 그대로).
- 결과: 마주 보는 직진끼리, 우회전과 반대편 직진 등은 동시에 지나간다.

## 4. 신호 없는 교차로의 우선순위 (도로교통법 제26조를 게임 규칙으로)
1. 이미 교차로 안에 있는 차 먼저.
2. **넓은 도로(폭 등급이 높은 도로)가 자동으로 우선**. 좁은 도로 쪽은 양보.
3. 폭이 같으면 먼저 도착한 차, 동시면 오른쪽 도로의 차.
4. 좌회전 차는 마주 오는 직진·우회전 차에 양보.
- 플레이어가 진입로별로 **우선 / 양보 / 정지**를 바꿀 수 있다(TRAFFIC_SIGNALS_KO 통행 방법). 양보 = 부딪히는 차가 가까이 없으면 멈추지 않고 진입, 정지 = 일단 멈춘 뒤 같은 판정.
- 양보만 하다 굶는 차 방지: 게임 시간 20초 넘게 기다리면 순위를 올려 준다.

## 5. 신호 있는 교차로
- 초록·화살표가 내 이동을 허용할 때만 진입(3번 판정 포함).
- 노랑: 정지선 앞에서 무리 없이 설 수 있으면 정지, 아니면 통과.
- **빨간불 우회전: 일단 정지 후, 부딪히는 차가 없으면 우회전**(2023 시행규칙). 그래서 설정 창에 우회전 화살표가 기본으로 없어도 된다.
- 꼬리물기 금지(기본 ON): 초록이어도 나갈 자리가 없으면 정지선에서 대기. OFF면 그냥 진입.

## 6. 막힘 처리
- 한 자리에서 게임 시간 60초 넘게 못 움직이면 경로를 다시 찾는다.
- 그래도 계속 갇혀 있으면(제안: 게임 시간 5분) 차를 지우고 도착 처리한다(사용자 확정).
- **플레이어에게는 알리지 않는다**(알림·통계 화면·지도 표시 없음). 막힌 곳은 화면에서 직접 찾아 고치는 것이 게임의 재미(사용자 확정).
- **개발용 기록만 남긴다**: 교차로·구간별 '교통 마비' 횟수(재탐색 수, 삭제 수, 위치, 게임 시각)를 코드 내부 카운터·로그로 저장. 디버그 출력으로만 확인.

## 7. 안 보이는 차(거시 계산)와 성능
- 화면에 없는 차는 교차로를 실제로 통과하지 않고, **교차로별 평균 대기 시간**만 소요 시간에 더한다(VEHICLE_SPAWN_DESPAWN_KO 2단계 교통).
- 부딪힘 목록은 연결선당 비트마스크로 저장, 도로가 바뀔 때만 다시 계산. 차는 정지선에 다가올 때만 판정.

## 나중 (이번 범위 아님)
긴급차량 우선, 보행자 횡단, 비보호 좌회전, 추월, 사고.

## 구현 순서 제안
① 차로별 방향 + 부딪힘 목록 + 동시 통과 → ② 차로 변경 → ③ 우선/양보/정지 → ④ 신호 연동 → ⑤ 회전교차로
