# 정식 맵 크기 — 10km × 10km (사용자 확정 2026-11-10)

상태: **결정 확정, 구현 전.** 현재 게임은 `cities_do/maps/example_100.json`(100×100칸, 1칸=4m = 0.4km×0.4km) 예시 지도로 시작한다.

## 확정

- 정식 맵: **10km × 10km = 100km²**.
- 1칸 = 4m 공통 축척 유지 → **2,500 × 2,500칸** (625만 칸).
- 근거: 목표 최대 인구 100만 명. 100km²면 평균 1만 명/km²(서울 평균 약 1.6만/km²보다 여유) — 도로·공원·공업·빈 땅 포함 가능.
- 네 이웃 마을은 맵의 네 변 바깥(REGIONAL_EXCHANGE_RULES_KO) 그대로.

## 구현 시 영향 (기획 검토, 미구현)

| 영역 | 영향 |
|---|---|
| 구획 격자 | 이미 sparse chunk(core/zoning_grid.gd, 도로 주변만 생성)라 625만 칸 전체를 만들지 않음 — 유지 |
| 지형 렌더링 | 10km 지면을 한 메시로 그리지 않고 구역(청크) 단위 표시·카메라 거리별 상세도 필요 |
| 카메라 | 전체 맵 축소 보기와 확대 한도, 지도 버튼(하단바)으로 전체 보기 |
| 교통·경로 | 맵이 커지면 경로 캐시·구간 혼잡도 집계(VEHICLE_SPAWN_DESPAWN_KO 연산 절감 1~4)가 필수 |
| 전력·수도 | 64m/32m 망 그래프 노드 수 증가 — 공간 인덱스 필요 여부 측정 |
| 저장/불러오기 | 도시 데이터 크기 증가 — 청크 단위 저장 고려(백로그 6번) |
| 기존 예시 지도 | 100×100 예시 지도는 테스트·데모용으로 유지(기존 테스트 fixture 보존). 새 정식 지도 파일을 별도로 추가 |

## 관련 확정 규칙

- 주차장 탐색: 목적지에서 **걷는 거리 1km** 이내(VEHICLE_SPAWN_DESPAWN_KO).
- 표시 차량 단계 비율: 100만 명에 최대 약 11,800대(같은 문서).

## 지형·시작·해금 (사용자 확정 2026-11-11, 세부는 기획 담당 결정)

1. **지형**: 평지 위주. 강 1개가 맵을 가로지르고 한쪽에 바다(또는 큰 호수). 산은 가장자리에만. 수력댐·취수장·하수장은 물가 배치.
2. **자원 지형 표시만**: 숲(목재)·광산(철·석탄)·유전(석유)·(우라늄 광상)을 지형 표시로만 넣고 채취 기능은 나중에. 현재 원료는 전부 수입.
3. **고속도로**: 시작부터 **화면 11시 변(x=0, 비슷한 마을 B) ↔ 5시 변(x=맵 너비, 발전한 마을)**을 잇는 고속도로 1개가 맵을 관통(맵 중심에서 약 1km 비켜 지나가 시작 원 안을 지남). 1시(엄청 발전)·7시(비슷한 마을 A) 마을은 플레이어가 도로를 이어 연결. 이웃 배치는 REGIONAL_EXCHANGE_RULES_KO.md(마름모 맵의 네 변 = 화면 1·5·7·11시).
4. **해금 = 인구 비례로 커지는 중앙 원**: 처음에는 맵 중심 반경 1km 원 안에만 건설 가능. 인구에 따라 원이 저절로 커지고 **인구 1만 명에 맵 전체 해금**.
   - 제안식: 반경(km) = 1.0 + 6.1 × (인구 / 10,000) → 인구 1,000마다 약 0.6km 확장, 1만 명에 7.1km(맵 모서리까지).
   - 원 밖은 어둡게 표시, 건설·구획 불가. 기존 건물이 원 밖에 생기는 일은 없음(원은 줄지 않음).
5. **시작 위치**: 맵 중앙, 고속도로 인터체인지 근처.
   - **미리 만든 인터체인지 3개**: 시작 원 안 1개(중앙), 고속도로 양쪽 구간 각 1개(중앙에서 약 3km 지점). 기존 나들목 규칙(측면 진입·진출, 유선형 램프, 램프 흰 실선 없음) 준수.
