# 가격 제안 1차 · 사용자 검토 대기

[대응하는 수용량·발전량·처리량 제안](CAPACITY_PROPOSALS_KO.md)도 함께 검토한다.
두 문서의 제안은 아직 실제 차감/생산 코드에 적용하지 않았다.

2026-11-02 KST. 아래 **0 doth인 주거·상업·공업 구획 규칙만 확정**이다.
다른 가격과 유지비는 제안이며 실제 차감 코드에 적용하지 않았다.

## 확정된 구획 규칙

- 주거·상업·공업 구역 지정 비용은 **0 doth**다.
- 플레이어가 드래그로 영역을 지정하면 그 안에 건물이 자동으로 들어선다.
- 플레이어가 각 민간 건물을 구매해 놓는 방식으로 가격을 매기지 않는다.
- 무료 지정/자동 신축이 성장 조건·필지·실제 도로 접면 조건을 없애는 것은 아니다.
  기존 자동 성장의 만족도·전기/수도 등 합의는 유지한다.
- 현재 실행 코드는 클릭 배치/수동 성장 프로토타입이다. 이번에는 새 설계 규칙을
  기록했으며 드래그 구획 칠하기와 자동 입주 전체를 구현한 작업이 아니다.

## 제안 기준

기본 난이도 시작 자금 50,000 doth에 맞춰 소규모 인프라는 초기에 살 수 있게,
대형 공공시설과 발전소는 도시가 성장한 뒤 투자하게 잡았다. 실물 화폐 환산값이
아닌 게임 밸런스 초안이다. 성능/수용량이 아직 정해지지 않아 경제 밸런스 검증을
마친 가격표는 아니다.

건설비는 1회, 유지비는 **게임 내 1개월당** 제안이다. 게임 1개월의 실제 진행 시간,
소수 화폐, 일할 계산 방식은 미정이다. 표의 정수 금액은 유지비 단위 확정을 뜻하지 않는다.
이웃 마을 구매/판매 단가와 세금은 아직 제안 수치에 포함하지 않았다.

안을 권한다. 할인·주차료·철거 환급금은 별도 미정이다. 현재 16면 타워는 평면 대형과
같은 수용량을 절반 부지에 넣으므로, 비싼 구조비를 땅 절약의 대가로 잡았다.

## 초반 구매 가능성 예시

2차로 도로 400m(4,000), 전선/상수도관/하수도관 각 200m(합계 1,400), 풍력(6,000),
취수장(8,000), 급수탑(4,000), 하수장(6,000), 초등학교(5,000), 쉼터 공원(300)을
만들면 **34,700 doth**, 잔액 **15,300 doth**다. 제안 월 유지비는 합계 **550 doth**다.
이는 합산한 구입 예시일 뿐 이 배치가 실제로 모든 수요를 충족하거나 지속 흑자가
난다는 증명은 아니다. 세입·가구 수·시설 용량·외부 구매 단가를 정한 뒤 수지 검증이 필요하다.
