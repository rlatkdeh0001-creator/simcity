# 경제 수치 통합 관리대장

사용자의 보관 요청으로 `ECONOMY_BALANCE.csv`에 현재 경제 수치를 모았다.
숫자 데이터는 이 CSV 한 파일에서 편집한다. 이 문서는 사용법과 검증 범위만 설명한다.

- UTF-8 BOM, 쉼표 구분, 첫 줄 한국어 열 이름. Excel/스프레드시트에서 열 수 있다.
- `분류`나 `대상`으로 필터한 뒤 `값`을 수정한다. 항목ID는 연결 식별자이므로 유지한다.
- `단위`를 함께 확인한다. 길이당 건설비, 시설당 건설비, 게임월 유지비와 kWh/m³ 요금은 서로 다르다.
- `적용중`: 현재 게임에서 사용하는 값. `확정`: 설계 규칙 확정이며 전체 기능 구현 여부는 메모 참고.
- `제안`: 검토 중이며 실제 비용으로 차감하지 않음. `보류`: 미적용 제안 기록. `미정`: 아직 값 없음.
- 미정의 빈칸은 0이나 무료를 뜻하지 않는다. 상태 열을 바꾸는 것만으로 경제 기능이 구현되지 않는다.

현재는 **보관·편집용 관리대장**이다. 게임이 이 CSV를 직접 로드하도록 바꾼 작업은 아니다.
적용 중 수치를 변경해 게임에 반영하려면 CSV의 `현재근거`에 적힌 코드/JSON도 동기화하고 검사한다.
향후 담당자는 CSV를 먼저 수정하고 적용 승인 범위를 확인한다. 기존 가격 문서는 출처/과거 제안 기록이다.
주민 사용료와 이웃 거래요금을 구분하고, 미정 세율을 임의로 생성하지 않는다.

2026-11-02 KST 생성·검증: 총 141개 항목, 9열. 기존 가격표 시설/노선 50종을 모두 포함한다.
적용중 19 / 확정 7 / 제안 104 / 미정 8 / 보류 2 / 관리정보 1행이다.
전기 거래 6항목과 수도 거래 9항목은 현재 코드/JSON에서 가져왔다.
가격표 전체 항목 누락 여부, ID 중복, CSV 재읽기 일치, 미정 공란, 요금 수를 확인했다.
숫자/런타임을 바꾸지 않은 자료 정리 작업이므로 게임 회귀 검사는 재실행하지 않았다.
