# 교차로 설정 창 시안 결정 (사용자 확정 2026-11-13)

채택: **C3 v2** — `mockup-c3-v2.html` (재생 가능한 시안).

- 큰 창: 왼쪽 교차로 도식, 오른쪽 **신호등 번호 × 단계 표**, 아래 재생 막대.
- 모드: 자동 / **수동(차량 감지)** / 수동(시간 조정) (TRAFFIC_SIGNALS_KO.md). 수동(차량 감지) 화면에는 **초 줄 없음**(시간이 자동이라 혼동 방지) — `mockup-c3-partial.html`.
- 방향 글자(남북·동서 등) 없이 **화살표만**. 우회전 화살표는 기본 숨김.
- 신호등에 **번호(①②③④…)**, 표의 줄 = 같은 번호. 표 줄에 마우스를 올리면 도식의 해당 번호 강조.
- 단계는 **A·B·C·D…** (신호등 번호와 구분). 표 칸 = 그 단계에서 그 신호등이 주는 신호: ← 좌회전 / ↑ 직진 / ● 빨간불. 마지막 줄 = 단계 시간(초).
- 도식 신호등 4구: 빨강 · 노랑 · **← 좌회전 화살표 등** · 초록.
- **재생 테스트**: ▶/❚❚, 시간 슬라이더로 원하는 초로 이동, ×1·×4. 재생 중 현재 단계 열 강조, 도식 신호등·차로 화살표 색이 단계·황색(3초)·전적색(1초)에 맞춰 변함.

탈락: A(오른쪽 패널), B(맵 위 버튼), C1(단계 카드), C2(시간 막대) — `mockups.html`, `mockups-c.html`.
