# UI 시안 결정 (사용자 승인 2026-11-12)

시안: docs/concepts/ui-batch-20261112/mockups.html

## 1. 도로 그리기 방식 선택 — B안

- 도로 탭 선택 시 하단바 **위에 떠 있는 작은 버튼 묶음**(직선 · 곡선 · 자유 곡선). 기본 선택 직선(파란 강조 #36b7ff).
- 아이콘만, 설명 문구 없음. 도로 탭이 아닐 때는 숨김.

## 2. 잔고 부족 — B안 + 클릭 차단

- 건설비가 잔고보다 크면 카드는 흐리게(기존 표시 유지).
- 그 카드를 클릭하면 **배치 모드로 들어가지 않고**(고스트 안 뜸) 카드 바로 위에 말풍선 **"잔고가 부족합니다."**, 카드 테두리 빨강. 약 2초 뒤 사라짐.

## 3. 마우스 올림 정보 — A안 + 공식 돈 아이콘

- 기존 애셋 미리보기 말풍선에 이름 + 항목 추가: 건설비 / 유지비(−, /월) / 시설별 핵심 수치(발전량 kW, 급수·처리량, 정원 등 CSV 값).
- 금액 표기: **`15,000 ₫`** (숫자 + 공식 돈 아이콘). "doth" 글자 대신 아이콘.

## 공식 돈 아이콘 (사용자 지정)

- 시안 3-B에 쓴 기호 **₫**(강조색 #36b7ff)를 게임 공식 화폐 아이콘으로 채택.
- **화면에 "doth" 글자를 쓰지 않는다**(사용자: 유저가 doth라는 단어를 알 필요 없음). doth는 내부 데이터·문서 단위명으로만 남는다.
- 표기 형식: 천 단위 쉼표 + 공백 + 아이콘. 예: `15,000 ₫`, 유지비 `−200 ₫/월`.
- **상단 자금·수지 등 모든 HUD 금액에 적용**: `50,000 doth` → `50,000 ₫`, 수지 `+1,200 ₫/월`. (기존 HUD 규칙 "자금은 50,000 doth 형식"을 대체.)

## 변경: 자체 화폐 아이콘 A안 (사용자 승인 2026-11-12)

- ₫는 베트남 동 기호라 쓰지 않는다. **자체 아이콘 A안(D + 세로획을 지나는 가로 한 줄)** 으로 교체. 원본: `currency-icon-A.svg`(색 #36b7ff), 시안 `currency-icon.html`.
- 글리프가 아닌 **아이콘 이미지**로 표시(글자 높이에 맞춤). 상단 자금, **수지**, 건설비, 유지비, 말풍선 등 화면의 모든 금액에 적용. 예: `50,000 [D]`, `+1,200 [D]/월`, `−200 [D]/월`.
- **정렬(사용자 지적 수정)**: 정보 말풍선은 3칸 표 — 항목명(좌) / 숫자(**우측 정렬**, 끝자리 맞춤) / 단위(좌측 정렬: 아이콘, 아이콘/월, kW). 숫자는 고정폭 숫자 사용.
