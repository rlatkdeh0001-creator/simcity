# 우리 게임으로 실행한 하단 UI 검토 장면

**최신 규칙: [구획 탭·기본 타일 숨김·통합 불도저](DEMOLITION_ZONING_KO.md)**. 아래 이전 단계 기록보다 우선한다.

**최신 배치는 [시티즈: 스카이라인 참고 수정](SKYLINES_REFERENCE_KO.md)**을 따른다. 반경·간격 설명은 게임 UI에서 제거했다.

2026-11-02 KST. 사용자 요청에 따라 생성형 도시 그림을 쓰지 않고 **현재 Godot 게임을
실제로 실행한 화면**에서 하단 UI를 확인할 수 있도록 만들었다.

[실제 전력 화면 1920×1080](actual-game-power.png) ·
[실제 상하수도 화면 1920×1080](actual-game-water.png) ·
[실제 화면 1280×820](actual-game-1280.png)

`cities_do/bottom_ui_preview.tscn`은 기존 main.gd를 확장하는 별도 검토 장면이다.
기존 CityModel과 주거 카탈로그의 건물 34개, 실제 모델 도로 6개, 전력망·상하수도망을
검증된 건설 API로 배치하고 **기존 게임 렌더러**로 그린다. 지금 저장 중인 사용자 도시가
따로 있는 것은 아니므로 화면의 배치는 검토용으로 구성했다. 애셋/도시/네트워크를
생성형 그림으로 대체하거나 게임 화면에 그림을 합성하지 않았다.

원본 시안의 실루엣 느낌으로 SVG 경로를 직접 정의하고 Godot에서 텍스처로 만들어
하단의 실제 Button/Container에 넣었다. 외부 아이콘 라이브러리를 새로 설치하지 않았다.
상시 측면 패널과 디버그 HUD는 이 검토 장면에서 숨기고, 전력·수도 오버레이와
실제 건설 입력을 하단 도구에 연결했다. 이후 수정에서 일반 건설 화면/전력·수도 실습장의 설명 문구도 제거했다. 기본 건설 화면 전체를 새 레이아웃으로 교체한 것은 아니다.

자금과 건물 수는 실제 모델 값이다. 인구·만족도 엔진은 없으므로 `—`로 표시한다.
시설 출력/물 수요는 기존 시험 규칙이며 이 배치가 최종 도시 밸런스를 뜻하지 않는다.
교통 주행을 이 장면에 새로 연결한 것은 아니며 움직이는 가상 시민/교통량을 만들지 않았다.
UI 아이콘은 게임 내 유료 건설 시설이 아니며 건설비·유지비·요금은 변경하지 않았다.

## 현재 조작 범위

- 하단 8개 메뉴 버튼과 선택 강조, 상세 도구 모음 펼치기/접기.
- 전력/상하수도 전환은 실제 기존 네트워크 오버레이를 사용하며 측면 패널은 숨긴다.
- 전력선·발전시설·전력선 철거와 상하수관·취수장·처리장·관로 철거는 기존 건설 모드에 연결한다.
- 주거/상업/공업 신축, 도로 그리기/건물 선택도 기존 모드에 연결한다.
- 일시정지/재개와 1배/3배속은 검토 장면의 실제 시뮬레이션 경과 시간에 적용한다.
- 지도 버튼은 전체 배치에 맞춰 카메라를 재설정한다. Escape는 상세 도구 모음을 닫는다.
- 환경/공원/교통/기타의 상세 기능은 이번 장면에서 완성하지 않았다. 메뉴 위치 확인용이다.
- 키보드 기본 포커스와 좌우 이웃을 지정했다. 물리 게임패드 조작은 검증하지 않았다.
- 자금/건물 수 표시는 기존 모델의 변경을 확인해서 갱신하며 전체 HUD 이벤트 시스템으로
  리팩터링한 작업은 아니다. 기본 게임의 메뉴를 모두 교체한 것으로 해석하지 않는다.

## 실행·캡처

```sh
godot --path cities_do bottom_ui_preview.tscn
godot --path cities_do --resolution 1920x1080 bottom_ui_preview.tscn -- --capture-bottom-ui=/tmp/bottom-power.png
godot --path cities_do --resolution 1920x1080 bottom_ui_preview.tscn -- --bottom-tab=water --capture-bottom-ui=/tmp/bottom-water.png
godot --headless --path cities_do --script tests/test_bottom_ui.gd
```

캡처는 약 3초 후 `RenderingServer.frame_post_draw`에서 실제 뷰포트 PNG를 저장한다.
Xvfb+Mesa llvmpipe OpenGL로 실행했으며 생성형 이미지/HTML 합성은 사용하지 않았다.
제한 환경에서는 기존 작업과 같은 writable XDG 경로를 지정한다.

## 검사

Godot 4.6.3 전용 **24/24 통과**, 전체 13개 스크립트도 통과했다.
[원본 로그](../../bottom-ui-validation/).
실제 카탈로그 건물/도로/전원, 8개 버튼, 오버레이 전환과 실제 관로 모드,
1920×1080·1280×820·960×640의 하단 고정/상세 창 경계, 포커스 이웃,
Escape 접힘, 시뮬레이션 정지/3배속, 실제 자금·건물 수 표시를 확인했다.
1920×1080의 두 탭과 1280×820은 실제 그래픽 화면도 캡처해 육안으로 확인했다.
세로 휴대폰 화면·노치·200% 글자·물리 컨트롤러까지 통과했다고 주장하지 않는다.
