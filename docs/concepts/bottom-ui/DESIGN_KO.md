현재 게임 HUD를 교체하는 승인으로 해석하지 않고, 배치를 검토할 수 있는 별도 시안을 만든다.

## 디자인 계획

기존 짙은 청록/남색 패널과 밝은 실루엣 아이콘을 유지한다.
바탕 #142b37, 구분선 #38515e, 글자 #edf4f5, 선택 파랑 #36b7ff,
도시 배경은 잔디와 따뜻한 건물 색을 사용한다. 글자는 한국어 산세리프 계열이다.

상단·좌우 가장자리의 상시 HUD를 없애 도시를 넓게 본다.
하단에 자금·인구·만족도 등 상태와 건설/도로/전력/상하수도/환경/공원/교통/기타
메뉴 아이콘을 모은다. 지도/설정/전체 메뉴/시간 조절도 하단에 둔다.
선택 메뉴의 상세 도구는 하단 모음 바로 위로 펼치며 닫아서 지도 영역을 확보한다.
비선택 상태에서 항상 떠 있는 거대한 측면 패널은 두지 않는다.

레이아웃 구상:

```
┌─────────────────────────────────────────────────────────┐
│                                                         │
│                     도시 지도                           │
│                                                         │
│       [필요할 때만 펼치는 선택 메뉴 상세 도구]            │
├─────────────────────────────────────────────────────────┤
│ 자금 / 인구 / 만족도                날짜 / 시간 / 설정   │
│ 건설   도로   전력   상하수도   환경   공원   교통   기타 │
└─────────────────────────────────────────────────────────┘
```

원본 시안의 아이콘 의미를 유지하되, 형태를 통일한 밝은 실루엣으로 다시 구성한다.
선택 상태는 파란 배경/아이콘/밑줄 및 글자로 표현해 색만으로 구분하지 않는다.
최종 구현에서는 하단 anchor+container, 화면 안전 여백, 좁은 화면의 가로 스크롤/
가변 배치, 키보드 포커스와 상태별 팝업을 검증한다. 스킬을 설치했다고 이 동작이
현재 Godot 게임에서 구현·검증된 것으로 기록하지 않는다.

## 검토 범위

그림의 도시 외관/인구/수요 등은 설명용 시안이며 실제 실행 중 게임 화면이 아니다.
화면의 예시 숫자는 경제 CSV 수정이나 실제 요금·기능 변경을 뜻하지 않는다.
공급 거리 표시는 최신 반경 64m·접속점 32m를 따른다.

## 제작 결과와 실제 적용 범위

[시안 이미지](concept.png)는 원본 전력 설명 그림을 image_gen으로 편집해 제작했다.
출력 크기 1672×941. 기본 하단 모음은 화면 높이의 약 1/5이며,
전력 도구가 열린 상태에서는 그 위에 얕은 도구 모음이 추가된다.
건설·도로·전력·상하수도·환경·공원·교통·기타 8개를 하단에 나란히 배치했다.
자금·인구·상태, 날짜·시간 재생·지도·설정·전체 메뉴도 하단으로 옮겼다.
현재 이미지는 전력 선택 상태를 보여준다. 실제 클릭/접힘/키보드 동작은 구현하지 않았다.

[도입 스킬과 조사 범위](SKILL_RESEARCH_KO.md). 정적 시안/스킬 설치를 완료했으며
현재 Godot UI·세금·요금·애셋을 변경하지 않았다. 최종 UI로 확정된 것은 아니다.
