# 시티즈: 스카이라인 참고 · 설명 없는 하단 UI

**2026-11-10 최신:** [1A 본게임 하단 UI 통합·실제 캡처](../../bottom-ui-main-validation/README_KO.md).
기존 자체 SVG와 이 문서의 UI 원칙을 유지해 main에 통합했다. 아래 별도 검토 장면 설명은 과거 단계다.

2026-11-02 KST 사용자 요청: 시티즈: 스카이라인을 참고하고 전선 공급 반경/간격 등
게임 안의 설명 문구를 지운다. 규칙 자체를 삭제하라는 의미로 해석하지 않는다.

## 확인한 자료

- [Cities: Skylines 공식 Steam 페이지](https://store.steampowered.com/app/255710/Cities_Skylines/).
  공식 스크린샷은 주로 HUD를 숨긴 도시 화면이므로 UI 배치의 직접 근거로 확대하지 않았다.
- [Steam 커뮤니티 가이드: Desenvolvendo Cidades em Cities: Skylines](https://steamcommunity.com/sharedfiles/filedetails/?id=2020290339).
  가이드 내 실제 플레이 스크린샷에서 하단 분류 아이콘과 최하단 도시 상태 줄을 확인했다.
  참고 화면: https://images.steamusercontent.com/ugc/772870027348915903/E6800743A6CB79700745EFD65D94D9EC393BA56B/

참고 자료는 조사용으로만 열었다. 타 게임의 스크린샷·브랜드·아이콘·애셋을 프로젝트에
복사하지 않았다. 우리 게임의 기존 자체 실루엣/SVG와 실제 도시 렌더러를 사용한다.
범용 배치 원칙을 참고한 것으로 시티즈 UI를 똑같이 복제했다는 뜻은 아니다.

## 수정 결과

- 넓게 펼쳐져 있던 카테고리 버튼을 하단 가운데의 작은 아이콘 모음으로 바꿨다.
- 자금·건물 수·시간·설정 줄을 **맨 아래**로 이동했다.
- 선택 메뉴의 시설은 그 위에 **아이콘+짧은 이름** 타일로 배치했다.
- 공급 반경/접속점 간격, 표시와 공급 분리 설명, 현실/게임 시간 변환 설명,
  깊이 안내, 시험용/임시값 안내와 배치 검토 문구를 UI에서 제거했다.
- 일반 건설 화면의 상시 디버그 문단(성장 확률/맵 크기/좌표계/카메라 사용법)도 제거했다.
- 전력/수도 실습장의 거리·메커니즘 설명 문단도 제거했다.
- 도구 이름, 용량/수급/요금 같은 실제 상태, 선택·실패·완료 알림은 유지했다.
  설명과 개발상 한계는 문서에 보관한다.

공급 반경 64m·접속점 32m·동시 공급·표시 독립성·단가/정산은 그대로다.
이번 작업으로 경제 수치 CSV나 공급 엔진은 변경하지 않았다.
기본 건설 화면 전체를 새 하단 메뉴로 교체한 것은 아니며 레이아웃은 여전히
`bottom_ui_preview.tscn`에서 검토한다. 기본 게임에서도 설명 문구 제거는 적용됐다.
