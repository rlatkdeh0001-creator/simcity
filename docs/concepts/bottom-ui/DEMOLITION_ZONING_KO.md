# 구획 탭·배치 타일·통합 불도저

2026-11-02 KST 사용자 요청을 실제 Godot 장면과 공통 게임 모델에 반영했다.

- 하단 **건설** 메뉴 이름을 **구획**으로 변경했다. 내부 build 식별자는 호환성을 위해 유지한다.
- 하단 도구 모음 **맨 오른쪽에 불도저 아이콘**을 따로 둔다.
- 전력/상하수도 상세 메뉴의 개별 철거 버튼을 없앴다. 기본 건설 화면에도 공통 철거 도구를 연결했다.
- 배치 타일은 기본 숨김. **구획 또는 도로** 메뉴를 선택했을 때만 표시한다.
  전력·수도·환경·공원·교통·기타 및 철거 모드에서는 숨긴다.
- 타일의 표시만 바꾸며, 구획 데이터나 실제 건설 가능 조건을 삭제하지 않는다.

## 공통 철거 동작

불도저를 선택하고 지도에서 대상을 클릭하면 한 번에 대상 하나를 철거한다.
현재 도시 모델의 건물, 도로, 발전소, 전력선, 취수/하수처리 시설, 상하수관을 처리한다.
상하수관은 처음 설치할 때와 같이 두 관을 함께 제거한다.
철거 모드는 클릭 후 계속 유지되며 불도저 재선택, Escape 또는 오른쪽 클릭으로 취소한다.
마우스 아래 철거 대상을 주황색으로 강조한다. 숨겨진 지하 망은 선택하지 않는다.
전력/수도망을 먼저 선택하고 불도저를 누르면 그 망의 보이는 선을 철거할 수 있다.
보이는 선이 도로와 겹치면 선을 우선 선택해 뒤의 도로를 잘못 철거하지 않게 한다.

도로/선은 현재 데이터의 한 건설 경로 단위로 제거한다. 클릭한 위치에서 자동으로
새 구간을 잘라내는 도로 편집기는 아니다. 별도 전시 장면에만 존재하고 일반 도시 모델에
통합되지 않은 공원/주차 시설까지 이 도구에 연결한 것은 아니다.
철거 수수료/환급에 대한 새 규칙은 정하지 않았으며 이번 작업에서 자금을 차감/환급하지 않는다.

도로 철거 시 남은 도로의 구획 ID가 바뀌지 않도록 안정적인 parcel_id를 사용한다.
삭제한 도로의 타일은 재구성 과정에서 제거하지만 다른 건물을 자동 철거하거나 옮기지 않는다.
도로 접근을 잃은 건물의 장기 쇠퇴는 별도 성장 정책이다. 실제 전력/수도 공급 상태는
즉시 다시 계산하고, 도로를 철거하면 기존 주행 그래프를 중단해 유령 차로 주행을 막는다.

## 구현·검사

- `core/city_model.gd`: `demolish(kind,id)`, 안정적인 도로 구획 ID, 도로 삭제 후 구획 재구성.
- `main.gd`: 기본 선택 모드, 구획 타일 표시 게이트, 현재 보이는 대상 선택/강조/클릭 철거.
- `bottom_ui_preview.gd`: 구획 명칭, 오른쪽 불도저, 메뉴별 타일 표시, 기존 망 오버레이 재사용.
- `core/power_overlay.gd`, `core/water_overlay.gd`: 중복 철거 버튼 제거. 기존 삭제 API는 유지.
- `tests/test_demolition.gd`: 공통 6종 철거·대상 외 보존·재철거 안전성·수요 제거,
  도로 구획 ID/도로 접근 보존·빈 지도 카메라·UI 전환·표시·클릭·취소 검사.

Godot 4.6.3에서 철거/타일 전용 **47/47**, 기존 하단 UI **24/24**,
전체 **14개 테스트 스크립트 통과**. [결과](../../bottom-ui-validation/results.json) ·
[로그](../../bottom-ui-validation/).
실제 OpenGL 뷰포트에서 기본 전력/수도(타일 없음), 구획(타일 있음), 1280 화면을 캡처했다.
기본 게임은 구획 표시/철거 동작을 공유하며, 새 하단 배치 자체는 계속 별도 검토 장면이다.
