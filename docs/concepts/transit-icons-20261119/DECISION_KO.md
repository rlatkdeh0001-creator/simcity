## 적용할 때 (구현 지시용 메모)

- `icon()` match에 고른 안의 `icons-<안>.txt` 5줄을 넣는다.
- 691행 `tool_icons`에 `"rail":"rail","metro":"metro","transit_line":"transit_line","freight_line":"freight_line","remove_line":"remove_line"`을 더한다.
- 쓴 SVG 요소와 속성은 기존 아이콘과 같다(path, circle, fill, stroke, stroke-width). 색은 `#e4eef1` 하나다.

## 확인한 것

- Edge headless로 찍은 PNG 4장을 직접 봤다. `s1-*.png`는 트레이 그림 15개를 4배로 키운 조각으로도 확인했다. 깨지거나 잘린 모양, 남은 버스 그림은 없다.
- 브라우저에서 그려진 요소 수: `s=1` 캔버스 10개 중 10개, `s=2` 캔버스 78개 중 78개, 칸 83개.
- 시안 글자는 모두 18px 이상이다.
- **Godot에서는 확인하지 못했다**(실행 금지). 구현 뒤 실제 캡처 한 장으로 다시 봐야 한다.
