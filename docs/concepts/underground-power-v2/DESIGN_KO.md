이 문서는 사용자의 시안 수정 요청을 반영한다. **게임에는 도입하지 않았다.**
1차 생성형 이미지의 배경을 편집한 것이 아니라, 거리와 움직임을 확인할 수 있는 독립

## 수정된 시각 규칙

**확정된 공급 원칙:** [실제 공급과 흐름 표시의 분리](../../ELECTRICITY_RULES_KO.md).
전력이 충분한 연결 대상에는 동시에 공급하며, 하얀 원이 도착할 때까지 기다리지 않는다.
아래 분기 목적지 순서는 애니메이션 순서일 뿐 공급 우선순위나 전달 지연이 아니다.

- 공급 범위는 기존 반경 16m에서 **반경 64m**로 확대한다(기존 반경 해석을 이어감).
- 지중 접속/공급점은 기존 8m에서 **32m 간격**으로 바꾼다.
- 1칸=4m이므로 반경 16칸, 점 간격 8칸이다. 원은 지면에 있으므로 화면에서는 타원이다.
- 건설한 전력선과 고정 접속점은 파란색으로 유지한다.
- 작은 **하얀 원이 간헐적으로 이동**해 어느 쪽으로 공급되는지 보여준다.
- 내부 공급 시 발전소에서 각 활성 분기의 말단으로 이동한 뒤 사라진다.
- 수출 시 내부 공급을 유지하면서 잉여분의 흐름 표시가 이웃 마을 연결부로 이동해 사라진다.
- 기존 수입 규칙의 표시 예로 이웃 접속점에서 내부 말단으로 들어오는 모드도 넣었다.
- 끝에 별도 종단 시설을 요구하지 않는다. 하얀 원만 사라지고 파란 선/고정점은 남는다.
- 모든 선은 지중 건설이며 깊이를 정하지 않고 다른 시설과 겹쳐 건설할 수 있다.

반경/간격 확대만으로 전선의 수송 용량이나 생산량을 4배로 늘린 것으로 간주하지 않는다.
점 간격 32m와 이전 가격 초안의 건설비 단위 8m도 다른 항목이다. 요금·건설 길이 스냅
단위는 이 시안으로 바꾸지 않았다. [기존 kWh 요금 제안](../../ELECTRICITY_TARIFF_PROPOSAL_KO.md)은 여전히 검토 대기다.

## 표현과 아직 미정인 항목

원은 흐름 방향을 알려주는 표시다. 원의 이동 속도·개수·생성 빈도를 실제 전기 속도나
kWh 거래량으로 해석하지 않는다. 시안은 1.5초마다 원을 하나 내보내고 분기 목적지를
순서대로 바꾸며, 경로를 따라 이동한 뒤 마지막 0.25초 동안 사라지게 했다.
이 타이밍은 보기 위한 임시 값이다. 공급 시점과 표시의 분리는 확정됐으며,
공급 엔진 구현·다중 발전소 배분·단전된 가지·
순환망·선로 단순 교차 시 접속 여부·32m 미만 잔여 구간의 끝점 생성은 후속 구현 대상이다.

전력을 전달받는 개별 가정으로 선에서 떨어져 나가는 표시보다는, 사용자가 요청한
'말단까지 이동 후 사라짐'을 이번 기본안으로 삼았다. 실제 내부 소비/잉여 수출량이나
부족 수입량을 계산하는 프로그램을 추가한 것은 아니다.

## 독립 시안의 시각 계획

잔디 #95a789, 도로 #4c5659, 건물 #ded6bc, UI #172d35를 배경으로 두고 전력망의
#36b7ff와 흐름 원의 흰색에 주의를 모은다. 타이포그래피는 한국어 시스템 산세리프를
사용하며 거리/상태를 큰 글자로 구분한다. 도시를 왼쪽 컨트롤+오른쪽 등각 지도에 놓고
공급 경로 자체를 주요 시각 요소로 삼는다. 직선 좌표의 원을 등각 변환해 간격과 반경을
같은 축척으로 유지한다. 이 구성이 요구한 파란 오버레이와 방향 표시를 직접 설명한다.

## 검증과 열어 보기

`tools/verify_power_preview.py`에서 Chromium/Playwright로 단위·좌표·흐름 방향·말단 소멸·
버튼·일시정지·범위 표시·390px 모바일 가로 넘침·동작 줄이기 설정·JS 오류를 검사한다.
결과는 [validation.json](validation.json)에 있다. GIF는 실제 브라우저 화면 64프레임,
250ms 간격, 내부 공급→수출 순서의 16초 반복이다. 마지막 수출 구간에는 이웃 도착 후
흐름 원이 사라지는 장면도 포함했다.

GitHub에서는 GIF/PNG로 바로 볼 수 있다. HTML은 GitHub 파일 보기에서 실행되지 않으므로
preview.html을 다운로드해 브라우저로 열면 모드 전환·일시정지·범위 표시를 시험할 수 있다.
외부 라이브러리·서버 API·폰트 다운로드는 없다.

```sh
python3 .agents/skills/webapp-testing/scripts/with_server.py \
  --server 'exec python3 -m http.server 8768 --bind 127.0.0.1 --directory docs/concepts/underground-power-v2' \
  --port 8768 -- python3 tools/verify_power_preview.py
```

frontend-design과 webapp-testing 지침을 적용했다. canvas-design을 적용한 1차 정적 시안은
원본대로 보존하고, 이번은 움직임 검토를 위한 별도 프런트엔드 시안으로 구분한다.
게임 런타임은 바꾸지 않았으므로 기존 Godot 검사 결과를 새 실행 결과로 반복 기재하지 않는다.
