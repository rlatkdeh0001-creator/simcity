# 수도 거래요금 · 사용자 조정용 기본값

2026-11-02 KST. 사용자가 “수도요금도 니가 책정해서 넣어놔봐 내가 바꿀게”로
책정·적용을 위임하여 아래 요금을 실제 게임 정산에 적용했다.

**수정할 파일: [cities_do/core/water_tariffs.json](../cities_do/core/water_tariffs.json)**
단위는 모두 **doth/m³**다. JSON의 숫자를 바꾼 뒤 게임을 다시 시작하면 새 도시 모델부터 적용된다.
별도 GDScript 수정 없이 조정할 수 있다. peer는 비슷한 마을 A/B가 함께 사용한다.

| 이웃 | 상수 수입 water_import | 상수 수출 water_export | 하수 외부 처리 sewage_disposal |
|---|---:|---:|---:|
| 엄청 발전한 마을 highly_developed | 0.040 | 0.015 | 0.030 |
| 발전한 마을 developed | 0.045 | 0.018 | 0.035 |
| 비슷한 마을 peer | 0.050 | 0.025 | 0.040 |

예: 비슷한 마을에서 물 100m³를 사오면 5doth 지출, 물 100m³를 팔면 2.5doth 수입,
하수 100m³를 외부에 맡기면 4doth 지출이다. 하수 위탁은 우리 도시가 지불하는 처리 서비스다.
이웃 하수를 가져와 처리하고 돈을 받는 사업은 이번에 추가하지 않았다.

## 가격을 이렇게 잡은 이유

기본 수입가 0.05는 초반 인구 500명의 생활용수 100m³/일 제안에서
하루 5doth로 시작할 수 있는 값이다. 하수 80m³/일까지 모두 위탁하면 하루 8.2doth,
30일 비교월에 **246doth**로 시작 자금 50,000의 약 0.492%다.
수출가는 기본 수입가의 절반으로 두었고, 가장 싼 수입가 0.04도 가장 높은 수출가 0.025보다
높아 기본 설정에서 외부 물을 되파는 단순 차익은 없다.
발전한 이웃은 공급/처리 원가가 낮고 자체 여유가 크므로 싸게 팔고 싸게 사는 설정이다.
이것만으로 무료 시험 취수장의 수출 사업 밸런스가 완성되는 것은 아니다.

| 물 100m³/일 수입 + 하수 80m³/일 위탁 | 하루 지출 | 30일 비교월 지출 |
|---|---:|---:|
| 엄청 발전한 마을 | 6.40doth | 192doth |
| 발전한 마을 | 7.30doth | 219doth |
| 비슷한 마을 | 8.20doth | 246doth |

상수 수입, 상수 수출, 하수 위탁은 각각 가장 유리한 **연결된** 이웃을 선택한다.
상수는 싼 곳에서 사고 비싸게 사는 곳으로 팔며, 하수는 싼 처리 이웃으로 보낸다.
흐름 원도 선택된 접속부의 방향을 따라간다. 계약한도는 추가하지 않았다.

## 정산과 화면

물량(m³)=거래율(m³/게임일)×경과 게임일.
요금(doth)=실제 거래 물량×해당 단가. 기존 시험 시간은 현실 1초=게임 1초다.
상수 구매비/하수 처리비/상수 판매액을 따로 누적하며 매 갱신에서 소수 금액을 이월한다.
정수 doth만 도시 자금에 정산하므로 작은 프레임 요금이 무료가 되지 않는다.
조회·흐름 원·꿀렁임·표시 토글은 돈이나 물량을 누적하지 않는다.
상하수도 패널에는 현재 외부 요금/수출 수익의 doth/일과 미정산 잔액을 표시한다.
[요금 적용 후 실제 화면](screenshots/water-tariffs-ui.png).

잔액 부족 시 자동 부채는 만들지 않는다. 현재 계통에서는 상수 구매를 우선하고,
남은 가용 자금으로 하수 외부 처리를 구매한다. 부족한 하수 처리는 미처리량에 남는다.
이번 구간의 상수 수출 수익은 그 구간의 하수 처리비에 사용할 수 있다.
전기·수도의 소수 미정산액을 합친 가용 잔액을 사용해 같은 돈을 두 번 쓰지 않는다.
서로 분리된 계통의 유한 예산 배분은 순차적이며 전 도시 최적 구매/우선순위 엔진은 아니다.
매우 큰 시간 간격을 한 번에 정산할 때와 실제 초 단위 진행의 자금 고갈 배분은 다를 수 있다.

내부 취수량과 내부 하수 처리량에는 외부 거래 단가를 곱하지 않는다.
주민/사업장에 청구하는 수도 사용료, 내부 시설 건설비·운영비·세금은 별도 경제 항목이다.
이번 위임은 위 거래 단가를 설정·적용한 것이며 기존 시설 가격/유지비 제안까지 차감한 것은 아니다.
실제 인구·수원·공공시설 전력 소비 등의 기존 시험 한계는 [상하수도 보고서](WATER_SEWAGE_KO.md)를 따른다.

## 수정 예시

```json
"peer": {
  "water_import": 0.05,
  "water_export": 0.025,
  "sewage_disposal": 0.04
}
```

0은 무료로 취급한다. 음수·문자·비유한 값·필수 키 누락은 허용하지 않는다.
JSON 구조나 단가가 잘못되면 오류를 기록하고 외부 수도 거래를 중단한다.
이미 설치한 내부 취수/처리 기능은 남는다. 값을 고친 뒤 게임을 다시 시작한다.
