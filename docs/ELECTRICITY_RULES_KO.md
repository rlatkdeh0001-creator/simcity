# 전력 규칙: 실제 공급과 흐름 표시의 분리

2026-11-02 사용자 승인으로 **게임에 도입 완료**. [현재 구현·단가·검사·한계](UNDERGROUND_POWER_KO.md)를 함께 읽는다.

## 실제 공급

- 발전소/이웃 마을 전원과 전력망이 연결되고 공급 범위에 있는 수용가가 대상이다.
- 전력이 충분하면 **같은 시뮬레이션 갱신에서 모든 해당 수용가에 동시에 공급**한다.
- 가까운 건물부터 순서대로 켜거나, 하얀 원이 이동한 거리만큼 전력을 배달하지 않는다.
- 전체 수요와 가용 전력으로 실제 수급을 계산한다. 내부 소비를 공급하고 잉여가 있으면
  외부로 수출하며, 부족하면 연결된 이웃에서 수입한다. 발전도별 단가를 적용하며
  계약한도는 적용하지 않는다. 부족 시 같은 계통 내 비례 배분은 현재 시험 규칙이다.
- 실제 수입/수출 kWh는 거래 전력과 시뮬레이션 경과 시간으로 계산하며 그림의 원을 세지 않는다.

## 하얀 원은 사용자에게 보여주는 방향 표시

- 파란 선/고정점 위를 간헐적으로 흐르는 **시각 효과**다.
- 실제 공급 결과를 읽어 방향을 표시하며, 표시가 공급 상태를 변경하지 않는다.
- 내부 공급은 분기 말단까지, 수출은 이웃 접속부까지 이동한 뒤 사라진다.
  수입은 이웃 쪽에서 내부 공급 방향으로 표시한다.
- 원의 생성/도착/소멸 시점에 건물을 켜거나 전력을 지급/회수하지 않는다.
- 원의 수·속도·목적지 순서·현재 화면에 보이는 원의 유무는 생산량·소비량·거래량과 무관하다.
- 애니메이션을 숨기거나 재생만 멈추거나 프레임 수를 바꿔도 실제 공급 계산은 같아야 한다.
  게임 전체 시간 정지와 시각 효과 정지는 구분한다.

예: 발전 300kW, 연결된 대상의 총수요 240kW라면 모두 동시에 공급하고 잉여 60kW를
거래 가능한 범위에서 수출한다. 하얀 원이 아직 선 중간에 있어도 모든 대상은 이미
공급 중이다. 반대로 원이 도착했다고 부족한 전력이 새로 생기지 않는다.
이 숫자는 원리 설명용이며 승인된 발전/소비 밸런스가 아니다.

## 후속 구현 원칙과 검사 기준

공급 상태/전력 수지 계산과 렌더링은 독립시킨다. 렌더러가 전력 공급 판정을 호출하거나
흐름 원의 콜백에서 공급 상태를 갱신하지 않는다. 겹치는 공급 원 안의 건물도 한 번만
수요를 계산한다. 연결 단절·발전/수요 변화는 다음 공급 계산에 반영하고 원의 잔상을 기다리지 않는다.

아래 항목은 `tests/test_power.gd`에서 검사했다. 전체 41/41 통과. 공급 계산은 표시와 독립이다.

1. 원을 전부 숨겨도 공급 대상과 수입/수출량이 동일한가.
2. 화면 프레임·원 간격·이동 속도를 바꿔도 같은 시뮬레이션 시간의 공급량이 같은가.
3. 원이 말단에 도착하기 전부터 충분한 전력이 모든 연결 대상에 공급되는가.
4. 전원/연결을 끊으면 이동 중인 원이 남아 있어도 실제 공급이 중단되는가.
5. 원의 도착/소멸을 반복해도 전력과 돈이 추가 생성되지 않는가.
