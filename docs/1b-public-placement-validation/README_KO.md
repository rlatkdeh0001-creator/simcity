## 승인된 배치 상호작용

기존에는 공원·주차도 검사/전시 경로뿐이었으므로, 추가 승인대로 배치 상호작용을 새로 연결했다.
기존 C카드 → 실제 GLB 월드 고스트(초록/빨강 반투명+외곽선) → 좌클릭 배치.
R=현재 도로 로컬 방향 기준90도 회전, ESC/우클릭 취소. 대각선 도로는 실제 로컬 좌표로 스냅한다.
기존 카드/하단바 레이아웃·패널·라벨을 추가하거나 교체하지 않았다.

- 공통 접도1.5m/정면/도로·교차로·민간·공공·기반시설 충돌/지도 경계 검사를 재사용한다.
- 원본 규격 그대로2×2·2×4·4×4·4×8·6×6·8×8. 성장용 정사각2/4/8 제한을 공공시설에 적용하지 않는다.
- 서로 다른 시설과 민간 건물은 같은 공간에 겹칠 수 없다. 신규 도로도 기존 공공시설을 관통할 수 없다.
- 도로 삭제/변경으로 공공시설을 이동·회전하지 않는다. 기존 불도저에서 공공시설과 연결 공급원까지 함께 철거한다.
- 불가 사유는 `PUBLIC_PLACEMENT_REJECT` 로그와 검사 JSON으로만 확인한다. HUD 설명 문구를 추가하지 않았다.
- 공원/주차도 개별 시설로 배치한다. 기존 주차장 합치기 전시 기능은 그대로이며 도시의 자동 합필을 새로 만들지 않는다.

## 비용·운영 범위

- 카드 선택·고스트·취소는 무료. 유효한 월드 배치 성공 시에만 건설비를 한 번 차감한다.
- 자금은 기존 전기/수도 소수 정산분을 반영한 가용 잔액으로 검사한다. 불가 시 비용/도시/ID/공급원을 변경하지 않는다.
- 월 유지비는 **게임 하루=게임 한 달 경계**마다 현재 시설 합계 차감. 여러 날을 넘으면 각 경계분을 차감한다.
  일할 계산·철거 환급 없음. 유지비가 현금보다 크면 음수 현금을 그대로 기록하며 대출을 생성하지 않는다.
- 새 월수지 엔진/표시를 만들지 않았고, 기존 수지 `—` 자리는 유지했다. 유지비는 실제 자금 및 monthly_upkeep()에서 검증한다.
- 발전5종은 기존 PowerGrid에 평균 순출력으로 연결: 풍력1000(정격2000), 태양광450(정격1800), 석탄8000, 석유16000, 원자력80000 kW.
  별도 연료·바람·일조 엔진 없음. 실제 전선 없이는 민간 건물에 공급하지 않는다.
- 취수1000, 하수장800, 하수처리2400 m³/게임일은 기존 WaterGrid/짝 관망에 연결한다.
  기존 엔진의 전기 연동/오염 부하 모델을 새로 구현하지 않았다. 자체 전력 부하·오염 제거95% 등은 등록 데이터다.
- 급수탑/소각장/재활용센터는 **배치·비용·철거·용량 데이터만**. 저장조 입출고/쓰레기 수집·처리/소각 발전 없음.
- 소방·경찰·교정·의료·교육·화장터·공원·주차도 서비스/출동/행복도/교육/수용 효과 없음.

## 기존 도구 중복 — 삭제하지 않음

| 기존 도구 | 새 C카드와 겹치는 기능 | 유지 상태 |
|---|---|---|
| `power_plant` 발전시설 / 전력 설정 | 발전소 생성·출력 수동 조절 | 기존 무료 시험 도구 그대로 |
| `water_supply` 취수장 | 물 공급원 생성·용량 조절 | 기존 무료 시험 도구 그대로 |
| `water_treatment` 하수처리장 | 하수 처리원 생성·용량 조절 | 기존 무료 시험 도구 그대로 |

실제 시설 C카드는 유료·실측 GLB·CSV 용량이며 위 프로토타입 도구와 병존한다. 통합/제거는 사용자 결정 대기다.
전선·짝 관로 배치 기능/가격은 이번에 교체하거나 과금하지 않았다.

## 코드 / 검토

`core/public_balance.gd`, `public_facilities.gd`, `public_placement_controller.gd`로 데이터/도시/월드 상호작용을 분리했다.

기존 main/불도저/GLB 방향 렌더·공급망을 재사용한다. tools/capture_public_placement.py/.gd,
sync_public_economy.py, audit_public_placement.py로 재현한다. 새 외부 의존성/에이전트 없음, 자체 리뷰다.
원본/빌더 재실행, 행복도·연료·대출·쓰레기·저장조 엔진, 새 HUD/패널, main 푸시는 하지 않았다.
