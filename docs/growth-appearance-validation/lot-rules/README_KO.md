# 승인된 부지 규칙 — 4×4 우선 신축 / 5단계 8×8

기반: 성장 외관 `4077e44`, 브랜치 `feature/growth-appearance`.
사용자 갱신 기획은 **내용 수정 없이** 별도 docs 커밋 `02f505c`에 보존했다.
INITIAL_LOT_SIZE_KO/BUILDING_GROWTH_KO만 의미 변경이 있었고, 함께 지정한 ASSET_REQUEST_GROWTH_KO/ECONOMY_LOOP_SPEC_KO는 이미 추적 중이며 의미 변경이 없어 원문을 유지했다.
AGENTS.md 수정 금지, 원본 애셋 수정 금지, 새 UI 금지 준수.

## 적용

- 자동 신축: 기존 시간·수요 게이트를 유지하고, 동일한 bounded fair scan에서 **4×4 우선 → 2×2 폴백**.
  두 크기 모두 안 되면 미건설. 한 간격에 최대1동은 유지한다. 용도별 원본 소형 외관/레벨1.
- 4×4 전체 동일 용도, 한 도로 로컬 블록, 접도1.5m·정면·도로/건물/시설/교차로 충돌 공통 경로를 통과한다.
- 수동 성장: 다음 단계2~4에서는 최대4×4, 다음 단계5에서8×8 우선. 안 되면4×4/현재 부지 유지.
  기존보다 작은 부지는 후보에서 제외한다. 남의 건물 철거·자동 합필 없음. 최종 단계5에서 추가 단계 상승 없음.
- 구획에서 신축한 건물의 확장 전체도 동일 용도로 지정되어야 한다. 정면/공간 판정은 기존 경로를 재사용한다.
- 새 authored 8×8 검토 배치도 단계5로 시작한다. 이미 존재하는 조기 단계8×8 데이터는 축소하지 않고 큰 외관을 유지한다.
- 무작위 크기 추첨 함수는 삭제했다. config의 size_weights는 옛 fixture 호환용 비활성 필드이며 사용하지 않는다.
  +100 수동 버튼, 성장 기준100, 이웃 연쇄 확률/상한 등 숫자는 그대로다. 행복도 경험치·자동 밀도 성장 구현 없음.

## 정원·수요 보존

기존 population.gd/설정/가격·용량 파일은 변경하지 않았다.
4×4 가구 정원과 상업·공업의5개 일자리 밴드는 각각 **2×2 정원의4배**인 기존 면적 비례다.
실제 주민이 있는 상태의 수요가 신축 후 증가하지 않고 음수가 되지 않음, 주거 수요 게이트, 무료 신축,
한 기존 인구 tick에 한 가구만 입주하는 속도를 검사했다.

**남겨 둔 기존 한계:** 상업·공업의 수요식은 여전히 건물 동수로 차감한다. 4×4 한 동과2×2 네 동의
정원은 같지만 수요 차감량까지 동일하다고 주장하지 않는다. 이번 '시뮬레이션 수치 변경 금지' 범위에서
면적환산 수요식이나 수요 기반 자동 성장을 새로 구현하지 않았다.
