# CITIES_DO 1차 산업 애셋 제작 요청 — 메인 건물 9종 + 작업지 타일 9종

도시 시뮬레이션 게임 CITIES_DO에 쓸 **1차 산업(농업·임업·광업·석유·어업) 애셋**을 Blender 스크립트로 만들어 주세요.
기존 건물·시설 시리즈와 같은 방식·톤이어야 합니다.

## 1. 게임 규칙 (왜 이렇게 만드는지)

- 1칸 = 4m. 플레이어가 **메인 건물**을 직접 배치하면, 건물 주변의 자원 지형 위에 **작업지**(밭, 벌목지, 채굴지 등)가 **1칸(4×4m) 단위로 자동으로** 넓어집니다.
- 작업지 칸 위에 도로나 다른 건물이 생기면 그 칸만 사라집니다. 그래서 작업지는 **1칸짜리 타일을 이어 붙이는 방식**으로 만듭니다.
- 작업지 타일은 옆 칸과 이어 붙였을 때 **이음매가 티 나지 않아야** 합니다(네 변 모두 연속).
- 게임은 위에서 비스듬히 내려다보는 아이소메트릭 시점입니다.

## 2. 공통 규격

- 메인 건물 부지는 **정확히** 16×16m(4×4칸). 건물·마당·차량 진입로 모두 부지 안에. 바닥판·지면 높이는 기존 애셋과 동일(일부 바닥판 z=-0.12m까지 허용).
- **정면은 Blender 기준 -Y 한 면, 위쪽은 +Z**(Godot으로 내보내면 +Z 정면 = 도로 쪽). 출입구·하역문·차량 진입구는 정면 쪽.
- 층고는 기존 시리즈와 동일(약 3.05m). 사람(1.75m)·트럭(약 7~8m)과 비교해 축척이 자연스럽게.
- 작업지 타일은 정확히 4×4m, 높이는 낮게(지면 z=0 기준, 작물·그루터기·소품만 위로). 타일 하나 삼각형 **약 300~1,500개**.
- 기존 시리즈 톤: 단순한 매스와 또렷한 실루엣, 저채도 팔레트. 업종이 한눈에 보이게.
- **외부 모델·외부 텍스처·생성형 이미지 금지.** Blender 스크립트 지오메트리, 재질 색, 시스템 폰트만.

## 3. 산출물

폴더 `assets/primary-industry/{id}/`
- `{id}.blend` — 원본
- `building.png`(메인 건물) 또는 `tile.png`(작업지) — 900×1100px(타일은 900×900px), 정사영 카메라, 앙각 30°, 투명 배경, 기존 애셋과 같은 구도
- 작업지 타일은 추가로 `tile-3x3.png` — 같은 타일 3×3장을 이어 붙인 미리보기(이음매 확인용)
- `metadata.json`:
```json
{
  "id": "{id}", "name": "{한글 이름}", "kind": "primary_main|primary_work_tile",
  "industry": "farm_grain|farm_vegetable|farm_livestock|forestry|mine_iron|mine_coal|oil|mine_uranium|fishing",
  "footprint_cells": [N, N], "cell_meters": 4, "lot_meters": [N*4, N*4],
  "floors": 0, "footprint_status": "user-specified", "front": "-Y (Blender) / +Z (Godot)",
  "vertex_bounds_m": [[minX, minY, minZ], [maxX, maxY, maxZ]],
  "source": "original scripted Blender geometry; system font; no external models, textures or generation APIs"
}
```

## 5. 진행 방식

- 먼저 **곡물 농장(#1) + 곡물 밭 타일(#10)** 한 쌍을 만들어 확인받은 뒤 나머지를 진행해 주세요(메인 건물과 타일의 톤·축척 기준을 잡기 위해).
- 각 애셋 완료 시 png를 보여주고, 실측 크기(W×D×H m)와 삼각형 수를 함께 보고해 주세요.
- 타일은 `tile-3x3.png`로 이음매가 없는지 꼭 확인해 주세요.
- 부지 크기·정면 방향이 규격과 다르면 제출 전에 직접 바로잡아 주세요.
