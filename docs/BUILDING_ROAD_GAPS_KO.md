# 건물이 도로에서 떨어져 보이는 원인

**과거 진단 기록:** 이후 사용자가 최대 1.5m와 도로 옆 격자를 확정했다.
[현재 적용 규칙·새 화면](BUILDING_ROAD_ADJACENCY_KO.md)을 먼저 확인한다.
아래 10m/비교 장면 간격은 변경 전 상태의 기록이다.

2026-11-02. 사용자 요청에 따라 원인을 조사했다. **도로 접근 판정이 실제 접도가 아니라
최대 10m의 근접 판정이고, 비교 장면의 배치 여백과 모델 내부 앞마당이 더해진다.**
이전 정면 방향 수정은 방향을 맞춘 작업이며 부지를 도로에 붙이는 조건을 추가하지 않았다.
이번 작업은 진단과 재현 기록이며 제품 배치 조건·모델·기존 도시 위치를 바꾸지 않았다.

## 1. 배치가 도로와 떨어져 있어도 허용된다

`cities_do/core/growth_config.gd`의 `road_access_distance = 2.5`는 셀 단위다.
1셀=4m이므로 **부지와 일반도로의 가장자리 사이 간격 10m 이하**이면 접근 가능하다.
`city_model.gd::_polygon_error()`는 이 최소 거리만 검사한다.
부지 정면이 보도와 변을 공유하는지, 출입문까지 연결로가 있는지는 검사하지 않는다.

일반 UI의 `add_building_at()`은 클릭한 구획의 깊이 v를 그대로 사용한다.
구획 원점 자체는 보도 바깥 경계에 있지만 `v=1,2`를 선택하면 부지가 뒤로 밀린다.
성장 시에도 같은 근접 조건으로 후보를 찾으므로 도로 접촉을 강제하지 않는다.

이번 실제 모델 실행으로 세 각도(수평·수직·약 21.2도), 도로 양쪽, 네 깊이를
검사한 **24개 사례**에서 같은 결과를 얻었다.

| 구획 깊이 v | 부지와 도로 바깥 경계 간격 | 신축 결과 |
| ---: | ---: | --- |
| 0 | 0m | 허용 |
| 1 | 4m | 허용 |
| 2 | 8m | 허용 |
| 3 | 12m | 거부 |

[실행 결과](road-gap-validation/gaps.json), [로그](road-gap-validation/audit.log).
수직·대각선 사례의 0m에는 작은 부동소수점 오차가 있을 수 있다.

## 2. 기존 비교 장면도 떨어뜨려 배치했다

직전 [정면 방향 비교 화면](frontage-validation/road-facing.png)의 네 방향 맨션은
`tools/capture_building_frontage.gd`에 명시한 좌표 때문에 **네 곳 모두 부지와 보도 사이가 4m**다.
예를 들어 첫 건물 부지는 y=10~14, 도로 중심은 y=16, 도로 반폭은 1셀이다.
도로 바깥 경계 y=15와 부지 끝 y=14 사이에 1셀=4m가 남는다.
이 여백은 이전 비교 장면을 만들 때 남긴 배치 여백이다.
방향을 검증한 결과를 도로에 붙이는 기능의 완성으로 설명하면 안 된다.

`residential_showcase.gd`의 주거 10종 전시도 부지 앞쪽 꼭짓점 x+y=90,
도로 중심선 x+y=94, 반폭 2셀이다. 따라서 최소 간격은
`(4/√2 − 2) × 4 ≈ 3.314m`로 **10종 모두 떨어져 있다.**
세계 좌표축에 맞춘 부지와 대각선 도로라서 정면 변 전체가 도로와 평행한 배치도 아니다.

이 수치는 이번에 기존 장면의 실제 CityModel 배치를 다시 생성해 측정했다.
링크한 화면은 직전 작업의 실제 캡처이며 이번에 새로 촬영한 이미지로 표시하지 않는다.

## 3. 부지가 붙어도 벽은 앞마당만큼 떨어질 수 있다

모델의 부지와 건물 본체는 같은 크기가 아니다. 앞마당·출입 보행로·조경이 부지 안에 있다.
이전 Blender 실측 결과에서 원본 정면(-Y)의 부지 경계부터 본체 벽까지 계산하면 다음과 같다.

| 모델 | 부지 안 정면 여백 |
| --- | ---: |
| 단층 전원주택 | 2.15m |
| 2층 타운하우스 | 1.90m |
| 정원형 단독주택 | 4.70m |
| 안뜰형 연립주택 | 4.05m |
| 벽돌형 / 모던형 맨션 | 각 3.35m |
| 발코니 아파트 | 4.20m |
| 코너 주거타워 | 4.10m |
| L자형 주거 아파트 | 5.50m |
| 계단형 주거타워 | 5.75m |

출입구·차양·계단 등 돌출부는 본체보다 도로에 가까울 수 있다. 이 표는 문까지의 거리가 아니다.
수치는 [앞마당 계산](road-gap-validation/model-setbacks.json)에 보존했다.
이번에는 원본 Blender를 다시 측정하지 않고 [이전 실측](scale-validation/source-measurements.json)을
사용했다. 원본 모델은 이후 변경되지 않았다.

직전 화면의 맨션은 **부지 바깥 빈 공간 4m + 부지 안 여백 3.35m = 벽까지 약 7.35m**다.
도로 폭에는 이미 보도가 포함되어 있다. 검은 아스팔트부터 재면 현재 2차로 보도 약 1m까지
더해져 벽까지 약 8.35m로 보인다. 같은 모델·방향 규약의 정면 기준 예시다.
이는 축척을 일괄 조정해야 한다는 근거가 아니다. 현재 표시 앵커의 오류가 원인이라는
증거도 이번 거리 조사에서는 발견하지 않았다.

## 권장 수정 방향 (이번에는 미적용)

- **부지의 앞면이 보도 바깥 경계에 실제로 접하도록** 신축·성장 후보를 검증한다.
  가까운 꼭짓점 하나의 거리만으로 앞면 접도를 인정하지 않는다.
- 구획 도구에서 도로 뒤쪽을 지정해도 도로에서부터 유효 부지를 구성하도록 배치 흐름을
  정리한다. 단순히 v=0으로 덮어쓰면 겹침·모퉁이·다른 도로를 향한 부지를 잘못 처리할 수 있다.
- 비교 장면도 실제 접도 규칙을 따르는 도로 로컬 부지로 갱신한다.
- 앞마당은 부지 안에 남길 수 있다. 필요하면 주택·도심 공동주택별 여백을 별도로 검토한다.
  모델 전체 확대나 부지 밖으로 밀기로 해결하지 않는다.
- 이미 도로에서 떨어진 건물은 일괄 이동하지 않는다. 기존 도시 충돌과 도로 철거 후
  단절된 건물의 처리도 별도 정책으로 정한다.

이번에는 원인 확인 요청에 맞춰 배치 조건과 앞마당 크기를 변경하지 않았다.
전체 게임 회귀 검사는 재실행하지 않았으며, 위 24개 재현과 비교 장면 4+10개 실측을 새로 실행했다.
