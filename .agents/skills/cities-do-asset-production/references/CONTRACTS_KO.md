# 기존 제작 방식과 제출 계약

우리가 현재 재현 가능한 방식은 Blender Python으로 직접 지오메트리를 만들고,
같은 파일에서 정사영 카메라로 투명 PNG를 렌더하는 방식이다. Claude 계정·API 키가
필요하지 않다. 생성형 그림만 있고 3D 원본이 없는 과거 시안과 혼동하지 않는다.

## 외형과 축척

- 단순한 매스, 읽히는 실루엣, 저채도 기본 팔레트. 유리·금속·콘크리트는 재질로 구분.
  도로 아스팔트 `4c5659`, 흰 선 `e8e7dc`, 황색 선 `e4bd5f` 등 실제 recipe 색을 기준으로 한다.
  서비스 표시색만 선명하게. 같은 부지에서 밀도가 다르면 높이·볼륨 차이가 보여야 한다.
- 사람 1.75m, 승용차 약 4.6m를 비교 기준으로 사용한다. 1 Blender 단위 = 1m.
  바닥/발바닥 z=0. 건물의 기존 플린스는 −0.12~+0.12m일 수 있으므로 바닥 기준을 함께 쓴다.
- 정사영 카메라, 수평에서 30° 내려다봄. 건물은 정면/옆이 보이는 구도와 여백을 유지.
  건물 900×1100, 작업 타일 900×900, 차량 8방향 430×245 등 실제 profile 설정이 우선이다.
  렌더 화면에 맞추려고 모델 축척을 바꾸지 말고 카메라만 조정한다.
- 간판은 시스템 오픈 폰트 + 실제 텍스트 지오메트리. 창문/간판/출입구가 가려지지 않는지
  실제 렌더를 본다. 간판이 흰 벽과 묻히거나 차양·출입구 박스에 잘리는 문제를 재발시키지 않는다.
  상업은 간판·쇼윈도로 주거와 구분하고, 보석/명품은 대형 상업에만 쓴다.

## 부지와 카테고리

일반 성장 건물은 2×2=8×8m, 4×4=16×16m, 8×8=32×32m. 8×8은 최종 성장 단계에만
사용하며 이번 묶음의 성장건물 14종에는 없다. 크기와 밀도는 별도 항목이지만 최신 게임
해금 규칙을 어기지 않는다. 산업 메인 건물은 4×4, 확장 작업지는 1×1 타일인 별도 계약이다.
서비스 시설은 사용자가 정한 부지(예: 주차장 2×4/4×4/4×8)를 따른다.

건물·조경·담장 등은 부지 안에 배치한다. 정확한 실측은 모디파이어 적용 후 월드 좌표
vertex 전체로 계산한다. 오버행이 있으면 숨기거나 nominal 값으로 덮지 말고 보고한다.
정면 Blender −Y / Godot +Z를 적고 출입·하역구는 도로 쪽에서 접근할 수 있게 한다.
작업지 광산은 반복 구덩이 대신 이어진 낮은 바닥. 곡물은 승인된 매끈한 황금 이랑
(6afefd8 계열), 목초지는 소 없는 01 + 위치가 다른 02/03. 철은 붉은 크러셔/광석,
석탄은 검은 석탄 더미/컨베이어로 실루엣까지 다르게 만든다.

## 차량

Blender 전방 −Y, 왼쪽 +X, 위 +Z, 왼쪽 운전석. 바퀴 밑면 z=0. 미러는
몸체→마운트→암→하우징이 실제로 맞닿아야 한다. 구급차는 가상 한국형 하이루프 승합형,
높이 3.4m 이하. 쓰레기차는 압축 적재함/후면 리프트와 녹색+흰 띠, 높이 3.3m 권장.
`spec.json`의 nominal 차체 크기와 미러·지붕 설비 포함 실측을 구분한다.
실제 제조사 로고/모델의 복제보다 기능을 읽을 수 있는 가상 디자인을 사용한다.

## 시민

공유 뼈대 1개, `body/hair/top/bottom` 4개 메시, 각 1개 회색 재질.
Idle 키 1.75m, 1,500tri 이하. 파일명 `<layer>_<direction>_<frame>.png`.
64×96, 40px/m, 발 기준점 (32,84), S/SE/E/NE/N 각 0/45/90/135/180°,
걷기 4 + idle = 100장. `Walk` 실제 샘플은 1/5/9/13, 17이 1과 일치한다.
층 겹침은 `layer-depths.npz`의 uint16 카메라 깊이(작을수록 앞, 65535는 투명)를 함께 써서
픽셀별 정렬 후 tint/alpha-over 한다. PNG 4장을 고정 순서로 그리면 팔·다리 가림이 틀린다.
코드 기준은 `compose_citizen_pilot.py`; 미래 옷 조합은 별도 검증한다.

## 신호등

운전자가 보는 왼쪽→오른쪽 빨강/노랑/초록 좌회전←/초록. 각 등 별도 메시와 on/off 재질.
원본은 모든 등 off. 가로대 −X, 머리 아래 노면 여유 4.5m 이상, 한 방향만 렌즈.
`.blend`의 fake-user는 GLB에서 미사용 재질을 보존한다는 보장이 아니다.
후속 exporter는 lamp 이름과 `material_definitions`의 켜짐 재질 정의를 반드시 보존해야 한다.
신호 주기/교통 AI/게임 배치는 이 제작 묶음의 검증 대상이 아니다.

## 제출/적용

애셋만 별도 브랜치에 올린다. 현재 사용자 요청에 다른 지시가 있으면 그것을 따른다.
원본 generator/의존 파일/라이선스/미리보기/메타데이터/검사 보고서와 재현 명령을 함께 보관한다.
원본 스타일에서 달라질 필요가 생기면 차이와 근거를 먼저 설명한다. 현재 요청에 없는
부지/성장/가격/용량/유지비/도로 규칙을 임의 확정하지 않는다. 승인된 애셋을 자동 교체하거나
게임 catalog/main에 자동 적용하지 않는다. 존재하지 않는 과거 결과를 복구했다고 말하지 않는다.
