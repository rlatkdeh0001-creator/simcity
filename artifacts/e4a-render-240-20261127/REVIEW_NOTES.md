# E4a 렌더 계수기 — 240초 제한 유지

- C의 최초 v4는 두 배 규모의 60프레임 확인 뒤 71개 단언에서 종료 1(240초). 동일 소스의 분리 재실행은 완료됐고, 고정 C 계측에서도 원래 시간 초과는 재현되지 않았다. 그 계측에서는 2× 도로 편집 29.66초, 이후 렌더 동기화 0.94초로 비용을 분리했다.
- 테스트의 실제 도로변 구획만 4줄에서 1줄로 줄였다. 생산 코드, 74개 단언, 각 장면의 실차 4,800대·차량당 조회 1회·실제 커넥터·2배 도로/구조물·60 이동 프레임·실제 도로 편집 양성 대조는 그대로다. 계측한 2× 도로 편집은 5.89초였다.
- 고정 C의 무계측 수정본 74/74, 50.99초. B `8efb674` 위 통합 무계측 실행 **74/74, 48.516초**, 종료 0, 진단 없음. 제한은 계속 240초다. 이 수치는 테스트 실행 시간이지 프레임 성능이 아니다. [결과/해시](results.json), [통합 원시 로그](integrated-b.log).
