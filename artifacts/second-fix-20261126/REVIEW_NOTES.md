## 확인 대기
- 점 수가 다를 때만 이전 높이 프로필의 경사 전환점을 새 중심선의 전체 길이 비율에 맞춰 옮긴다. 같은 점 수에서는 기존대로 같은 점 번호의 높이를 사용한다. 길이가 줄어 경사가 맞지 않으면 높이를 낮추지 않고 거절한다.
- 기존 교각을 통과하도록 뒤늦게 공사하는 경우에는 자동 이동 대신 미리보기·확정을 거절한다. 기존 도로·철도를 피해 새 교각을 설치하는 방향은 이전 탐색을 유지한다.
- 현행 건설이 허용하지 않는 독립 지하철 띠·역 겹침은 기존 배치가 남아 있는 상황을 재현하도록 fixture에만 직접 구성했다. 건설 규칙은 변경하지 않았다. 차량 y-sort는 실제 차량 스프라이트를 정지 위치에 두고 비교했다. 선택 건물의 HUD 정보는 유지한다.
