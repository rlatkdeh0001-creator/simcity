# E3a 고가 철도·철교 — 구현·검증 기록 (cities-claude, 2026-11-19)

브랜치 `perf/render-sim-cadence`, 기준 HEAD `960e9c2` 위 E3a 단계 커밋이다. 사용자 예외 승인으로 cities-claude가 직접 구현했다.

## 한 일

- **높이 데이터(`transit_routes.gd`)**
  - 철도(rail) 선로에 점마다 높이 `heights_m`(m, 0 이상)를 선택 항목으로 둔다. 도로 `heights_m` 방식을 따랐다.
  - 높이가 없는 기존 선로·저장 파일은 지상(0m)으로 본다. `snapshot_error`는 높이·교각이 있을 때만 검사한다.
  - 지하철(metro)은 높이를 받지 않는다("지하철 높이는 바꿀 수 없습니다"). 음수는 "지하 철도는 아직 지을 수 없습니다"로 거절한다.
- **경사(`road_height.gd`)**
  - `grade_for("rail") = 3.5%`. 10m 오르는 최소 길이는 288m(72칸), 5m는 144m이고, 8m 단위로 올린다.
  - 경사 검사는 `profile_error` 한 함수로 도로·철도가 함께 쓴다. 같은 방향으로 이어지는 모든 조각을 한 경사로로 재며, 마지막 조각만 재지 않는다(E1 버그 재발 방지).
  - 경사 초과는 빨강 "경사가 너무 급합니다", 길이 부족은 "경사로 길이가 부족합니다"이다.
- **철교 구조**
  - 구조물 폭 `STRUCTURE_WIDTH = 10.0m`. 도상과 전주는 기존 철도 규격(±3.8m 안, 전주 ±4.0m)이다.
  - 교각은 E1 `Height.supports`를 그대로 써서 중심선 1개, 기본 32m, 밑을 피할 때 16~48m 간격으로 둔다. 결과는 `route.piers`에 저장한다.
  - 그리기는 `elevated_road_renderer.build_road`를 재사용한다. 옆면 띠, 0→+5m 옹벽·흙 채움, +5m부터 교각·상판, 4m 조각 그리기 순서가 모두 E1과 같다.
  - 철도는 아스팔트·차선·중앙선 대신 `transit_view`가 만든 상판 선로 조각(`geometry.deck`: 도상 → strip/strip_rails)을 같은 4m 조각에 넣어 높이 h만큼 올려 그린다.
  - 구조물은 오른 구간(`LEVEL_SPLIT_M = 0.005m` 위)에만 만든다. 지상 구간은 기존 지상 선로 띠로 남는다.
- **전차선(`rail_catenary.gd`)**
  - 지상·상판 모두 같은 3.8/4.8/5.3m, ±4.0m, 32m 배치다. 상판·경사로 위 항목은 선로 높이를 더해(`a_height/b_height += h`) 높이를 따라간다.
  - 상판 위에서는 지상 마스크(도로·역 부지)와 지상 건너선을 적용하지 않는다.
  - 상판 전차선은 자기 상판 면 뒤, 바깥 방호벽 앞 깊이로 정렬한다(`cached_world_renderer.deck_catenary_depth`).
- **열차**
  - 상판·경사로 위 열차는 E1 `lift_vehicle`로 그림만 올린다(`rail_height_m` 메타).
  - 운행·경로·회차는 바꾸지 않았다. 다만 노선 그래프(`transit_line_planner.build_graph`)는 같은 높이에서 만나는 선로만 잇는다. 그래서 철교가 지상 선로 위를 지나도 분기가 생기지 않는다.
- **규칙(`transit_routes.plan`, `city_model`)**
  - 고가 철도 밑에는 구획 칸을 두지 않고 건물을 짓지 않는다. 지상 선로와 같이 옆 구획을 만들지 않는다.
  - 건물 위로 지날 때 구획 건물은 노랑 + 경고 B(`road_demolition_warning.gd` 재사용, 확인 후 철거)이다. 확정할 때 철거 ID가 미리보기와 같아야 한다.
  - 공공시설·발전소·정수시설은 빨강 "공공시설과 겹침"이다. 공원은 +5m 이상 상판 밑에서 통과한다(E1 `usable_under_deck`). 빈 땅·물·도로는 통과한다.
  - 수직 간격: 고가·지하 도로, 고가 철도와 위아래로 겹치면 `overlap_error`로 10m 미만일 때 빨강 "수직 간격 부족"이다. 지상 도로 위를 10m 이상으로 지나면 건널목을 만들지 않는다. 도로와 철도는 지면 밖에서는 같은 높이라도 만나지 않는다.
  - 높이가 다른 선로 끝은 서로 잇지 않는다("높이가 다른 선로와는 이을 수 없습니다").
  - 도로를 철교 교각 위에 그으면, 또는 철교를 도로 고가 교각 위로 지나게 하면 "교각과 겹침"으로 거절한다.
  - 역은 지상 선로에만 둔다. 역 포트가 고가 구간에 닿으면 빨강 "고가 구간에는 역을 둘 수 없습니다"이다(선로를 먼저 짓든 역을 먼저 짓든 같다).
  - X 건너선(`terminal_crossover.gd`)은 역 앞 8칸 선로 중 하나라도 오르면 두지 않는다.
- **UI**
  - 철도 도구에 시안 2 C `road_height_controls`를 재사용했다(`rail=true`, 이름 `RailHeightControls`): 지상/고가 토글, −/+5m, PgUp/PgDn ±5m.
  - 지하 버튼은 철도에서 비활성이다(E3b).
  - 미리보기는 시작점 높이에서 목표 높이까지 최소 경사로 길이로 오르고, 그 뒤는 목표 높이를 유지한다. 초록·노랑(철거 경고)·빨강 띠는 높이만큼 올려 그린다.
- **비용**: 아래 '임시값'을 보라.
- **기타**: `transit_view.append_road_tunnels`가 도로 위상이 없는 형상 전용 스텁(`test_rail_catenary`의 City)에서 `road_visuals`·`junctions`를 선택적으로 읽게 했다. 이 오류는 E2 커밋(f72368e)부터 있었고, 저장소 원본에서 SCRIPT ERROR 27줄이 나는 것을 확인했다. 판정 결과는 바뀌지 않는다.

  - 마지막 캡처에서 뜨는 물체, 구멍, 열린 끝, 상판에서 떨어진 전차선은 보이지 않았다.
- 성능 측정은 하지 않았다.

## 임시값 (가격은 나중에)

- `elevated_road_config.json`의 `rail_height_cost`는 `enabled:false`, `pending_user_approval`이다.
  - 길이 가중 `1 + (h / 10m)^2` 상대 계수를 미리보기 결과 `height_cost_factor`로만 낸다. 돈은 받지 않는다.
  - 계수를 끄거나 바꾸려면 설정 한 곳만 고치면 된다.

## 확인 대기 (문서에 없어 되돌리기 쉬운 쪽으로 정함)

1. **선로 모양을 바꿀 때 높이 처리**: 고가 선로의 점 수가 바뀌는 재편집(`update_transit_route`)은 지상으로 다시 그린다. 같은 점 수면 높이를 유지한다. 재편집 중 철거가 필요하면 거절한다(경고 B는 새로 그릴 때만).
2. **도구 높이**: 철도 도구에는 0과 +5m 단위만 있다. PgDn은 0 아래로 가지 않는다.
3. **열차 높이**: 열차 그림 높이는 가장 가까운 고가 선로 구간의 높이를 쓴다(진행 방향이 맞는 구간). 운행 상태에는 높이를 넣지 않았다.
4. **상판 위 전차선 그리기 순서**: 같은 노선 상판의 앞 방호벽 조각보다 바로 앞쪽 깊이로 정렬했다. 다른 고가 구조와 겹치는 복잡한 경우는 검토가 필요하다.
5. **도로×철도 높이 교차**: 지면 밖에서는 같은 높이라도 서로 잇지 않고 겹치면 "수직 간격 부족"이다(고가 도로–철교 접속은 범위 밖).
6. **철교 구조 폭**: 정비·피난 통로 표현 없이 10.0m 콘크리트 상판에 도상 띠만 올렸다.

## 알려진 문제

- 철교 양 끝 경사로 발치(0m 부근)의 구조 시작면은 E1 경사로와 같은 방식으로 그린다. 아주 짧은 경사로(8m 단위 최소 길이 미만)는 거절되므로 보이지 않는다.
- 상판 위 선로 띠는 도상 다음 strip/strip_rails 순서다. 여러 고가 노선이 겹치는 경우는 수직 간격 규칙으로 막는다.
