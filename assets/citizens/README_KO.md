# CITIES_DO 시민 원본

현재 adult-pilot-01 성인 시험형1명만 제작했다.
[원본 크기 시트·걷기·규격·검증·깊이 합성 계약](../../docs/citizen-adult-pilot/README_KO.md).
100개 부위 PNG는 독립 부위 형태이며 같은 파일명별 깊이는 layer-depths.npz에 있다.
게임의 고정4층 그리기만으로는 옆모습 가림이 달라질 수 있으므로 이 합성 계약을 확인한다.
게임 등록/렌더러 적용은 포함하지 않는다. 지오메트리/스킨/뼈대는 원래 스크립트 제작이며 외부 모델/텍스처/생성 API 없음.
