# 재활용센터 — 사용자 검토용 시안

8×8칸(32×32m)은 시안용 부지 제안이며 도로변 육상 설치를 의도합니다. 낮은 녹색 선별동, 반입구 2개, 종이·플라스틱·유리·금속 분류함, 컨베이어, 지붕이 있는 압축 재활용품 출하장을 표현했습니다. 굴뚝·소각로·매립지는 없습니다.

사용자 승인 대기, 게임 미등록입니다. building.blend 편집 원본, building.png 정면, reverse-review.png 뒷면, metadata.json 규격을 포함합니다. 쓰레기 수거·선별·재활용 시뮬레이션은 구현하지 않았습니다.

재생성: 저장소 루트에서 `blender --background --factory-startup --python-exit-code 1 --python assets/waste-study/build_recycling-center.py`. Blender 4.3.2 CPU, 30도 정투영, 900×1100 투명 RGBA. 외부 모델·텍스처 없이 제작했으며 간판용 글꼴 사용 조건은 상위 FONT_LICENSE.txt를 참조하세요.
