# 소방시설 3종 — 사용자 검토용 시안

공통 빨간 스타일을 유지하고 형태를 다르게 만들었다.

- small-fire-station: 4×4, 단층 박공지붕·2대 차고.
- fire-station: 6×6, ㄱ자 배치·3층 사무동·3대 차고.
- regional-fire-station: 8×8, 큰 4층 본관·돌출 유리 지휘실·세로 FIRE 표식·4대 차고.

크기·층수·차고 수는 시안 제안이다. 모두 도로변 육상 설치를 의도하며 승인 대기·게임 미등록이다. 출동·화재·서비스 범위 시뮬레이션은 미구현이다.

각 폴더: building.blend 편집 원본(간판용 글꼴 포함), building.png 정면, reverse-review.png 뒷면, metadata.json 부지·형태·승인 상태. 소방차는 자체 제작한 정지 조형이며 실제 차량 시스템은 아니다.

Blender 4.3.2 CPU, 30도 정투영, 900×1100 투명 RGBA. 종류별 카메라 프레이밍이 달라 화면상 크기가 실물 크기 비율을 뜻하지 않는다. 외부 모델·텍스처 없이 제작. 글꼴 조건은 FONT_LICENSE.txt 참조.

재생성: 저장소 루트에서 `blender --background --factory-startup --python-exit-code 1 --python assets/fire-study/build_small-fire-station.py`처럼 각 build_*.py를 실행한다.

설계: docs/design/FIRE_TAB_KO.md.

## 광역 소방서 수정

사용자 요청에 따라 낮은 본관과 별도 훈련탑 구성을 폐기하고 4층 대형 본관 중심으로 재설계했다. 1층은 출동 차고, 상층 3개 층은 지휘·사무 공간이다. 옥상 통신설비는 추가 층수가 아니다. 8×8 부지는 시안 제안이며 수정안은 승인 대기다.

## 광역 소방서 옥상 헬기장

사용자 추가 요청에 따라 4층 본관 옥상에 H·원형 표시·경계선·모서리 조명을 갖춘 14.8×14.8m 착륙장 조형을 추가했다. 공조설비와 안테나는 가장자리로 이동했다. 지붕 설비이며 점유 층수는 4층 그대로다. 헬기 이동·출동·착륙 동작은 이번 외관 작업 범위에 포함하지 않았다.

## 옥상 계단실 출입구

착륙장에서 본관으로 내려가는 계단실 출입구와 L자 연결 통로를 옥상 오른쪽에 추가했다. STAIRS 표지·문·유리창·방향 화살표를 표현했다. 착륙장 외곽과 계단실 사이 간격, 옥상 경계 및 통신설비 이격을 모델 생성 시 검사한다. 계단실은 옥상 출입용 설비 공간으로 본관 점유 층수는 4층을 유지한다. 현재 외관 조형이며 인물 이동·실내 계단 내비게이션은 미구현이다.
