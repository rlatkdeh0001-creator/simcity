# AUREL GRAND 대형 백화점

32×32m, 8층. 넓은 매장 양익과 중앙 유리 아트리움, 옥상 채광창, 보석 모양 간판을 갖춘 고밀도 상업 디자인입니다.

승인 대기 중인 시안으로 게임에는 등록하지 않았습니다. 상호는 가상 이름입니다. 고밀도 표기는 디자인 분류이며 성장 규칙 구현을 뜻하지 않습니다.

- building.blend: 편집 가능한 원본(간판용 글꼴 포함)
- building.png: 정면 투명 PNG
- reverse-review.png: 뒷면 검토 PNG
- metadata.json: 부지·층수·투영 규격과 승인 상태

저장소 루트에서 `blender --background --factory-startup --python-exit-code 1 --python assets/commercial-study/build_large-8x8-grand-department-09.py`로 재생성합니다. 글꼴 라이선스는 상위 FONT_LICENSE.txt를 참조하세요. Blender 4.3.2 CPU 렌더, 외부 모델·텍스처 미사용.
