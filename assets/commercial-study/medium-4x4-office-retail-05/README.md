# 중형 상업 1번 — 업무·상가 복합빌딩

4×4칸(16×16m), 지상 4층의 검토용 시안입니다. 1층 약국·베이커리와 별도 사무실 출입구, 위층 사무실 창을 표현했습니다. 보석·명품 요소는 없습니다.

- `building.png`: 정면 투명 PNG
- `reverse-review.png`: 뒷면 검토 PNG
- `building.blend`: 편집 가능한 원본(간판용 글꼴 포함)
- `metadata.json`: 규격, 투영 기준점, 승인 상태

사용자가 디자인을 승인했습니다. 게임 카탈로그 등록은 아직 하지 않았습니다. 재생성은 저장소 루트에서 `blender --background --factory-startup --python-exit-code 1 --python assets/commercial-study/build_medium-4x4-office-retail-05.py`를 실행합니다. 글꼴 라이선스는 상위 폴더의 `FONT_LICENSE.txt`에 있습니다.
