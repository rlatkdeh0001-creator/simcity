# 대형 상업 2번 — NOVA 오피스 타워

4×4칸(16×16m), 지상 10층. 저층 상업 2개 층과 상층 사무실 8개 층입니다. CAFE·TECH 간판, 별도 OFFICE 출입구, NOVA 세로 간판, 상층부 2단 후퇴와 옥상 설비를 표현했습니다. NOVA는 시안용 가상 상호입니다.

사용자 승인 대기, 게임 미등록입니다. 고밀도 분류는 디자인 의도이며 성장 규칙 구현을 뜻하지 않습니다.
