# 대형 상업 1번 — AUREL 백화점

4×4칸(16×16m), 지상 8층, 고밀도 상업용 디자인 시안입니다. 저층 2개 층과 상층 6개 층으로 구성하고, 큰 쇼윈도, 보석 모양 간판, 석재 세로 장식과 AUREL 간판을 표현했습니다. AUREL은 시안용 가상 상호입니다.

사용자 승인 대기 중이며 게임에는 미등록입니다. `density: high`는 디자인 분류이며 게임의 고밀도 성장 조건을 구현했다는 뜻은 아닙니다.

building.blend 편집 원본, building.png 정면, reverse-review.png 뒷면, metadata.json 규격을 포함합니다. 원본 생성 스크립트는 상위 build_large-4x4-department-07.py, 글꼴 라이선스는 FONT_LICENSE.txt입니다. 기존 Blender 4.3.2 명령 방식으로 재생성할 수 있습니다.
