# NOVA CENTRAL 트윈 복합타워

32×32m. 3층 상업 포디움 위에 사무실 11층·9층의 두 동을 배치한 최고 14층 고밀도 상업 디자인입니다. 저층 CAFE·TECH 매장과 별도 업무 출입구, 옥상 정원을 표현했습니다.

승인 대기 중인 시안으로 게임에는 등록하지 않았습니다. 상호는 가상 이름입니다. 고밀도 표기는 디자인 분류이며 성장 규칙 구현을 뜻하지 않습니다.

- building.blend: 편집 가능한 원본(간판용 글꼴 포함)
- building.png: 정면 투명 PNG
- reverse-review.png: 뒷면 검토 PNG
- metadata.json: 부지·층수·투영 규격과 승인 상태

저장소 루트에서 `blender --background --factory-startup --python-exit-code 1 --python assets/commercial-study/build_large-8x8-twin-central-10.py`로 재생성합니다. 글꼴 라이선스는 상위 FONT_LICENSE.txt를 참조하세요. Blender 4.3.2 CPU 렌더, 외부 모델·텍스처 미사용.
