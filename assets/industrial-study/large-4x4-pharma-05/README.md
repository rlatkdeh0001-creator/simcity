# 대형 공업 1번 — 제약 생산시설

4×4칸(16×16m), 지상 4층. 제약 생산동, 캡슐 모양 간판, 밀폐형 설비 탱크 2기, 외부 배관, 옥상 공조설비와 하역장으로 업종을 표현한 게임용 디자인입니다. 실제 공정 설계가 아닙니다. 탱크와 옥상 설비는 층수에 포함하지 않습니다.

사용자 승인 대기, 게임 미등록입니다. 대형 분류는 애셋 디자인 분류이며 성장 규칙 변경을 뜻하지 않습니다.

building.blend 편집 원본, building.png 정면, reverse-review.png 뒷면, metadata.json 규격 포함. 재생성: 저장소 루트에서 `blender --background --factory-startup --python-exit-code 1 --python assets/industrial-study/build_large-4x4-pharma-05.py`. Blender 4.3.2 CPU 렌더, 글꼴 라이선스는 상위 FONT_LICENSE.txt 참조.
