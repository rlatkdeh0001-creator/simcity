# 중형 공업 2번 — 전자부품 공장

4×4칸(16×16m), 지상 3층. 밝은 패널 생산동, 가로로 긴 창, 전자칩 간판, 하역 셔터, 외부 배관과 옥상 공조설비로 업종을 표현했습니다. 지붕 설비는 층수에 포함하지 않습니다.

승인 대기 중이며 게임에는 미등록입니다. building.blend 편집 원본, building.png 정면, reverse-review.png 뒷면, metadata.json 규격을 포함합니다.

재생성: 저장소 루트에서 `blender --background --factory-startup --python-exit-code 1 --python assets/industrial-study/build_medium-4x4-circuitworks-04.py`. Blender 4.3.2 CPU 렌더링, 외부 모델·텍스처 없이 직접 제작했습니다. 글꼴 라이선스는 상위 FONT_LICENSE.txt를 참조하세요.
