# CITIES_DO 공업건물 시안

사용자 방향: 공업건물 대부분은 지상 1~4층의 낮은 건물로 구성. 제약회사·화학공장 같은 대규모 시설은 예외적으로 높이를 허용. 대형 공업도 부지 면적과 생산시설 규모로 구분하며 고층화를 기본값으로 삼지 않음.

## 소형 1번 — 금속가공 작업장

`small-2x2-metalworks-01`: 2×2칸(8×8m), 지상 1층. 셔터, 금속 외장, 지붕 환기구, 높은 측창, 자재 팔레트와 하역 표시. 지붕 설비는 층수에 포함하지 않음. 사용자 승인 대기, 게임 미등록.

Blender 원본과 정면·뒷면 900×1100 투명 PNG, 규격 JSON 포함. 외부 모델·텍스처 없이 직접 제작. 간판용 DejaVu 글꼴 사용 조건은 FONT_LICENSE.txt 참조.

재생성: 저장소 루트에서 `blender --background --factory-startup --python-exit-code 1 --python assets/industrial-study/build_small-2x2-metalworks-01.py`. Blender 4.3.2 CPU 렌더링.

## 소형 2번 — 식품가공 작업장

`small-2x2-foodworks-02`: 2×2, 단층. 단열 패널, 냉장 하역문, 출하 상자와 냉각설비. 승인 대기, 게임 미등록.

금속가공 작업장 1번은 사용자 디자인 승인 완료, 게임 등록은 대기 중입니다.

## 중형 1번 — 정밀기계 공장

사용자 지시에 따라 4×4 소형 대신 중형 제작으로 진행. `medium-4x4-precision-03`: 4×4, 단층 생산동 + 2층 사무동, 톱니형 채광 지붕과 하역 셔터. 승인 대기, 게임 미등록. 식품가공 작업장 2번은 디자인 승인 완료, 게임 등록 대기.
