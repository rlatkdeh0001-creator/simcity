# 중형 공업 1번 — 정밀기계 공장

사용자 지정에 따라 다음 제작군을 중형 공업으로 전환했습니다. 4×4칸(16×16m), 최대 지상 2층. 생산동은 단층의 높은 작업공간, 사무동은 실제 2층으로 구성했습니다. 톱니형 채광 지붕은 추가 층이 아닙니다.

하역 셔터 2개, 집진설비, 사무동과 금속 자재 팔레트를 표현했습니다. 승인 대기 중이며 게임에는 미등록입니다.

building.blend 편집 원본, building.png 정면, reverse-review.png 뒷면, metadata.json 규격 포함. 재생성: 저장소 루트에서 `blender --background --factory-startup --python-exit-code 1 --python assets/industrial-study/build_medium-4x4-precision-03.py`. Blender 4.3.2 CPU 렌더. 글꼴 라이선스는 상위 FONT_LICENSE.txt 참조.
