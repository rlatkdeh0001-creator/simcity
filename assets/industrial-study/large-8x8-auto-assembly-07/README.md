# 대형 공업 3번 — 자동차 조립공장

8×8칸(32×32m). 넓은 단층 생산동과 3층 사무동을 결합한 저층 대형 시설입니다. 톱니형 채광 지붕은 추가 점유 층이 아닙니다. 생산동의 하역 셔터 3개, 추출·환기설비, 부품 상자와 완성차 출하 구역을 표현했습니다.

사용자 승인 대기, 게임 미등록입니다. building.blend 편집 원본, building.png 정면, reverse-review.png 뒷면, metadata.json 규격 포함. 차량도 외부 모델 없이 직접 제작했습니다.

재생성: 저장소 루트에서 `blender --background --factory-startup --python-exit-code 1 --python assets/industrial-study/build_large-8x8-auto-assembly-07.py`. Blender 4.3.2 CPU 렌더링, 글꼴 라이선스는 상위 FONT_LICENSE.txt 참조.
