# 소형 공업 2번 — 식품가공 작업장

2×2칸(8×8m), 지상 1층. 밝은 단열 패널, 녹색 하부 마감, 밀 이삭 간판, 냉장 하역문, 외부 냉각설비, 포장 상자로 식품 생산·출하 시설을 표현했습니다. 소매 매장 진열은 없습니다. 환기구와 냉각설비는 층수에 포함하지 않습니다.

승인 대기 중이며 게임에는 미등록입니다. building.blend 편집 원본, building.png 정면, reverse-review.png 뒷면, metadata.json 규격을 포함합니다.

재생성: 저장소 루트에서 `blender --background --factory-startup --python-exit-code 1 --python assets/industrial-study/build_small-2x2-foodworks-02.py`. Blender 4.3.2 CPU 렌더링. 외부 모델·텍스처 없이 직접 제작했고, 간판용 DejaVu 글꼴 라이선스는 상위 FONT_LICENSE.txt에 있습니다.
