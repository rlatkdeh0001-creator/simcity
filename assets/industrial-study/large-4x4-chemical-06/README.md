# 대형 공업 2번 — 화학 생산시설

4×4칸(16×16m), 지상 2층 생산·제어동과 별도의 반응 탱크·설비탑·서비스 작업대로 구성했습니다. 높은 설비는 점유 층수에 포함하지 않습니다. 공업건물 대부분을 낮게 유지한다는 사용자 방향을 따릅니다.

게임용 조형 시안으로 CHEM WORKS 간판, 반응 탱크 2기, 설비탑과 배관, 작업대·사다리, 출하 드럼을 표현했습니다. 사용자 승인 대기, 게임 미등록입니다.

building.blend 편집 원본, building.png 정면, reverse-review.png 뒷면, metadata.json 규격 포함. 재생성: 저장소 루트에서 `blender --background --factory-startup --python-exit-code 1 --python assets/industrial-study/build_large-4x4-chemical-06.py`. Blender 4.3.2 CPU 렌더링. 글꼴 라이선스는 상위 FONT_LICENSE.txt를 참조하세요.
