# 시안 검증

- Blender 4.3.2 CPU Cycles, 64 samples. 외부 모델·텍스처·생성 API 호출 없음.
- A/B 각각 .blend 저장 성공. 생성 중 실제 메시 좌표 기준 부지 안쪽 배치 검사 통과.
- A/B 각각 occupied floor marker 4개를 모델 생성 시 확인.
- 앞면/반대편 PNG 4개: 각 900×900 RGBA, 투명 여백과 잘림 없는 알파 경계 확인.
- 두 시안의 카메라 및 부지 투영 좌표 일치 확인.
- 두 시안의 정면·반대편과 최종 비교판을 직접 확인.
- 비교 HTML: 이미지 2개 정상 로드, JavaScript 오류 없음, 1600×1100 캡처 생성.
- 초기 제작 중 부지 밖 나무 수관, 기본 world 미생성, OIDN 미지원 오류를 해결 후 재렌더.
- A의 지붕 모서리를 벗어나는 이음선을 수정한 뒤 재렌더.
- 최종 Godot 씬 연결이나 플레이 중 가림/정렬은 아직 검증하지 않음.
